# 테스트 피드백

> [!abstract] 한 줄 요약
> 플레이테스트에서 받은 지적과 그에 대한 대응 방향. 반영된 항목은 [[패치내역]]에 올라간다.


- 모험 준비 단계에서 성공률 텍스트가 뭘 의미하는지 모르겠다
	-> 모험 준비 단계의 성공률 텍스트를 클릭 시 상세 정보를 표시하는 패널 추가
- 앱 이름이 영어다
	-> 한국어로 변경
- 대화창의 이름/역할의 가시성이 안좋다
	-> 가시성 수정
- 저녁에 할일이 없어서 맥이 끊긴다
  -> 아침과 동일하게 모든 상호작용 완료 시 스킵 추가
