# 점술가(Seer) 시스템 개편

## 개요

기존 `EventTypeHint` 제거, `AbstractIndicator` + 신규 `LuckIndicator` 이중 구조로 개편.

- **AbstractIndicator (5단계)**: 모험 성공 가능성 예측 — 정보 제공
- **LuckIndicator (4단계)**: 운세 — 실제 `cumulativeModifier` 버프/디버프 제공
- 두 결과를 조합해 단일 서사 텍스트 + 운세 효과를 출력

---

## AbstractIndicator — 성공 예측 (5단계)

| 단계 | 조건 (estimatedRate) | 텍스트 |
|------|----------------------|--------|
| 대길조 | >= 0.8 | 강한 빛이 감돌고 있습니다. 성공이 눈앞에 보입니다. |
| 길조  | >= 0.6 | 밝은 기운이 감돌고 있습니다. 순조로운 여정이 기대됩니다. |
| 보통  | >= 0.4 | 흐릿하지만 가능성이 보입니다. 준비가 관건입니다. |
| 험난  | >= 0.2 | 험난한 여정이 예상됩니다. 각별한 준비가 필요합니다. |
| 암담  | < 0.2  | 앞날이 매우 어둡습니다. 대비 없이는 어렵겠습니다. |

**계산 방식 (기존 유지):**
```
estimatedRate = (bestStatScore / threshold) × (1 + bestArmorBonus)
bestStatScore = 모든 WeaponType 중 최고 GetStatScore(wt)
bestArmorBonus = 모든 WeaponType 중 오늘 ArmorType 대비 최고 상성 보너스
```

> **주의:** 현재 모든 던전의 `baseStatThreshold = 200`으로 동일.
> 모험가 최고 스탯이 200 미만이면 길조(0.7+) 도달이 어려움.
> 임계값 단계 조정 또는 임계값 자체 분리 검토 필요.

## LuckIndicator — 운세 (4단계)

### 단계 정의

| 단계 | cumulativeModifier | 의미 |
|------|-------------------|------|
| 흉   | -0.10 | 불운. 이벤트 성공률 -10%p |
| 소길 | +0.05 | 소소한 행운. 이벤트 성공률 +5%p |
| 중길 | +0.10 | 행운. 이벤트 성공률 +10%p |
| 대길 | +0.20 | 큰 행운. 이벤트 성공률 +20%p |

> `cumulativeModifier`는 모험 시작 시 초기값으로 세팅됨.
> 이후 이벤트 결과(함정 패널티 등)에 따라 추가 누적됨.

### LUK 기반 판정

모험가의 LUK 스탯(0-100)을 기반으로 가중치 랜덤 판정.

| LUK 범위 | 흉   | 소길 | 중길 | 대길 |
|---------|------|------|------|------|
| 0 ~ 25  | 40%  | 35%  | 18%  | 7%   |
| 26 ~ 50 | 25%  | 38%  | 27%  | 10%  |
| 51 ~ 75 | 12%  | 30%  | 38%  | 20%  |
| 76 ~ 100 | 5%  | 20%  | 40%  | 35%  |

> 수치는 플레이테스트 후 조정 가능.
> 흉이 디버프를 주기 때문에 유저에게 유의미한 판단 기회를 줘야 함.

## 저장 구조

### SeerResult 변경

```csharp
public class SeerResult
{
    public SeerResultType resultType;   // AbstractIndicator만 남김
    public string description;          // 조합 서사 텍스트
    public LuckLevel luckLevel;         // 신규
    // luckModifier는 저장 불필요 — 런타임 시 InsightConfig에서 LuckLevel → modifier 조회
}
```

### 저장 흐름

- `gameData.seerResults[key]`에 `SeerResult` 저장 (기존 구조 유지)
- 매일 `OnNewDay`에서 초기화 (기존 유지)
- 모험 시작 시(`StartAdventure`): `SeerManager.GetLuckModifier(luckLevel)` → `InsightConfig`에서 수치 조회 → `adventure.cumulativeModifier` 초기값 세팅
- `cumulativeModifier`는 `AdventureInstanceSaveData`에 이미 저장됨 → 별도 처리 불필요

## 테스트 케이스 (CSV 데이터 기반)

### 입력 조건

모든 던전 `baseStatThreshold = 200` 동일. LUK은 `adventurerData`의 min-max 중간값 사용.

| 모험가 | 주요 스탯 | LUK 중간값 | 던전 | 예상 Abstract | 예상 Luck 분포 |
|--------|----------|-----------|------|--------------|--------------|
| 기사 주디 | STR 90 | 85 | DGN_001 고블린 소굴 (Common/Light) | 보통 (statRatio ≈ 0.45) | 대길 35%, 중길 40% |
| 무희 판도라 | DEX 90 | 90 | DGN_003 도적 야영지 (Common/Light) | 보통 | 대길 35%, 중길 40% |
| 군주 모르가트 | STR 95 | 45 | DGN_007 오크 요새 (Rare/Heavy) | 보통 | 흉 25%, 소길 38% |
| 궁중마법사 제네시스 | INT 92 | 75 | DGN_009 마법사 탑 (Rare/Magical) | 보통 | 중길 38%, 대길 20% |
| 투사 라그나 | STR 95 | 55 | DGN_015 드래곤 둥지 (Legendary/Heavy) | 보통 | 소길 30%, 중길 38% |
| 학자 발타자르 | INT 87 | 85 | DGN_013 고대 유적 (Epic/Magical) | 보통 | 대길 35%, 중길 40% |
| 마녀 레이븐 | INT 90, LUK 80 | 80 | DGN_012 악마의 사원 (Epic/Magical) | 보통 | 중길 40%, 대길 35% |

### 관찰

- 현재 데이터 기준 `baseStatThreshold = 200`에서 대부분 모험가 statRatio ≈ 0.45~0.5 → 5단계 기준 '보통(0.4~0.6)' 수렴
- **길조(0.6+)** 도달: bestStatScore × (1 + armorBonus) >= 120 필요 → GetStatScore가 복합 계산이면 가능성 있음
- **대길조(0.8+)** 도달: bestStatScore × (1 + armorBonus) >= 160 필요 → 고스탯 + 상성 일치 시 가능
- **험난/암담** 구간: STR/DEX/INT 전부 낮은 일반 모험가가 고등급 던전 도전 시 발생 예상
- 실제 GetStatScore 로직 확인 후 임계값 세부 조정 필요
