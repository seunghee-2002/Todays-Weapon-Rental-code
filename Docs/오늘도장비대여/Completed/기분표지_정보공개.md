# 기분 표지(Mood) — 정보 공개 관점

모험 시작 버튼의 **배경색**으로 표시되는 정성적 신호.
"이 모험가가 이 던전을 어떻게 느끼는가"를 한 가지 색으로 요약한다.

- 계산: `MoodLabelCalculator.Calculate` (`Assets/_Projects/Scripts/Systems/AdventureManager/MoodLabelCalculator.cs`)
- 표시: `PreparationTab3Panel.RefreshStartButtonMood` (`Assets/_Projects/Scripts/UI/Views/AdventurerInteraction/PreparationTab3Panel.cs`)
- 색 사전: `AdventureInfoConfig.moodLabels` (`Assets/_Projects/Scripts/Data/Config/AdventureInfoConfig.cs`) (20색, 디자이너 조정)

> **화면에 단어("환희" 등)는 나오지 않는다.** `Calculate`가 돌려주는 것은 `color`/`textColor`뿐이고, band·state·라벨 단어는 색을 고르는 데만 쓰인다. (에셋의 `label:` 필드는 미사용)

---

## 무엇으로 결정되는가

입력은 **모험 준비 화면에 떠 있는 모험 정보 칩 전부**다. 칩은 `AdventurePreparationController.BuildAdventureInfoCards` (`Assets/_Projects/Scripts/UI/Controllers/AdventurerInteraction/AdventurePreparationController.cs`)에서 생성된다.

각 칩 = `type`(보너스 종류) + `value`(성공 기여도 ±) + `isConfirmed`(확정 / 시뮬레이션).

**칩 종류와 확정 여부**

| 칩(`BonusType`) | 의미 | `isConfirmed` |
|---|---|:---:|
| DungeonGrade | 던전 등급 baseline | 항상 true |
| Affection | 호감도 보너스 | 항상 true |
| Charm | 매력 보너스 | 항상 true |
| Trait | 특성 보너스 | 항상 true |
| Collection | 수집(도감) 보너스 | 항상 true |
| Seer | 점술 길흉 보정 | 항상 true |
| DungeonArmor | 무기-던전 방어 상성 | 방어 타입 **공개 시** true, 미공개(시뮬레이션) 시 false |
| WeaponCondition | 무기 상태 보정 | 무기 확정 시 true, 시뮬레이션 시 false |

→ 정보 노출은 칩 단계에서 이미 게이트됨: **공개되지 않은 칩은 화면에 없으므로 mood 계산에도 안 들어간다.** mood는 새 정보를 만들지 않고, 보이는 칩들을 한 색으로 합산할 뿐이다.

---

## 두 축

### 세로축 — Band (기대 밝기, 5단계)

```
E = Σ value   where isConfirmed = true        (확정 칩들의 합)
```

| VeryDark | Dark | Neutral | Bright | VeryBright |
|:---:|:---:|:---:|:---:|:---:|
| E ≤ -0.15 | -0.15 < E ≤ -0.05 | -0.05 < E < +0.05 | +0.05 ≤ E < +0.15 | E ≥ +0.15 |

임계: `bandThresholdVeryDark/Dark/Bright/VeryBright`.

### 가로축 — Variance (변동성 방향, 4종)

미확정(시뮬레이션) 칩만 본다. "확실하지 않은 부분이 어느 쪽으로 흔들리는가".

```
V₊ = Σ value      where isConfirmed = false AND value > 0
V₋ = Σ |value|    where isConfirmed = false AND value < 0
V  = V₊ + V₋
total = Σ |value| for all cards
T_low = max(varianceLowFloor, total × varianceLowRatio)   # 동적 하한
```

| 상태 | 조건 | 의미 |
|---|---|---|
| None | V < T_low | 미확정 영향 미미 — 거의 확정 |
| Positive | V₊ / V ≥ varianceLeanThreshold | 미확정분이 좋은 쪽으로 우세 |
| Negative | V₋ / V ≥ varianceLeanThreshold | 미확정분이 나쁜 쪽으로 우세 |
| Mixed | 위 둘 다 아님 | 좋고 나쁨이 섞임 |

→ (Band, State)로 `AdventureInfoConfig.moodLabels` (`Assets/_Projects/Scripts/Data/Config/AdventureInfoConfig.cs`)에서 색을 찾는다.

## 정보 공개 컨셉과의 관계

- **정량 정보는 노출하지 않는다.** 성공률·보상 수치는 통찰/정찰 게이트로 별도 관리([[통찰_정보공개_체계]]). mood는 그 게이트를 우회하지 않는 "분위기" 신호다.
- **Band**는 이미 보이는 확정 칩들의 요약 → 새 정보 아님.
- **Variance**는 *미확정* 칩이 시뮬레이션상 어느 쪽으로 기우는지를 드러낸다. 색으로 Positive/Negative를 구분하면 "숨겨진 변동의 방향"을 힌트로 주는 셈 — 정찰/통찰을 더 할지 강행할지 고민하게 만드는 **의도된 긴장**이다. 단, 이 노출 강도가 부담되면 variance를 색조 대신 채도/질감으로만 약하게 표현하는 선택지가 있다.
