# 통찰 — 정보 공개 체계

통찰(Insight)은 0~100 범위의 플레이어 누적 수치.

---

## 통찰 구간별 공개 정보

| 통찰 | 모험가 | 던전 | 수색꾼 | 모험 준비 화면 |
|:---:|---|---|---|---|
| **0** | 무기 타입 힌트 대화 해금 | — | 파견 소요 120분 | 부가효과 전체 표시 (Active/Inactive/Unknown) |
| **15** | 일반: 랜덤 스탯 1개 자동 공개 | — | — | — |
| **25** | — | — | 파견 소요 80분 | — |
| **30** | 일반: 평균 스탯 표시<br>대화 소요 42분 | 보상 최솟값 표시 (`X G~`) | — | — |
| **50** | 일반: 랜덤 스탯 2개 자동 공개<br>대화 소요 24분 | — | 파견 소요 40분 | — |
| **55** | — | 예상 소요 시간 표시 | — | 소요 시간 행 표시 |
| **60** | — | 보상 전체 표시 (`X~Y G`) | — | 보상 행 전체 표시 |
| **70** | 일반: 최고 스탯 추가 공개<br>대화 소요 12분 | — | — | — |
| **75** | — | — | 파견 소요 20분 | — |
| **80** | 일반: 특성 자동 공개 | — | — | 기본/최종 성공률 표시 (스탯 3개+방어타입 공개 시 통찰 무관하게도 표시) |

---

## 2차 대화 성공 확률

| 항목 | 공식 (기본값 기준) |
|---|---|
| 개별 스탯 | `clamp(60% + 통찰×0.5% − 공개된스탯수×(30%−통찰×0.2%), 0, 100%)` |
| 전체 스탯  | 개별 공식에서 패널티 ×1.5 |
| 특성       | `clamp(50% + 통찰×0.8%, 0, 100%)` |

---

## 수색꾼 — 방어 타입 공개

통찰 수치와 무관. 파견 → 소요 시간 경과 → 결과 팝업 확인 시 공개.

- 파견 비용: `현재 일차 × 30G × 던전 등급 배수`
- 날짜 변경 시 미완료 임무 환불 + 전체 초기화

**던전 등급 배수**

| Common | Uncommon | Rare | Epic | Legendary |
|:---:|:---:|:---:|:---:|:---:|
| ×0.8 | ×1.0 | ×1.2 | ×1.5 | ×2.0 |

---

## 모험 준비 화면 — 성공률 분해 행 표시 조건

| 행 | 표시 조건 |
|---|---|
| 기본 성공률 | 통찰 80+ OR (스탯 3개 이상 공개 AND 던전 방어 타입 공개) |
| 무기-던전 상성 | 무기 타입 공개 (방어 타입 미공개 시 시뮬레이션 기반 표시) |
| 무기 부가 효과 | 항상 (ArmorTypeBonus는 실제 또는 시뮬레이션 방어 타입 기반으로 합산) |
| 부적 사용 | 항상 (값 0이면 숨김) |
| 특성 보너스 | 특성 공개 (일반 모험가는 통찰 80+면 자동 공개. 값 0이면 숨김) |
| 최종 성공률 | 통찰 80+ OR (스탯 3개 이상 공개 AND 던전 방어 타입 공개) |
| 예상 소요 시간 | 통찰 55+ |
| 보상 | 통찰 30+부터 단계적 |

**부가효과 표시 상태**

| 상태 | 색상 | 해당 효과 타입 |
|:---:|:---:|---|
| Active  | 흰색/황금 | StatBonus·AllStatBonus·WeaponTypeMatchBonus는 항상 / 나머지는 조건 충족 시 |
| Inactive | 회색 | 조건 불충족 확인됨 |

효과 이름의 타깃(방어타입·등급 등)은 무기 고유 정보이므로 방어 타입 공개 여부와 무관하게 항상 표시한다. ArmorTypeBonus의 Active/Inactive는 실제 또는 시뮬레이션 방어 타입 기준으로 판정한다.

---

## 시뮬레이션 기반 표시

방어 타입이 수색꾼으로 공개되지 않은 던전은 모험 준비 상세 패널의 시뮬레이션 토글로 가상의 방어 타입을 선택할 수 있다. 토글 변경 시 모험 준비 상세 패널의 분해 행과 Tab3의 모험 정보 칩이 함께 갱신된다.

**시뮬레이션 적용 대상**
- 성공률 분해 행: 무기-던전 상성, 무기 부가 효과(ArmorTypeBonus 부분)
- 모험 정보 칩: DungeonArmor, WeaponCondition (ArmorTypeBonus 영향분)
- 부가효과 리스트: ArmorTypeBonus의 Active/Inactive 상태

**시뮬레이션 미적용 — 실제 방어 타입 공개 필요**
- 기본 성공률 / 최종 성공률 행 — 정확 수치를 보장하기 위함
- 모험 정보 칩의 WeaponAdventurerMatch — 동일한 이유

**모험 정보 칩의 `isConfirmed` 의미**
- `true` — 실제로 확정된 값 (체크 아이콘)
- `false` — 시뮬레이션에 의존하는 값 (`??` 아이콘)
