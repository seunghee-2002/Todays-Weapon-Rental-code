## 2. 특성별 상세 정의

### 행운아 (Lucky)
> "어디서든 운이 따른다."

- **효과:** 대성공 확률 +5%
- **구현 상태:** ⚠️ 구현됨 → Config 필드명 변경 필요
- **Config 키:** `luckyGreatSuccessBonus` → **`traitLuckyGreatSuccessBonus = 0.05f`**

---

### 베테랑 (Veteran)
> "수많은 던전을 헤쳐온 노련함이 있다."

- **효과:** 탐험도 상승량 ×2.0 (곱계산)
- **구현 상태:** ❌ 미구현 → 구현 필요
- **Config 키 (신규):** `traitVeteranExplorationMultiplier = 2.0f`
- **적용 위치:** 탐험도 적용 계산부에서 `Veteran` 특성 체크 후 곱연산

---

### 약탈자 (Looter)
> "남들이 지나치는 것도 챙긴다."

- **효과:** 모험 성공 시 재료 드롭 +1개
- **구현 상태:** ⚠️ 구현됨 → Config 필드명 변경 필요
- **Config 키:** `looterMaterialBonus` → **`traitLooterMaterialBonus = 1`**

---

### 신속 (Swift)
> "빠르게 치고 빠진다. 탐색은 생략한다."

- **효과:** 모험 소요 시간 ×0.5, 탐험도 0 (탐험도 기여 없음)
- **구현 상태:** ❌ 미구현 → 구현 필요
- **Config 키 (신규):** `traitSwiftDurationMultiplier = 0.5f`
- **적용 위치:**
  - 모험 duration 계산부에서 `Swift` 특성 체크 후 ×0.5
  - 탐험도 적용 직전 `Swift` 특성 체크 시 0으로 고정
- **비고:** 시간 이득 대신 던전 개척 진행이 전혀 없는 완전한 트레이드오프.

---

### 부자 (Rich)
> "씀씀이가 크다. 무기를 빌리고 나서 팁을 두둑이 챙겨준다."

- **효과:** 모험 완료 시 기본 수수료의 10%를 팁으로 추가 지불
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):** `traitRichTipRate = 0.1f`
- **적용 위치:** 모험 완료 보상 계산부에서 `Rich` 특성 체크 → `수수료 × traitRichTipRate` 만큼 별도 합산
- **비고:** 기존 수수료 공식과 독립된 별도 항목. UI에서 "팁 +Xg" 식으로 구분 표시 가능.

---

### 짐꾼 (Porter)
> "짐꾼 출신이라 거래에 서툴다. 가져온 재료를 싼 값에 넘긴다."

- **효과:** 이 모험가가 가져온 재료를 플레이어가 구매할 때 가격 -50%
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):** `traitPorterMaterialPriceMultiplier = 0.5f`
- **적용 위치:** 재료 구매 UI에서 `Porter` 특성 체크 → 가격에 곱연산

---

### 광전사 (Berserker)
> "전투에서 한계를 뛰어넘는다. 성공률과 사망률이 모두 오른다."

- **효과:** 성공률 ×1.1, 사망률 ×1.1 (둘 다 곱계산)
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):**
  - `traitBerserkerSuccessMultiplier = 1.1f`
  - `traitBerserkerDeathMultiplier = 1.1f`
- **적용 위치:** 성공률·사망률 최종 계산 후 각각 곱연산 적용

---

### 생존가 (Enduring)
> "어떤 상황에서도 살아남는 법을 안다."

- **효과:** 모험 시작 시 보호 +1 부여 (사망 판정 1회 무효화)
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키:** 없음 (보호 카운트는 코드 분기로 처리)
- **적용 위치:** 사망 판정 시 보호 카운트가 남아있으면 1 소모 후 생존 처리

---

### 성장하는 자 (Rising)
> "역경에서 빛을 발한다. 어려운 던전일수록 실력이 올라온다."

- **효과:** 던전 등급에 비례해 성공률 증가 (등급당 +2%)
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):** `traitRisingBonusPerTier = 0.02f`
- **계산 예시:**

  | 던전 등급 | 성공률 보정 |
  |----------|------------|
  | 1등급 | +2% |
  | 2등급 | +4% |
  | 3등급 | +6% |
  | 4등급 | +8% |
  | 5등급 | +10% |

- **적용 위치:** 성공률 계산 시 `dungeon.tier × traitRisingBonusPerTier` 합산

---

### 유명인 (Famous)
> "소문이 자자한 모험가다. 그의 활약이 가게의 명성을 높인다."

- **효과:** 모험 성공/대성공 시 평판 획득량 추가 +2
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):** `traitFamousReputationBonus = 2`
- **적용 위치:** 평판 변화 계산부에서 `Famous` 특성 체크 → 성공/대성공 결과일 때 보너스 합산
- **비고:** 실패/사망 시에는 적용 안 함.

---

### 흥정꾼 (Haggler)
> "기분에 따라 값을 깎기도, 후하게 내기도 한다. 예측이 안 된다."

- **효과:** 모험 완료 시 수수료 변동 — -15% / 0% / +20% 중 랜덤 1개 적용
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):**
  - `traitHagglerRateLow = -0.15f`
  - `traitHagglerRateMid = 0f`
  - `traitHagglerRateHigh = 0.2f`
- **적용 위치:** 모험 완료 보상 계산부에서 `Haggler` 특성 체크 → 3가지 중 균등 확률(33.3%)로 선택 후 수수료에 적용
- **비고:** 기댓값은 +1.67%로 약간 플레이어에게 유리. 불확실성 자체가 특성의 개성.

---

### 겁쟁이 (Coward)
> "목숨이 최우선이다. 위험하다 싶으면 물러선다."

- **효과:** 사망률 ×0.3, 성공률 ×0.85 (둘 다 곱계산)
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):**
  - `traitCowardDeathMultiplier = 0.3f`
  - `traitCowardSuccessMultiplier = 0.85f`
- **적용 위치:** 성공률·사망률 최종 계산 후 각각 곱연산 적용
- **비고:** 광전사(Berserker)의 반대 구조. 사망 리스크를 극도로 낮추는 대신 성공률 포기.

---

### 집중 (Focused)
> "느리지만 철저하게 준비한다."

- **효과:** 모험 소요 시간 ×1.5, 성공률 +15%
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):**
  - `traitFocusedDurationMultiplier = 1.5f`
  - `traitFocusedSuccessBonus = 0.15f`
- **적용 위치:**
  - 모험 duration 계산부에서 `Focused` 특성 체크 후 ×1.5
  - 성공률 계산부에서 `Focused` 특성 체크 후 +15%
- **비고:** 신속(Swift)의 반대 구조. 시간을 더 쓰는 대신 성공률 대폭 향상.

---

### 도축업자 (Butcher)
> "전리품엔 밝지만 돈 계산은 못 한다."

- **효과:** 재료 드롭 +2개, 수수료 -20%
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):**
  - `traitButcherMaterialBonus = 2`
  - `traitButcherFeeMultiplier = 0.8f`
- **적용 위치:**
  - 재료 드롭 계산부에서 `Butcher` 특성 체크 후 +2
  - 수수료 계산부에서 `Butcher` 특성 체크 후 ×0.8
- **비고:** 약탈자(Looter, +1개 / 페널티 없음)보다 재료는 많지만 수수료 손해가 있는 트레이드오프.

---

### 양학 (Easy Expert)
> "쉬운 던전에서 두각을 드러낸다. 어려운 던전은 영 못 맞는다."

- **효과:** 1~2등급 던전 성공률 +20%, 3등급 이상 성공률 -15%
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):**
  - `traitEasyExpertLowTierBonus = 0.2f` (1~2등급 적용)
  - `traitEasyExpertHighTierPenalty = -0.15f` (3등급 이상 적용)
- **적용 위치:** 성공률 계산 시 던전 등급 분기 후 각 보정값 합산
- **비고:** 성장하는 자(Rising)의 완전한 반대 구조. 저등급 던전 전담 포지션.

---

### 전투광 (Battle Maniac)
> "싸우는 것 자체가 목적이다. 탐색 따위엔 관심 없다."

- **효과:** 성공률 +10%, 탐험도 0 (탐험도 기여 없음)
- **구현 상태:** ❌ 신규 구현 필요
- **Config 키 (신규):** `traitBattleManiacSuccessBonus = 0.1f`
- **적용 위치:**
  - 성공률 계산부에서 `BattleManiac` 특성 체크 후 +10%
  - 탐험도 적용 직전 `BattleManiac` 특성 체크 시 0으로 고정
- **비고:** 신속(Swift)과 마찬가지로 탐험도가 없음. 차이점은 시간 단축 없이 성공률만 높음. 탐험도 진행이 불필요한 상황(이미 완전히 개척된 던전)에서 최적.

## 5. 구현 우선순위

### Phase 1 — 기존 미구현 특성 완성
1. **베테랑**: 탐험도 계산부 ×2.0 적용
2. **신속**: 소요 시간 ×0.5, 탐험도 0 고정

### Phase 2 — 신규 특성 구현
3. **부자**: 수수료 × 10% 팁 별도 합산
4. **광전사**: 성공률·사망률 각 ×1.1 적용
5. **짐꾼**: 재료 구매 가격 ×0.5 적용
6. **생존가**: 사망 판정 분기에 보호 카운트 체크 추가
7. **성장하는 자**: 던전 등급 기반 성공률 보정 추가
8. **유명인**: 평판 보너스 연동
9. **흥정꾼**: 수수료 변동 랜덤 (-15% / 0% / +20%)
10. **겁쟁이**: 사망률·성공률 곱계산
11. **집중**: 소요 시간 ×1.5, 성공률 +15%
12. **도축업자**: 재료 +2, 수수료 ×0.8
13. **양학**: 던전 등급 분기 성공률 보정
14. **전투광**: 성공률 +10%, 탐험도 0 고정

## 6. AdventureConfig.cs 변경 사항

### 6-1. 삭제할 기존 필드

삭제된 특성(철의 의지, 도박사)에 해당하는 필드 제거:

```csharp
// 삭제
public float ironWillDeathReduction = 5f;
public float gamblerGreatSuccessBonus = 0.1f;
```

### 6-2. 이름 변경할 기존 필드

`trait` 접두사로 통일 (참조 코드도 함께 변경 필요):

```csharp
// 변경 전 → 변경 후
luckyGreatSuccessBonus   →  traitLuckyGreatSuccessBonus
looterMaterialBonus      →  traitLooterMaterialBonus
```

## 7. AdventureManager.Calculations.cs 리팩토링 방향

특성 로직이 현재 각 계산 함수에 인라인으로 흩어져 있음. 각 계산 도메인마다 `GetTrait*` 메서드를 하나씩 두고, 해당 함수 내부에서 모든 특성 분기를 처리하도록 변경.

### 7-1. 추가할 GetTrait* 메서드 목록

| 메서드 | 반환 | 적용 특성 | 호출 위치 |
|--------|------|----------|----------|
| `GetTraitSuccessBonus(adventurer, dungeon)` | `float` | Focused +15%, BattleManiac +10%, Rising 등급×2%, EasyExpert 등급 분기 | `CalculateSuccessRate` bonusSum 합산 |
| `GetTraitSuccessMultiplier(adventurer)` | `float` | Berserker ×1.1, Coward ×0.85, 기본 1.0 | `CalculateSuccessRate` 최종 결과에 곱 |
| `GetTraitDeathMultiplier(adventurer)` | `float` | Berserker ×1.1, Coward ×0.3, 기본 1.0 | `CalculateDeathRate` 최종 결과에 곱 |
| `GetTraitGreatSuccessBonus(adventurer)` | `float` | Lucky +5% | `CalculateGreatSuccess` chance에 합산 |
| `GetTraitMaterialBonus(adventurer)` | `int` | Looter +1, Butcher +2 | `CalculateMaterialDropsWithBonus` baseAmount에 합산 |
| `GetTraitDurationMultiplier(adventurer)` | `float` | Swift ×0.5, Focused ×1.5, 기본 1.0 | 모험 duration 계산부에 곱 |
| `GetTraitExplorationMultiplier(adventurer)` | `float` | Swift/BattleManiac → 0, Veteran ×2.0, 기본 1.0 | 탐험도 적용부에 곱 |
| `GetTraitFeeMultiplier(adventurer)` | `float` | Butcher ×0.8, Haggler 랜덤(-0.15/0/+0.2), 기본 1.0 | `ApplyCommission` 수수료 계산부에 곱 |
| `GetTraitTipBonus(adventurer, baseGold)` | `int` | Rich = baseGold × 0.1 | `ApplyCommission` 팁 항목에 별도 합산 |
| `GetTraitReputationBonus(adventurer)` | `int` | Famous +2, 기본 0 | `CalculateRewards` 평판 변화 합산 |

### 7-2. 기존 코드 변경 사항

```csharp
// 변경 전: GetTraitBonus() 항상 0 반환
private float GetTraitBonus(AdventurerInstance adventurer) { return 0f; }

// 변경 후: 삭제하고 GetTraitSuccessBonus + GetTraitSuccessMultiplier로 분리

// CalculateSuccessRate 변경 후 구조
bonusSum += GetTraitSuccessBonus(adventurer, dungeon);     // 기존 GetTraitBonus 대체
float result = Mathf.Clamp(baseRate + bonusSum, ...);
return result * GetTraitSuccessMultiplier(adventurer);     // 곱계산 특성 후처리

// CalculateDeathRate 변경 후 구조
float rate = Mathf.Clamp(baseRate / 100f, 0f, Config.maxDeathRate);
return rate * GetTraitDeathMultiplier(adventurer);         // 기존 인라인 IronWill 체크 대체

// CalculateGreatSuccess 변경 후 구조
chance += GetTraitGreatSuccessBonus(adventurer);           // 기존 switch 블록 대체

// CalculateMaterialDropsWithBonus 변경 후 구조
baseAmount += GetTraitMaterialBonus(adventurer);           // 기존 Looter 인라인 체크 대체
```
