# 인벤토리·아이템 UI

> 보유한 무기·재료·보조 아이템을 **보여 주고, 상세를 확인하고, 팔거나 쓰는** 화면을 기획 관점에서 정리한다. 시스템 규칙은 [[인벤토리_시스템]] 참조.

---

## 1. 인벤토리 화면 (3탭)

인벤토리는 **탭으로 나뉜 단일 화면**이다.

| 영역 | 내용 |
|---|---|
| 제목 / 닫기 | 화면 제목과 닫기 버튼 |
| 탭 | **무기 · 재료 · 보조 아이템** 세 탭을 토글로 전환 |
| 목록 | 선택한 탭의 보유 항목을 슬롯으로 나열(종류별 슬롯 모양) |
| 무기 수 표시 | 무기 탭의 보유 수(슬롯 한도 대비)를 표시 |
| 빈 안내 | 해당 탭에 가진 것이 없을 때 안내 문구 |

- 탭을 바꾸면 그 종류의 목록만 보인다.
- 슬롯을 누르면 종류에 맞는 **상세 팝업**이 열린다(아래 2~4장).
- 보유 내용이 바뀌면 목록이 **즉시 갱신**된다.

---

## 2. 무기 상세 팝업

무기 슬롯을 누르면 열린다.

### 표시 정보

| 요소 | 내용 |
|---|---|
| 아이콘 / 이름 | 무기 그림과 이름 |
| 등급 / 타입 | 무기 등급과 무기 유형 |
| 공격력 / 내구도 | 현재 공격력과 남은 내구도 |
| 설명 | 무기 설명 |
| 부가효과 목록 | 무기가 가진 부가효과들을 줄별로 표시 |

### 조작

| 요소 | 기능 |
|---|---|
| 판매 | 무기를 팔아 골드로 바꾼다 |
| 닫기 | 팝업을 닫는다 |

---

## 3. 재료 상세 팝업

재료 슬롯을 누르면 열린다.

### 표시 정보

| 요소 | 내용 |
|---|---|
| 아이콘 / 이름 | 재료 그림과 이름 |
| 등급 / 분류 | 재료 등급과 분류(강화·제작·특수) |
| 설명 | 재료 설명 |
| 보유 수량 | 현재 가진 개수 |
| 판매 가치 | 팔았을 때 받는 값 |

### 조작

| 요소 | 기능 |
|---|---|
| 판매 | 재료를 팔아 골드로 바꾼다 |
| 닫기 | 팝업을 닫는다 |

---

## 4. 보조 아이템 상세 팝업

보조 아이템 슬롯을 누르면 열린다.

### 표시 정보

| 요소 | 내용 |
|---|---|
| 아이콘 / 이름 | 아이템 그림과 이름 |
| 종류 | 어떤 보조 아이템인지 |
| 설명 / 효과 | 아이템 설명과 효과를 풀어 쓴 문구 |
| 보유 수량 | 현재 가진 개수 |

### 조작

| 요소 | 기능 |
|---|---|
| 사용 | **여는 맥락이 허용할 때만** 표시되는 사용 버튼 |
| 닫기 | 팝업을 닫는다 |

- 인벤토리에서 그냥 열어 볼 때는 **정보 확인용**이며, 사용 버튼은 그 아이템을 쓸 수 있는 화면에서 열렸을 때만 나타난다.
- 실제 배정·사용 흐름은 인벤토리 밖에서 일어난다(아래 6장).

---

## 5. 무기↔방어구 상성 도움말 팝업

무기 타입이 어떤 방어구에 강하고 약한지를 보여 주는 **참고용 팝업**이다.

| 요소 | 내용 |
|---|---|
| 제목 | 도움말 제목 |
| 상성 목록 | 무기 타입별 방어구 상성을 행으로 나열 |
| 닫기 | 팝업을 닫는다 |

> 상성이 모험 성공률에 어떻게 작용하는지는 [[모험_시스템]]에서 다룬다.

---

## 6. 인벤토리 밖에서의 사용 흐름

보조 아이템의 **실제 배정·사용**과 재료 구매는 다른 도메인 화면에서 이루어진다. 인벤토리 화면은 보유·열람·판매를 담당한다.

| 흐름 | 어디서 | 참고 |
|---|---|---|
| 모험형 아이템을 모험가에게 배정 | 모험 준비 화면 | [[모험_UI]] |
| 강화석을 대장장이 작업에 배정 | 대장간(강화석 선택) | [[무기_UI]] |
| 모험 도중 재료 구매 | 모험 진행 화면 | [[모험_UI]] |
| 인형(즉시형)으로 호감도 선물 | 모험가 대화 | [[모험가_UI]] |

---

## 7. 공통 표시 규칙

- 모든 목록·수량은 인벤토리 내용이 바뀌면 **즉시 갱신**된다(획득·소모·판매·대여 시작/종료 반영).
- 비어 있는 탭에는 안내 문구를 띄워 "없음"을 분명히 한다.
- 무기 탭의 보유 수 표시가 **슬롯 한도(가득 참)**를 사용자에게 알려 주는 핵심 장치다.
