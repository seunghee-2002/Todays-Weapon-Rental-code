# 인벤토리·아이템 시스템

> 길드가 보유한 **무기·재료·보조 아이템(액티브 아이템)**의 보관·증감·사용 규칙을 기획 관점에서 정리한다. 화면/표시는 [[인벤토리_UI]] 참조.
>
> 무기 자체의 등급·강화·효과는 [[무기_시스템]], 아이템 효과가 모험에 작용하는 방식은 [[모험_시스템]]에서 다룬다. 수치는 모두 밸런싱 설정값이다.

---

## 1. 세 가지 인벤토리

길드의 자원은 성격이 다른 세 종류로 나뉘어 따로 관리된다.

| 인벤토리 | 담는 것 | 세는 방식 | 보관 한도 |
|---|---|---|---|
| 무기 | 대여용 무기 한 자루씩 | 자루별 **개별** 보관 | 있음(슬롯 한도) |
| 재료 | 강화·제작용 소재 | 종류별 **수량 누적** | 없음 |
| 보조 아이템 | 1회성 보조 도구 | 종류별 **수량 누적** | 없음 |

- 무기는 같은 종류라도 등급·내구도·강화 상태가 제각각이라 **한 자루씩** 따로 센다.
- 재료·보조 아이템은 같은 것끼리 묶어 **개수**로 센다.
- 어느 인벤토리든 내용이 바뀌면 **변경 알림**이 발생해 화면이 즉시 갱신된다.

---

## 2. 무기 인벤토리

길드가 대여용으로 보유한 무기 재고. 무기 자체의 규칙은 [[무기_시스템]]에서 다루고, 여기서는 **보관·재고 관리**만 본다.

### 슬롯 한도

- 무기를 보관할 수 있는 **칸 수가 정해져 있다**: 기본 슬롯 수(설정값) + **유산으로 확장한 추가 칸**.
- 재고가 가득 차면 새 무기를 **더 들일 수 없다**. 먼저 팔거나 분해해 자리를 비워야 한다.
- 무기를 들이기 전에 항상 **남은 자리 여부**를 확인한다.

### 대여 상태

각 무기는 "지금 빌려나가 있는지"를 표시한다.

| 구분 | 의미 |
|---|---|
| 대여 가능 | 길드에 있어 빌려줄 수 있는 무기 |
| 대여 중 | 모험가가 빌려나간 무기(모험이 끝나야 복귀) |

- 모험가에게 무기를 제안할 때 후보로 뜨는 것은 **대여 가능한 무기뿐**이다.

### 들이고 내보내기

- 들이는 경로: 무기점 구매, 제작 완성, 일부 이벤트·보상.
- 내보내는 경로: 판매, 분해, 소실(모험가 사망 시 빌린 무기 분실).
- 무기 한 자루는 **고유 식별값**으로 구분되어, 같은 종류가 여러 자루여도 특정 한 자루를 정확히 골라 처리할 수 있다.

## 3. 재료 인벤토리

강화·제작에 들어가는 소모성 소재. 종류별로 **개수만** 관리한다.

### 규칙

- 같은 재료를 더 얻으면 **수량이 합산**된다.
- 재료를 쓰면 수량이 줄고, **0이 되면 목록에서 사라진다**.
- 사용 시 **보유량이 모자라면 거래가 성립하지 않는다**(부분 소비 없음 — 필요한 만큼 전부 있어야 한다).
- 보관 개수에 **상한이 없다**.

### 재료 분류

재료는 용도에 따라 세 갈래로 나뉜다. 분류는 화면에서 재료를 묶어 볼 때 쓰인다.

| 분류 | 용도 |
|---|---|
| 강화 재료 | 무기 강화에 사용 |
| 제작 재료 | 무기·아이템 제작에 사용 |
| 특수 재료 | 특정 레시피·이벤트 등에 쓰이는 특별 재료 |

- 각 재료는 **등급**(아래 6장)과 **기준 가치**(판매 기준)·**구매가**를 가진다.
- 강화·제작이 **어떤 재료를 얼마나** 요구하는지는 대장장이 규칙이므로 [[무기_시스템]]에서 다룬다.

## 4. 보조 아이템 (액티브 아이템)

모험이나 무기 작업에 즉효를 주는 **일회성 보조 도구**. 종류별로 수량으로 쌓인다.

### 사용 맥락 — 언제 쓰는가

아이템마다 **쓰이는 자리**가 정해져 있고, 그 자리에 맞춰 사용·소모된다.

| 맥락 | 사용 방식 |
|---|---|
| 즉시형 | 받는 즉시 효과가 적용된다(예: 호감도 선물). |
| 모험형 | 모험 떠나기 전 **특정 모험가에게 배정**해 두고, 그 모험에 1회 적용된 뒤 소모된다. |
| 대장장이형 | 대장장이 작업 슬롯에 **배정**해 두고, 강화·진화 작업에 1회 적용된 뒤 소모된다. |

**배정과 취소:**
- 모험형·대장장이형은 배정하는 순간 **인벤토리에서 빠져** 대기 상태가 된다.
- 작업(모험 출발/강화 실행)이 실제로 일어나면 그때 **소모**된다.
- 배정을 **취소하면** 아이템은 다시 인벤토리로 **복귀**한다.
- 대장장이 슬롯은 **한 개만** 배정할 수 있다(새로 배정하면 이전 것이 인벤토리로 돌아간다).

### 보조 아이템 종류

각 아이템은 효과 크기를 정하는 **설정값**을 하나 가진다.

| 아이템 | 맥락 | 효과 |
|---|---|---|
| 부적 | 모험 | 모험 성공률을 설정값(%)만큼 올린다 |
| 물약 | 모험 | 보호(후퇴 방지) 횟수를 설정값만큼 추가한다 |
| 탈출 로프 | 모험 | 함정 회피 확률을 설정값만큼 올린다 |
| 신속의 신발 | 모험 | 모험 진행 시간을 설정값 배율로 줄인다(예: 0.8 = 20% 단축) |
| 분해의 칼 | 모험 | 재료 획득량을 설정값(개)만큼 늘린다 |
| 황금 부적 | 모험 | 골드 획득을 설정값 비율만큼 늘린다 |
| 보물 지도 | 모험 | 희귀 드롭 보너스 재료를 설정값(개)만큼 늘린다 |
| 사망 방지 | 모험 | 사망률을 설정값 비율만큼 낮춘다 |
| 명성 두루마리 | 모험 | 모험 성공 시 평판을 설정값만큼 더 준다 |
| 인형 | 즉시 | 모험가 호감도를 설정값만큼 즉시 올린다 |
| 강화석 | 대장장이 | 강화·진화 성공률을 설정값 비율만큼 올린다 |

> 모험형 효과가 성공률·보상·시간·사망률·평판에 실제로 어떻게 합산되는지는 [[모험_시스템]], 강화석의 성공률 작용은 [[무기_시스템]]에서 다룬다.

---

## 5. 판매

- 무기와 재료는 인벤토리에서 **팔아 골드로 바꿀 수 있다**(재료는 보유 가치 기준).
- 보조 아이템은 **판매하지 않고 사용만** 한다.
- 판매로 들어오는 골드 처리는 경제 도메인에서 다룬다.

---

## 6. 등급 체계

무기와 재료는 **공통 등급 6단계**를 쓴다.

| 등급 | 이름 |
|---|---|
| 1 | Common |
| 2 | Uncommon |
| 3 | Rare |
| 4 | Epic |
| 5 | Legendary |
| 6 | Mythic |

- 등급이 높을수록 희귀하고 가치가 크다.
- **보조 아이템은 등급을 갖지 않는다**(종류와 효과 설정값으로만 구분).

---

## 7. 저장

인벤토리 내용은 **한 회차 게임 데이터**에 함께 저장된다(게임오버 시 초기화되는 진행 저장).

| 항목 | 저장 형태 |
|---|---|
| 무기 | 자루별 식별값·등급·내구도·강화 상태·효과 등을 굽어 목록으로 저장 |
| 재료 | 재료 종류 → 보유 수량의 짝 목록 |
| 보조 아이템 | 아이템 종류 → 보유 수량의 짝 목록 |
| 배정 상태 | 모험가별로 배정해 둔 아이템, 대장장이 슬롯에 올린 아이템 |

- 불러올 때 저장된 식별값을 정적 카탈로그와 다시 연결해 본래 성능 정보를 복원한다.
- 영구 저장(유산)과는 별개다. 유산은 별도 도메인에서 다룬다([[Systems]]).
