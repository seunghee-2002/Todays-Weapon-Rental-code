# 유산 UI

> 모아 둔 유산으로 **영구 업그레이드를 둘러보고 사는** 화면, 그리고 회차 도중 유산을 쓸 때 뜨는 **확인 팝업**을 기획 관점에서 정리한다. 시스템 규칙은 [[유산_시스템]] 참조.

---

## 1. 진입

- 유산 업그레이드 화면은 **메인 메뉴**의 업그레이드 버튼으로 연다.
- 유산은 영구 자산이라 회차를 시작하지 않은 상태(메뉴)에서도 관리할 수 있다.

---

## 2. 유산 업그레이드 화면

| 영역 | 내용 |
|---|---|
| 보유 유산 | 현재 가진 유산 포인트 |
| 카테고리 탭 | **시작 · 대장간 · 모험 · 특수** 네 탭을 토글로 전환 |
| 업그레이드 목록 | 선택한 탭의 업그레이드 항목을 스크롤로 나열 |
| 닫기 | 화면을 닫는다 |

- 화면을 열면 **시작 탭**이 먼저 선택된다.
- 탭을 바꾸면 그 분류의 업그레이드만 보인다.
- 유산이 바뀌면(구매·환전 등) 보유 유산과 목록이 즉시 갱신된다.

---

## 3. 업그레이드 항목

각 업그레이드는 한 줄(카드)로 표시된다.

| 요소 | 내용 |
|---|---|
| 아이콘 / 효과 설명 | 업그레이드 그림과 **현재 누적 효과** 문구 |
| 다음 단계 효과 | 사면 더해지는 효과를 **강조 색**으로 함께 표시(최대 레벨이면 생략) |
| 레벨 | 현재/최대 레벨(막대 + 숫자) |
| 비용 | 다음 레벨 구매에 드는 유산. 최대 레벨이면 "MAX" |
| 구매 버튼 | 구매를 실행한다 |
| 잠금 표시 | 선행이 필요한 경우 "해금 조건: ○○"을 덮어 표시 |

### 구매 가능 조건과 표시
- **구매 가능**: 유산이 충분하고, 최대 레벨 미만이며, 선행 업그레이드를 갖췄을 때.
- **잠금**: 선행 업그레이드가 없으면 잠금 오버레이와 함께 필요한 선행 이름을 보여 주고 구매를 막는다.
- **최대 레벨**: 비용 칸이 "MAX"로 바뀌고 구매가 막힌다.
- 구매가 성사되면 **레벨·보유 유산·항목 상태**가 즉시 갱신된다.

---

## 4. 유산 소비 확인 팝업

회차 도중 유산을 쓰는 **모든 상황에서 공통으로 뜨는 확인 팝업**이다(골드 긴급 환전, 강화 즉시 재시도, 추가 재부여, 프리미엄 능력 테스트 등).

| 요소 | 내용 |
|---|---|
| 메시지 | 무엇에 얼마를 쓰는지 안내(예: 부족 골드를 유산으로 메우기) |
| 확인 | 들 **유산 비용**을 버튼에 표시하고, 누르면 진행 |
| 취소 | 쓰지 않고 닫는다 |

- 이 팝업은 영구 업그레이드 화면이 아니라, 각 도메인의 작업 흐름 중간에 끼어든다.
- 유산이 모자라면 진행되지 않고 부족 안내가 뜬다.
