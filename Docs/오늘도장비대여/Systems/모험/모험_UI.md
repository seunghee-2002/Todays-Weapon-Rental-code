# 모험 UI

> 모험 도메인의 화면들과 **무엇을 어떻게 보여주는지**를 기획 관점에서 정리한다. 로직·규칙은 [[모험_시스템]], 도메인 지도와 코드 위치는 [[모험]] 참조.

---

## 1. 화면 흐름

```
[메인] 모험 진행 버튼 ─────────────▶ 모험 진행 화면
                                         │ 진행/완료 모험 카드 캐러셀
                                         │ 완료 카드 클릭
                                         ▼
                                   모험 결과창 ── 재료 구매 팝업
                                         │ (리플레이 보기) ▶ 모험 리플레이

[메인] 모험가 클릭 ───────────────▶ 모험 준비 화면 (3탭)
        │  탐색 · 지원 · 실행
        │  (탐색=대화/스탯 테스트 연출, 점술 화면)
        │  모험 시작 버튼
        ▼
   출발 대화 ─▶ 모험 시작 → 진행 화면에 합류
```

## 2. 모험 준비 화면 (3탭)

모험가를 클릭하면 열린다. 화면 위쪽에 공통 요소(유산 안내·진행도·탭 내비·요약 정보)가 있고, 아래는 3개 탭으로 나뉜다.

| 탭 | 이름 | 무엇을 하는가 |
|---|---|---|
| **Tab1** | 탐색 | 모험가 정보 확인 + 대화 + **스탯 테스트**. 통찰을 써서 가려진 스탯/특성을 공개한다. 보너스는 부호 포함 퍼센트(`+10%`/`-15%`)로 보여준다. |
| **Tab2** | 지원 | **무기 대여**(무기 타입 필터로 골라줌) + **아이템 배정** + 상세 보기 |
| **Tab3** | 실행 | **던전 목록** + 점술 + **모험 정보 칩** + **기분 라벨** + **모험 시작** 버튼 |

선택한 무기/아이템/던전을 누르면 **상세 패널**(무기 상세, 아이템 상세, 던전 상세, 스탯 테스트 확인)이 뜬다.

### 2-1. 던전 상세

던전을 선택하면 다음을 보여준다:
- **방어 타입** — 미공개면 가려지고, 수색/점술로 공개된다.
- **무기 부가효과 목록** — 이 던전·이 무기 조합에서 각 효과가 **지금 작동하는지/안 하는지/아직 모르는지** 세 상태로 표시한다(예: 방어구 타입 보너스는 방어 타입이 공개되기 전엔 "모름").
- **성공률 분해** — 기본 성공률 / 상성 / 스탯 효과 / 조건부 효과로 나눠 보여준다.
- **예상 탐험 시간**.
- **던전 정보 탭** — 던전 기본 정보 + 누적 통계(시도/성공/탐험도 등).

### 2-2. 모험 정보 칩 & 기분 라벨 (실행 탭)

성공률에 영향을 주는 요소들을 **칩(작은 막대 그래프)**으로 시각화하고, 종합해서 **정성적인 기분 라벨**을 보여준다.

- **칩 종류**: 호감도 / 부적 / 특성 / 던전 방어 상성 / 무기 조건 효과 / 수집 / 점술 / 던전 등급. 각 칩은 5칸짜리 막대로 유불리를 색으로 표현한다.
- **기분 라벨**: 칩들을 종합한 기대치와 변동 폭을 합쳐 20종 라벨 중 하나로 표시한다 — 예: 환희·의기양양 / 희망·설렘·조마조마 / 담담·호기심·부담 / 불안·답답 / 암울·절망.

> ⚠️ 이 "기분 라벨"은 **유저에게 모험의 유불리·변동성을 정성적으로 알려주는 표시**다. [[모험_시스템#9-기분mood-시스템|모험_시스템 §9]]의 내부 기분(비노출 랜덤)과는 **다른 개념**이다. 자세한 규칙은 `Documents/Segment바_구조와_개선안.md §8`.

## 3. 대화 · 점술

| 화면 | 내용 |
|---|---|
| **출발 대화** | 모험 출발 시 모험가와의 대화 |
| **스탯 테스트 연출** | 통찰을 쓰는 행동(스탯 테스트 등)을 할 때 게이지로 게임 시간을 진행시키고 성공/실패 결과를 보여주는 팝업 |
| **점술** | 수정구 연출 + 점술 결과 텍스트(타이프라이터 효과). 점술 운세는 모험 성공률 보정에 반영된다 |

## 4. 모험 진행 화면

진행 중·완료된 모험을 **카드 캐러셀**로 보여준다.

- **카드**: 한 모험당 1장. 현재 진행 중인 이벤트 아이콘 + 이벤트 로그 한 줄 + (완료 시) 완료 표시. 완료된 카드를 누르면 결과창으로 간다.
- **이동**: 좌우 슬라이드(한 칸은 부드럽게, 여러 칸은 즉시 점프). 아래 네비게이터로 빠르게 이동.
- 모험이 진행/완료되면 해당 카드만 실시간으로 갱신된다(화면 밖 카드는 무시).

---

## 5. 모험 결과창

확인을 누르면 실제 보상이 지급된다.

- **별점(0~3)** — 실패는 0점, 성공은 상성 평가에 따라 1~3점.
- **수수료 연출** — 모험 총 보상에서 수수료를 떼고 실수령 골드로 가는 과정을 애니메이션으로 보여준다. (수수료 구성은 [[모험_시스템#12-보상|모험_시스템 §12]])
- **결과 항목** — 평판/호감도/재료 변화를 카드로 표시(재료는 툴팁 제공).
- **재료 구매 팝업** — 결과창에서 재료를 추가 구매할 수 있다(짐꾼 특성이면 절반 가격).

---

## 6. 모험 리플레이

완료된 모험의 이벤트 흐름을 처음부터 재생하고, 마지막에 보상이 날아오는 연출을 보여준다.

---

## 7. 표시 규칙 (가림 / 비노출)

- **통찰로 가려지는 정보** — 모험가 스탯·특성, 던전 방어 타입, 그에 의존하는 무기 효과와 성공률 분해는 **통찰로 공개되기 전까지 가려진다**(상세 패널에서 "모름"으로 표시). → 통찰·정보공개 도메인.
- **내부 기분 비노출** — 모험_시스템 §9의 내부 기분 값은 어느 화면에도 표시하지 않는다. 대신 준비 화면의 정성 라벨([2-2](#2-2-모험-정보-칩--기분-라벨-실행-탭))로 변동성만 전달한다.
