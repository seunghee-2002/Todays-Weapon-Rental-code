# 모험 시스템

> 모험가에게 모험을 주선하고(무기 대여는 선택) 던전에 보낸 뒤, 자동으로 진행되는 결과를 관리하는 게임의 핵심 루프.
> 이 문서는 **모험이 어떤 규칙·확률로 굴러가는지**를 기획 관점에서 정리한다. 화면/표시는 [[모험_UI]], 도메인 전체 지도와 코드 위치는 [[모험]] 참조.
>
> 수치는 모두 **밸런싱 설정값**(모험 설정·특성 설정에서 조정 가능)이며, 본문 값은 기본값이다.

---

## 1. 한눈에 보기

```
모험가 + 무기 + 던전 선택
        │
        ▼
 모험 출발 ── 기분 1회 결정 · 아이템 효과 확정 · 점술 운세 반영 · 이벤트 시퀀스 생성
        │
        ▼
 [입장] → [중간 이벤트들…] → [보스]      ← 등급이 높을수록 이벤트가 많다
        │  (인게임 시간이 흐를 때마다 한 칸씩 진행)
        ▼
 보스 성공 → 귀환 → 완료(성공)
 전투/보스 실패 → 보호가 있으면 재시도, 없으면 후퇴 → 완료(실패)
 보스 실패 + 보호 없음 → 사망 판정
        │
        ▼
 결과 계산 (보상·평판·호감도 — 아직 지급 X)
        │
        ▼
 결과창에서 확인 클릭 → 골드·재료·평판 실제 지급
```

- **자동 진행**: 모험은 인게임 시간이 흐를 때마다 이벤트가 한 칸씩 처리된다. 플레이어 조작 없이 진행된다. (게임 시간: 1 실제 초 = 3 게임 분, 밤 21시 자동 일시정지)
- **결과 지급은 2단계**: 모험이 끝나면 결과가 계산되어 대기 목록에 쌓이고, 플레이어가 결과창에서 **확인을 눌러야 실제 보상이 지급**된다. (현재 며칠 방치 시 자동 확인되는 기능은 없음 — 수동 확인만.)

## 2. 모험 출발

모험가·무기·던전을 정하고 출발하면 모험 1건이 생성된다. 이때 한 번에 정해지는 것들:

1. 모험가가 무기를 장비하고 모험 중 상태가 된다.
2. **이벤트 시퀀스 생성** (→ [3장](#3-이벤트-시퀀스)).
3. **사망 보호 충전(보호) 초기화** — 모험 중 치명적 실패를 막아 주는 횟수. 출발 시 합산:
   - 무기의 "후퇴 방지" 효과 수치만큼
   - 생존가(Enduring) 특성이면 +1
   - 포션(아이템)으로 추가
4. **아이템 효과 확정** — 황금 부적·영예의 두루마리·해체용 단검·사망 방지·탈출 로프·신속한 신발·보물 지도 등 배정한 아이템의 효과값을 출발 시점에 고정한다. 모험 도중 인벤토리가 바뀌어도 이 값은 변하지 않는다.
5. **점술 운세 반영** — 점술가에게 본 운세가 이 모험의 성공률 보정에 더해진다(→ 통찰·점술가 도메인).
6. **기분 1회 결정** — 이 모험의 기분을 정하고 끝까지 유지한다(→ [9장](#9-기분mood-시스템)).

## 3. 이벤트 시퀀스

모험은 **이벤트들의 순서 리스트**다. 첫 칸은 항상 입장, 마지막 칸은 항상 보스이고, 그 사이를 던전의 이벤트 풀에서 뽑아 채운다.

**이벤트 개수:**
1. 던전 등급별 기본 개수 — **Common 3 / Uncommon 4 / Rare 5 / Epic 7 / Legendary 10**.
2. **퀘스트 보드 강조 던전**이면 중간 이벤트가 약 2배로 늘어난다.
3. 무기의 "이벤트 수 증가" 효과로 최대 3개까지 추가.

**중간 이벤트 채우기:**
- 던전 이벤트 풀에서 보스를 제외한 항목을 **가중치 랜덤**으로 뽑는다(이벤트마다 출현 확률이 다름).
- 무기의 "휴식·보물상자·희귀드롭 출현률 증가" 효과가 있으면 해당 이벤트가 더 자주 나온다.
- 무기의 "보상 2배" 효과가 발동하면 입장을 뺀 모든 이벤트가 **한 벌 더 복제**되어 시퀀스가 통째로 길어진다.

**마지막 이벤트:** 보스를 끝에 고정한다.

## 4. 진행 방식

인게임 시간이 흐르면(약 1시간마다) 진행 중인 모든 모험의 현재 이벤트가 한 칸씩 굴러간다.

각 이벤트는 **2단계**로 처리된다:
1. **시작** — 결과를 미리 굴려 둔다. 화면상 "진행 중"으로 표시.
2. **완료** — 정해진 소요 시간이 지나면 결과를 실제로 반영하고 다음 칸으로 넘어간다. 칸 사이 빈틈 없이 이어진다.

**이벤트 1칸 소요 시간**은 기본 1시간(이벤트별로 다를 수 있음)에 다음 보정이 곱해진다:
- 무기의 "모험 시간 단축" 효과 (최대 50%까지 단축)
- 특성 — 신속(절반), 집중(1.5배)
- 신속한 신발(아이템) 배율
- 유산의 모험 속도 보너스

> 함정 회피, 실패 후 보호/후퇴, 보스 성공 후 귀환 등은 **현재 이벤트 직후에 새 이벤트가 끼어든다**. 시퀀스는 진행 중 늘어날 수 있다.

## 5. 이벤트 종류와 판정

| 이벤트 | 판정 | 성공 시 | 실패 시 |
|---|---|---|---|
| **입장**(Entrance) | 항상 성공 | — | — |
| **전투**(Battle) | 성공률 굴림 | 골드 획득(기본 배율 1.0) | 보호 있으면 1회 막음, 없으면 후퇴 |
| **미니보스**(MiniBoss) | 성공률 굴림 | 골드 획득(배율 1.5) | 위와 동일 |
| **보스**(Boss) | 성공률 굴림 | 골드(배율 2.0) + **보스 재료** + **대성공 판정** + 귀환 | 보호 있으면 재도전, 없으면 **사망 판정** 후 후퇴 |
| **함정**(Trap) | 회피 굴림 — 무기 함정무효화 + 탈출 로프 + **모험가 DEX**를 독립 확률로 합성 | 회피 성공 | 이후 이벤트 성공률이 누적으로 -10% 깎임 |
| **보물상자**(TreasureChest) | 자동 성공 | 골드(배율 2.5) | — |
| **희귀드롭**(RareDrop) | 자동 성공 | 재료 2개(+보물지도/무기효과 보너스) | — |
| **휴식**(Rest) | 자동 성공 | 사망 보호 +1 | — |
| **보호**(Protection) | — | 보호 1 소모해 전투/미니보스 실패를 1회 무효화 | — |
| **재도전**(Retry) | — | 보호 1 소모, 보스에 다시 도전 | — |
| **후퇴**(Retreat) | 실패 확정 | — | 모험 실패로 종료 |
| **귀환**(Return) | 성공 확정 | 모험 성공으로 종료 | — |

**전투/보스 흐름 요약:**
- 전투·미니보스 실패 → 보호가 **있으면** 1회 무효화, **없으면** 후퇴(실패 종료).
- 보스 실패 → 보호 **있으면** 보스 재도전, **없으면** 사망 여부를 굴린 뒤 후퇴.

## 6. 성공률은 무엇으로 결정되는가

전투·미니보스·보스의 성패는 매번 성공률을 굴려 정한다. 성공률은 다음 요소들이 모여 만들어진다.

### 6-1. 기본 성공률

```
① 스탯 점수      = 모험가 스탯을 무기 타입별 가중치로 합산 (+ 무기의 스탯 강화 효과)
② 스탯 기반 비율  = 스탯 점수 ÷ 던전 요구 수치 (0~100%로 자름)
③ 곱 보정        = 스탯 기반 비율 × (1 + 무기-방어구 상성 + 부적 보너스)
④ 가산 보정      + 무기 조건부 효과 + 수집 보너스 + 호감도 보너스 + 특성 성공 보너스
⑤ 최종           = (③+④)를 0~100%로 자름
⑥ 특성 곱배율    × 광전사/겁쟁이 배율
```

**① 스탯 점수** — 모험가의 STR/DEX/INT/LUK을 무기 타입마다 다른 가중치로 합산한다. 예: 검은 STR 위주(STR 1.2/DEX 0.5), 마도서는 INT 위주(INT 1.5/LUK 0.5). 무기에 "스탯 강화" 계열 효과가 있으면 점수가 올라간다.

**② 던전 요구 수치** — 던전마다 정해진 기준값. 스탯 점수가 이 값에 가까울수록 기본 성공률이 높다.

**③ 무기-방어구 상성** — 던전의 방어구 타입과 무기 타입의 궁합. 기본 성공률에 **곱**으로 작용한다(잘 맞으면 크게 오르고, 상극이면 깎인다).

| 무기 \ 방어구 | 무방비 | 경갑 | 중갑 | 마법 |
|---|---|---|---|---|
| 검 Sword | +30% | -15% | -45% | +60% |
| 도끼 Axe | -45% | -30% | +60% | +45% |
| 활 Bow | -30% | +60% | -30% | +15% |
| 석궁 Crossbow | -15% | +45% | -15% | +30% |
| 지팡이 Staff | +45% | +45% | -45% | -45% |
| 마도서 Tome | +60% | +30% | -30% | -45% |
| 단검 Dagger | +45% | -30% | +30% | -15% |
| 표창 Shuriken | +30% | -45% | +45% | -15% |

> 던전 방어구 타입은 퀘스트 보드의 당일 값으로 정해지며, 공개되기 전까지 화면에서 가려진다(→ 통찰 도메인).

**④ 가산 보정 요소:**
- **무기 조건부 효과** — "특정 던전 등급 보너스", "특정 방어구 타입 보너스"가 조건에 맞을 때 더해진다.
- **수집 보너스** — 같은 던전을 10회 클리어할 때마다 +2%, 같은 무기를 20회 사용할 때마다 +1%(최대 5단계).
- **호감도 보너스** — 호감도 등급별 Max +5% / High +3% / Medium +1%.
- **특성 성공 보너스** — [10장](#10-특성trait-효과) 참조.

**⑥ 특성 곱배율** — 광전사 ×1.1, 겁쟁이 ×0.85.

### 6-2. 실제 전투 성공률

위 기본 성공률에 이벤트 단위 요소가 더 붙는다:
```
기본 성공률 × 이벤트 난이도 계수      ← 이벤트마다 다름
+ 누적 보정(점술 운세 + 함정 누적 패널티)
× 기분 배율                          ← 보스는 효과 절반
→ 0~100%로 자름
```

### 성공률에 영향을 주는 모든 요소 (요약)

| 요소 | 작용 방식 | 출처 |
|---|---|---|
| 모험가 스탯 × 무기 타입 가중 | 기반 점수 | 모험가 / 무기 타입 |
| 던전 요구 수치 | 기준값 | 던전 |
| 무기 스탯 강화 효과 | 점수 ↑ | 무기 |
| 무기-방어구 상성 | 곱 | 무기 타입 × 던전 방어구 |
| 부적(아이템) | 곱 | 아이템 |
| 무기 조건부 효과(등급/방어구) | 가산 | 무기 |
| 수집 보너스(던전·무기 숙련) | 가산 | 누적 기록 |
| 호감도 | 가산 | 모험가 |
| 특성 | 가산 + 곱 | 모험가 |
| 이벤트 난이도 | 곱 | 이벤트별 |
| 점술 운세 + 함정 누적 | 가산 | 점술가 / 함정 |
| 기분 | 곱(이벤트마다 굴림, 보스 절반) | 출발 시 결정 |

## 7. 사망

보스에서 실패하고 보호 충전도 없을 때만 사망 여부를 굴린다.
```
기본 사망률 5%
  - (무기 등급 - 던전 등급) × 3%      ← 더 좋은 무기일수록 안전
  - 무기 강화 레벨 × 0.5%
→ 0 ~ 최대 50%로 자름
× (1 - 사망 방지 부적)
× 특성 사망 배율 (광전사 ×1.1, 겁쟁이 ×0.3)
```

**사망 보호 (별개 안전장치)** — 사망 판정이 났더라도, 모험가가 **호감도 100을 달성해 얻은 1회용 사망 보호**를 가지고 있으면 사망이 무효화되고 호감도가 절반으로 줄어든다.

사망이 확정되면: 무기 손실(기본 무기 제외), 골드 0, 평판 -20, 모험가 사망 처리.

## 8. 대성공과 탐험도

보스를 성공하면 1회 대성공 판정을 한다.
1. 해당 던전의 **탐험도가 100% 차 있으면 → 무조건 대성공**(이후 탐험도 리셋).
2. 아니면 확률: `기본 5% + 행운아 특성 + 무기 "대성공" 효과`에 유산 배율을 곱한 값.

대성공 시: 재료 2배, 평판 +2, 통찰 획득.

**탐험도** — 같은 던전을 돌 때마다 누적된다(성공 +10, 실패 +5에 특성 배율 적용: 베테랑 2배, 신속·전투광은 0). 100% 도달 시 다음 클리어가 대성공으로 확정된다.

## 9. 기분(Mood) 시스템

> 동일 조건 반복 플레이에 변동을 주기 위한 **유저 비노출** 내부 랜덤. 결과창·진행·리플레이 어디에도 직접 표시하지 않는다. (모험 준비 화면의 정성적 "기분" 라벨은 이것과 별개의 통계 표시 — [[모험_UI]] 참조)

모험 출발 시 **기분 1종을 정하고**(이후 불변), 전투·함정 이벤트마다 그 기분의 분포에서 배율을 새로 굴려 성공률에 **곱**한다.

### 기분 5종과 배율

| 기분 | 배율 분포 | 평균 | 성격 |
|---|---|---|---|
| 평범(Normal) | 0.70 ~ 1.30 | 1.00 | 진폭 큼, 균등 |
| 기분파(Moody) | 0.70~0.85 또는 1.15~1.30 (각 50%) | 1.00 | 양극화 |
| 우울(Depressed) | 0.90 ~ 1.10 | 1.00 | 진폭 작음, 안정 |
| 자기과신(Overconfident) | 0.75 ~ 1.10 | 0.925 | 하향 편향 |
| 자신감(Confident) | 0.90 ~ 1.25 | 1.075 | 상향 편향 |

### 기분 배정 확률

"모험가-무기 매칭 품질"(스탯 점수를 기준값으로 정규화, 던전 무관)에 따라 정해진다.
- 매칭이 나쁠수록 **자기과신**이 잘 뜨고(최대 35%), 좋을수록 **자신감**이 잘 뜬다(최대 35%).
- 중간 구간에서는 기본 3종(평범/기분파/우울)이 두꺼워진다(나머지 확률을 균등 1/3).

### 적용 강도

- 전투·미니보스: **그대로** 적용
- 보스: **절반** 강도 (사망과 직결되므로 완화)
- 함정: **절반** 강도 (회피 확률에 곱, 탈출 로프는 영향 없음)
- 보물상자·희귀드롭·휴식·입장·귀환·재도전·보호: 미적용

> 곱셈이라 양 끝에서 비대칭이다. 낮은 성공률은 변동 폭이 작고, 높은 성공률은 깎이는 쪽이 강해 "안정 빌드"의 상한을 살짝 낮춘다.

## 12. 보상

모험 도중 골드·재료는 **누적**되다가 완료 시 결산된다.

**골드 한 칸** = `던전 기본 보상 범위에서 랜덤 × 이벤트 배율 × (1 + 골드 보너스 효과)`. 이벤트 배율: 전투 1.0 / 미니보스 1.5 / 보스 2.0 / 보물상자 2.5.

**완료 시 결산:**
- **사망**: 무기 손실, 골드 0, 평판 -20.
- **후퇴(실패)**: 누적 골드의 50%(+"실패 골드 보존" 효과, 최대 100%), 누적 재료 일부, 평판 -2, 호감도 -3.
- **성공**: 누적 골드 전액(+황금 부적 배율), 누적 재료 전부, 평판 +3 (+타입 매칭 +1, +대성공 +2, +유명인 특성, +영예의 두루마리), 호감도 +3(+타입 매칭 +2), 대성공 시 통찰 획득.

**수수료** — 플레이어 실수령액은 `모험 총 보상 × 총 수수료율`. 총 수수료율 구성:
- 기본 수수료 20% (항상)
- 무기 대여 수수료 15% (기본 무기면 0, 유산 보너스 추가)
- 상성 팁 — 무기-방어구 상성이 좋을수록 0.01↑ 5% / 0.20↑ 10% / 0.35↑ 15% / 0.50↑ 20% (유산 보너스 추가)
- 특성 수수료 — 부자(+팁), 도축업자(-20%p), 흥정꾼(랜덤)

**보스 재료 드롭:**
- 기본 수량 1~4개 + 수집가/도축업자 특성, 무기 "재료 수량"·해체용 단검 보너스.
- 던전 등급 배율(Common 1.0 ~ Legendary 5.0), 대성공이면 2배.
- **강화 재료**: 던전 등급에 맞는 강화 재료 1~4개 + 무기 "강화재료" 효과.
- **제작 재료**: 던전 드롭 재료에서 가중치 랜덤(가치가 높은 재료일수록 적게 나옴).
- **특수 재료**: 등급별 확률(Common 1% ~ Legendary 10%) + 무기 "특수재료 확률" 효과. 성공 시 1개.

**실제 지급(확인 클릭 시)** — 골드/평판/호감도/통찰 반영, 무기 반환, 성공 시 퀘스트 진행도 갱신, 통계 갱신.
