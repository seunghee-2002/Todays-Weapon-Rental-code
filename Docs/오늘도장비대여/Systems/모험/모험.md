## 1. 모험 도메인이 하는 일

> 모험가에게 모험을 주선하고(필요하면 무기도 대여해) 던전에 보내면, 인게임 시간이 흐르며 이벤트가 자동 진행되어 성공/실패/사망 결과와 보상(수수료)이 결정되는 게임의 핵심 루프.

- **모험 출발**: 모험가 + 무기 + 던전 선택 → 기분 결정, 아이템·점술 운세 반영, 이벤트 시퀀스 생성.
- **이벤트 시퀀스**: 입장 → 중간 이벤트(전투·미니보스·함정·보물·휴식·희귀드롭) → 보스. 던전 등급이 높을수록 길다.
- **성공률 판정**: 모험가 스탯 × 무기 타입, 무기-방어구 상성, 무기 효과, 호감도, 수집 보너스, 특성, 점술 운세, 기분이 종합되어 매 전투의 성패를 가른다.
- **사망 / 보호 / 후퇴**: 실패 시 보호로 막거나 후퇴. 보스 실패 + 보호 없음 → 사망 판정(호감도 100 사망 보호 1회).
- **대성공 / 탐험도**: 같은 던전을 반복하면 탐험도가 쌓여 대성공 확정권이 생긴다.
- **보상**: 골드(수수료 차감 후 지급), 재료(제작/강화/특수), 평판·호감도·통찰. 결과창 확인 시 실지급.
- **기분(Mood)**: 동일 조건 반복에 변동을 주는 비노출 랜덤.
- **표시**: 준비 화면(3탭)의 성공률 분해·정보 칩·기분 라벨, 진행 화면 카드 캐러셀, 결과창 별점·수수료 연출.

## 3. 코드 구성 (어디에 있나)

### 로직
| 영역 | 위치 | 역할 |
|---|---|---|
| 모험 매니저 | `Scripts/Systems/AdventureManager/` | 기능별로 5개 파일 분할 — 메인(시간 연동·저장), 계산(성공률·사망·보상·특성·통계), 시퀀스 생성, 이벤트 진행·판정, 기분 |
| 보조 | 같은 폴더 | 준비 화면 기분 라벨 계산 |

### 데이터
| 영역 | 위치 |
|---|---|
| 모험 진행/결과 데이터 | `Scripts/Data/RuntimeInstance/AdventureInstance.cs`, `AdventureResult.cs` |
| 밸런싱 수치 | `Scripts/Data/Config/AdventureConfig.cs`(모험), `TraitConfig.cs`(특성) |
| 화면용 설정 | `Scripts/Data/Config/AdventureInfoConfig.cs`(정보 칩·기분 라벨), `AdventureResultMotionConfig.cs`(결과 연출) |
| 상성 테이블 | `Scripts/Utils/TypeAdvantage.cs`(무기-방어구 상성, 무기-스탯 가중) |

저장: 진행 중/완료 모험, 결과, 던전 통계, 무기 도감 진행도가 회차 저장 데이터에 보관된다.

## 4. 타 도메인 연결

| 도메인 | 연결 지점 |
|---|---|
| **통찰·정보공개** | 점술 운세가 성공률 보정에 반영; 스탯/방어타입/효과 가림; 스탯 테스트·점술 화면 |
| **무기·대장장이** | 무기 효과·등급·강화가 성공률/사망/보상에 작용; 강화 재료 드롭 연동 |
| **모험가·방문자** | 특성·호감도·사망 보호; 일반 모험가 등록/해제 |
| **인벤토리·아이템** | 아이템 효과 확정·소비; 재료 구매 |
| **퀘스트** | 성공 시 진행도 갱신; 퀘스트 보드 강조 던전 이벤트 2배 |
| **평판·경제** | 결과 평판·골드 지급 |
| **유산** | 모험 속도·대성공·수수료 배율 보너스 |
| **시간** | 인게임 시간 진행에 맞춰 이벤트 처리, 밤 자동 일시정지 |

---

## 5. 확장 메모

- 모험 도메인은 **시스템 문서 분할의 파일럿**이다. 같은 틀(개요 → 규칙/수치 → 영향 요소 표 → 데이터 → 관련 코드 / 타 도메인 연결)을 다른 도메인에도 적용한다.
- 본문은 **기획 용어 + 수치** 위주로 쓰고, 코드 식별자(메서드·변수명)는 본문에서 빼며 위치는 "관련 코드"에 **파일 단위**로만 남긴다.
- 전체 도메인 로드맵: [[Systems]].
