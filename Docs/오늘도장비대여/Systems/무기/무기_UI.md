# 무기 UI (대장간)

> 무기 도메인의 화면들과 **무엇을 어떻게 보여주는지**를 기획 관점에서 정리한다. 로직·규칙은 [[무기_시스템]], 도메인 지도와 코드 위치는 [[무기]] 참조.

---

## 1. 화면 흐름

```
대장장이 등장 (인사 / 타입 요청 대화)
        │
        ▼
   대장간 화면 ── 2분할 ──┬─ 제작 패널 (레시피로 새 무기/아이템 만들기)
                          └─ 무기 패널 (보유 무기 강화/진화/재부여/분해)
                                   │
            ┌──────────────────────┼───────────────────────┐
            ▼                      ▼                        ▼
      강화 확인 → 진행 연출 → 결과   진화 확인 → 진행 연출 → 결과   재부여 확인(효과 비교)
            │                                              분해 확인 → 분해 결과
        강화석 선택(성공률 ↑)
```

---

## 2. 대장간 메인 화면

좌우 **2분할** 구조다.

- **제작 패널** — 새 무기·아이템을 만드는 곳.
  - 좌측: 레시피 종류 토글(무기/아이템) + 타입별 필터 + 레시피 목록.
  - 우측: 선택한 레시피의 상세(필요 재료·골드, 결과물).
- **무기 패널** — 보유 무기를 다루는 곳.
  - 좌측: 무기 타입 필터 + 보유 무기 목록.
  - 우측: 선택한 무기의 상세 + **강화 / 진화 / 재부여 / 분해** 버튼.

---

## 3. 작업별 화면

| 작업 | 흐름 | 보여주는 것 |
|---|---|---|
| **강화** | 확인 팝업 → 진행 연출 → 결과 팝업 | 비용·재료·성공률, (선택) 강화석으로 올라간 성공률, 어떤 효과가 최대치가 됐는지 |
| **진화** | 확인 팝업 → 진행 연출 → 결과 팝업 | 비용·성공률, 진화 후 효과 미리보기(등급 상승 + 새 효과) |
| **재부여** | 단일 팝업(실행·결과·추가 재부여 통합) | 잠금 선택, 비용, **이전 효과 ↔ 새 효과 비교 후 선택**, 횟수 소진 시 추가 재부여(유산) |
| **분해** | 확인 팝업 → 결과 팝업 | 예상 골드·재료(분해 부스트 포함), 확인 시 실제 획득량 |

- **진행 연출**: 강화·진화는 자동 실행되며 게이지 애니메이션 후 성공/실패 결과를 보여준다.
- **강화석 선택**: 강화/진화 전, 성공률을 올려 주는 소비 아이템(강화석)을 고를 수 있다.

---

## 4. 대장장이 등장 / 대화

- 대장장이가 등장하면 **인사 대화**가 나온다. 플레이어가 요청한 타입과 실제 등장 타입이 맞았는지에 따라 인사 내용이 다르다.
- **타입 요청**: 다음에 어떤 타입(비용 감소/재료 감소/성공률/분해)의 대장장이가 오면 좋을지 미리 요청할 수 있다.

---

## 5. 표시 규칙

- **작업 전 미리보기**: 강화·진화·분해·재부여 모두 실행 전에 비용·성공률·예상 결과를 보여준다.
- **혜택 반영 표시**: 대장장이 타입·강화석·유산 보너스가 반영된 값으로 비용/성공률을 표시한다.
- **재부여 비교**: 새로 뽑은 효과와 기존 효과를 나란히 보여주고 플레이어가 적용 여부를 결정한다.
