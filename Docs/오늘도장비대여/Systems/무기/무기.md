## 1. 무기 도메인이 하는 일

> 모험가에게 빌려줄 무기를 만들고 키우는 시스템. 무기의 타입·등급·부가효과가 모험 성과를 좌우하므로, 대장장이를 통해 무기를 다듬는 것이 핵심 성장 루프다.

- **무기 구성**: 타입(8종) + 등급(5단계) + 부가효과(등급별 1~5개).
- **부가효과**: 무기 등급에 따라 효과 등급이 확률적으로 정해지고, 종류는 가중 랜덤으로 뽑힌다. 성공률·보상·재료·이벤트 등에 작용.
- **대장장이**: 등장 시 타입(비용 감소/재료 감소/성공률 부스트/분해 부스트)과 등급(일반/프리미엄)이 정해져 작업에 혜택.
- **5가지 작업**:
  - 제작 — 레시피로 새 무기/아이템 생성
  - 강화 — 효과를 하나씩 최대치로 (효과 수만큼)
  - 진화 — 한 등급 위로 (효과 전체 상승 + 새 효과 추가)
  - 재부여 — 효과 다시 뽑기 (잠금 가능)
  - 분해 — 무기를 골드·재료로
- **성공률 보정**: 대장장이 부스트 + 강화석(소비 아이템) + 유산 보너스.

## 3. 코드 구성 (어디에 있나)

### 로직
| 영역 | 위치 | 역할 |
|---|---|---|
| 대장장이 작업 | `Scripts/Systems/BlacksmithManager.cs` | 제작·강화·진화·재부여·분해 실행, 대장장이 등장·혜택·비용·성공률 |
| 무기 인스턴스 | `Scripts/Data/RuntimeInstance/WeaponInstace.cs` | 효과 생성, 강화/진화/재부여 동작, 등급/레벨 관리 |
| 부가효과 인스턴스 | `Scripts/Data/RuntimeInstance/WeaponEffect.cs` | 효과 값 생성·정수/퍼센트 구분 |

### 데이터
| 영역 | 위치 |
|---|---|
| 정적 데이터 | `Scripts/Data/StaticData/` (무기, 효과, 무기 레시피, 대장장이) |
| 밸런싱 수치 | `Scripts/Data/Config/WeaponConfig.cs`(효과), `BlacksmithConfig.cs`(작업) |
| 타입 정의 | `Scripts/Data/Enums.cs` (효과/대장장이/무기 타입, 등급) |

### UI
| 영역 | 위치 |
|---|---|
| 대장간 화면 전체 | `Scripts/UI/Views/Blacksmith/` |
| 화면 ↔ 로직 중개 | `Scripts/UI/Controllers/Blacksmith/BlacksmithController.cs` |

## 4. 타 도메인 연결

| 도메인 | 연결 지점 |
|---|---|
| **모험** | 무기 효과·등급·강화 레벨이 성공률/사망/보상에 작용; 강화 재료는 모험 보상으로 드롭 |
| **인벤토리·아이템** | 무기/재료 보유·슬롯, 강화석 등 소비 아이템 |
| **경제** | 작업 골드 비용, 분해/판매 골드 |
| **유산** | 비용·성공률·재부여·분해 보너스, 강화 재시도·추가 재부여 포인트 |
| **아침 이벤트** | 떠돌이 대장장이(무료 강화/재부여) 등 무기 변형 이벤트 |
| **모험가·방문자** | 대장장이도 방문 NPC로 등장 |

## 5. 메모

- 무기 효과가 모험에서 **어떻게 작용하는지**는 중복 서술을 피해 [[모험_시스템]]에 두고, 여기서는 효과가 **어떻게 생성·성장하는지**만 다룬다.
