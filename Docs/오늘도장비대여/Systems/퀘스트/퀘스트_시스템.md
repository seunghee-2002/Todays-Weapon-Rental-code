# 퀘스트 시스템

> 이름은 "퀘스트"지만 **두 개의 다른 시스템**을 묶는다.
> - **주간 퀘스트**: 매주 주어지는 목표. 달성하면 보상, 못 하면 벌금.
> - **의뢰판(Quest Board)**: 매일 아침 갱신되는, 그날 모험을 보낼 수 있는 **던전 목록**을 고르는 시스템.
>
> 이 문서는 두 시스템의 규칙을 기획 관점에서 정리한다. 화면/표시는 [[퀘스트_UI]] 참조. 수치는 밸런싱 설정값이며 본문은 기본값이다.

---

# A. 주간 퀘스트

## 1. 구조

- **주차마다 1개**의 퀘스트가 주어진다(주차별 목표 데이터).
- 한 퀘스트에는 **여러 목표**가 있고, 각 목표는 종류 + 목표 횟수를 가진다.
- 목표 종류(5가지):

| 종류 | 달성 조건 |
|---|---|
| 모험 성공 | 모험을 N회 성공 |
| 특정 등급 대여 | 일정 등급 **이상** 무기를 빌려준 모험 성공 |
| 특정 무기 대여 | 특정 무기 타입을 빌려준 모험 성공 |
| 특정 던전 클리어 | 지정 던전을 클리어 |
| 대성공 횟수 | 대성공을 N회 |

## 2. 진행과 판정

- 진행도는 **모험 성공 시** 갱신된다(모험 결과 처리에서 각 목표 종류별로 카운트, [[모험_시스템#12-보상|모험_시스템 §12]]).
- 모든 목표를 채우면 완료 상태가 된다.
- **마감(주가 지남)** 시점에 판정:
  - **완료** → 보상 즉시 지급(골드 + 평판 + 통찰) 후 다음 주 퀘스트 발급.
  - **미완료** → 실패. **벌금**을 물고 평판이 깎인다.

## 3. 벌금

- 실패 시 벌금은 해당 주차 퀘스트에 정해진 금액(`weeklyFine`). 데이터가 없으면 기본 500골드 × 1.1^(주차−1)로 점증.
- 벌금 납부 시 골드 차감 + 평판 페널티, 그 뒤 다음 주로 진행.
- 결과창에서 1회만 처리되도록 보장(중복 차감 방지).

# B. 의뢰판 (Quest Board)

## 4. 매일 던전 선택

매일 낮에 진입하면 의뢰판이 생성된다. **그날 모험을 보낼 수 있는 던전**을 여기서 정한다.

- **풀 / 선택 수 (평판 등급별)**:

| 평판 | 풀 크기 | 선택 가능 수 |
|---|---|---|
| Bronze | 5 | 3 |
| Silver | 6 | 3 |
| Gold | 7 | 4 |
| Platinum | 8 | 5 |
| Diamond | 10 | 6 |

- 풀은 전체 던전에서 **가중치(던전별 출현 가중)**로 뽑는다.
- 각 던전에는 그날의 **방어구 타입**이 굴려진다(던전의 방어 타입 변형 가중치). 이 값은 모험 성공률·수색에 쓰인다([[통찰_시스템#5-수색꾼-던전-방어-타입|통찰_시스템 §5]]).

## 5. 새로고침 / 확정

- **새로고침**: 풀이 마음에 안 들면 다시 뽑는다. 하루 **최대 3회**, 비용 `500 + 15 × min(일차 - 1, 140)`골드(140일 이후 고정).
- **확정**: 풀에서 **선택 가능 수만큼** 던전을 골라 확정한다. 확정한 던전만 그날 모험 대상이 된다.
  - 확정 시 선택 던전 각각이 **20% 확률로 "강조 던전"**이 된다 → 모험 시 이벤트 수가 약 2배로 늘어난다([[모험_시스템#3-이벤트-시퀀스|모험_시스템 §3]]).
  - 확정과 동시에 그날 던전들의 수색 비용·시간이 미리 계산된다.

## 6. 2단계 흐름

의뢰판은 한 화면에서 두 단계로 운영된다.
1. **선택 단계**: 풀에서 던전 고르기 + 새로고침 → 확정.
2. **수색 단계**: 확정 후, 던전 방어 타입을 알아내는 수색꾼 파견([통찰] 도메인).

매일 아침 의뢰판은 초기화된다.

---

## 7. 데이터 (저장되는 것)

- **주간 퀘스트**: 현재 주차, 진행도 배열, 퀘스트 시작일, 누적 벌금.
- **의뢰판**: 그날 풀 던전, 선택 던전, 강조 던전, 확정 여부, 새로고침 횟수, 던전별 방어 타입, 수색 비용·시간.

## Related

- **모험** — 모험 성공이 주간 퀘스트 진행도를 올린다. 의뢰판에서 확정한 던전만 그날 모험 대상. 강조 던전은 이벤트 2배.
- **통찰·정보공개** — 의뢰판 확정 후 수색으로 던전 방어 타입을 공개. 방어 타입은 의뢰판이 매일 롤한다.
- **평판** — 평판 등급이 의뢰판 풀/선택 수를 결정. 퀘스트 보상/실패가 평판을 증감.
- **경제** — 퀘스트 보상/벌금, 의뢰판 새로고침 비용.
- **통찰(통찰 점수)** — 주간 퀘스트 완료 보상에 통찰 포함.
