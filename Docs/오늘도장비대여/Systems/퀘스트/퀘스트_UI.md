# 퀘스트 UI

> 주간 퀘스트와 의뢰판 화면이 어떻게 구성되는지를 기획 관점에서 정리한다. 로직·규칙은 [[퀘스트_시스템]] 참조.

---

## 1. 주간 퀘스트 화면

| 화면 | 내용 |
|---|---|
| **퀘스트 현황** | 이번 주 퀘스트의 목표 목록과 각 진행도(예: 모험 성공 2/5), 보상·마감 정보를 표시 |
| **퀘스트 결과** | 마감 시점에 자동으로 뜬다. 완료면 보상 표시, 실패면 벌금 납부 화면 |

- 진행도는 모험 성공에 따라 실시간 갱신된다.
- 실패 결과창에서는 벌금을 납부해야 다음 주로 넘어간다.

---

## 2. 의뢰판 화면

의뢰판은 **하나의 화면에서 2단계**로 운영된다. 낮에 진입하면 자동으로 열린다.

```
[선택 단계]
  풀 던전 슬롯들 표시 → 슬롯 클릭 시 던전 상세 팝업
  새로고침(최대 3회, 골드) / 선택 가능 수만큼 고르기 → 확정
        │
        ▼
[수색 단계]
  확정된 던전들에 수색꾼 파견(방어 타입 알아내기 — 통찰 도메인)
```

- **던전 상세 팝업**: 슬롯을 누르면 던전 정보(모험 준비 화면의 던전 정보와 같은 구성, 5개 섹션)를 보여준다.
- 확정하면 같은 화면이 수색 단계로 전환된다.
- 매일 아침 초기화되며, 미확정 상태로 재진입하면 선택 단계가 복원된다.

---

## 3. 표시 규칙

- **확정 전 미리보기**: 풀의 각 던전 정보·그날 방어 타입(공개 시)을 상세 팝업에서 확인.
- **강조 던전 표시**: 확정 후 이벤트 2배가 되는 강조 던전을 별도로 표시.
- **새로고침 비용·잔여 횟수**를 화면에 안내.

## 관련 코드

> 화면이 구현된 위치. **파일 단위**로만 정리한다.

| 화면 | 위치 |
|---|---|
| 주간 퀘스트 현황·결과 | `Assets/_Projects/Scripts/UI/Views/Quest/` (`QuestView`, `QuestResultView`) |
| 의뢰판(2단계)·던전 상세 | `Assets/_Projects/Scripts/UI/Views/QuestBoard/` (`QuestBoardView`, `DungeonDetailPopup`) |
| 화면 ↔ 로직 중개 | `Assets/_Projects/Scripts/UI/Controllers/QuestBoard/`, 퀘스트 결과 Controller |
