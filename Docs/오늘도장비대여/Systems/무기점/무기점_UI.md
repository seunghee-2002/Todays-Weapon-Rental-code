# 무기점 UI

> 상인이 내놓은 무기 매물을 **둘러보고, 상세를 확인하고, 사거나 목록을 새로 뽑는** 화면을 기획 관점에서 정리한다. 시스템 규칙은 [[무기점_시스템]] 참조.

---

## 1. 상점 메인 화면

상인과 대화한 뒤 열리는 매물 진열 화면이다. 머무는 동안 게임 시간이 멈춘다.

| 영역 | 내용 |
|---|---|
| 보유 골드 / 유산 | 현재 골드와 유산 포인트 |
| 새로고침 | 새로고침 버튼 + 비용 + 사용 횟수(현재/최대) |
| 매물 격자 | 진열된 무기 카드를 격자로 나열(**등급 높은 순**) |
| 닫기 | 상점을 나간다 |

- 카드를 누르면 **상세 패널**이 열린다(아래 2장).
- 골드·유산이 바뀌면 표시가 즉시 갱신된다.
- 새로고침 사용 횟수를 다 썼거나 골드가 부족하면 새로고침 버튼이 비활성화된다.
- 나가려 하면 확인 문구로 한 번 더 묻는다.

### 무기 카드

| 요소 | 내용 |
|---|---|
| 아이콘 / 이름 | 무기 그림과 이름 |
| 타입 아이콘 | 무기 유형 표시 |
| 등급 표시 | 등급별 배경색과 테두리 |

---

## 2. 무기 상세 패널

카드를 누르면 열린다. 사거나 취소하면 닫힌다(상세 패널은 게임 시간을 멈추지 않는다).

### 표시 정보

| 요소 | 내용 |
|---|---|
| 아이콘 / 이름 | 무기 그림과 이름(등급색) |
| 등급 테두리 / 타입 | 등급 프레임과 무기 유형 |
| 가격 | 구매 가격 |
| 획득 가능 부가효과 수 | 이 무기가 가질 부가효과 개수(등급에 따라 1~5개) |
| 부가효과 범위 목록 | 부가효과 종류별로 **이 등급에서 나올 수 있는 수치 범위**(최소~최대)를 줄별로 |

- 부가효과 범위는 **개별 매물의 실제 효과가 아니라**, 그 등급 무기가 가질 수 있는 효과의 폭을 알려 주는 **미리보기**다.

### 등급별 효과 범위

무기 등급마다 부가효과가 어느 등급 폭까지 나올 수 있는지가 다르다(높은 등급일수록 더 강한 효과까지 가능).

| 무기 등급 | 효과 등급 범위 |
|---|---|
| Common | Common ~ Rare |
| Uncommon | Common ~ Epic |
| Rare | Common ~ Legendary |
| Epic | Uncommon ~ Legendary |
| Legendary | Rare ~ Legendary |

> 부가효과 종류와 무기 등급별 효과 개수의 규칙은 [[무기_시스템]]에서 다룬다.

### 조작

| 요소 | 기능 |
|---|---|
| 구매 | 골드를 내고 무기를 산다. 누르면 골드가 모자랄 경우 골드 확보 흐름으로 이어진다 |
| 취소 | 패널을 닫고 매물 격자로 돌아간다 |

---

## 3. 공통 표시 규칙

- 매물을 사면 그 카드가 격자에서 **즉시 사라진다**.
- 새로고침하면 격자 전체가 새 매물로 **교체**된다.
- 골드 변화가 헤더와 구매 버튼에 즉시 반영된다.
