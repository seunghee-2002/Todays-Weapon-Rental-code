# NPC 등장 확률 총정리

> 길드에 나타나는 모든 방문 NPC의 **등장 조건과 확률**을 한곳에 모은 레퍼런스. 각 NPC의 상세 규칙은 해당 도메인 문서를 참조하고, 여기서는 **"언제, 얼마의 확률로 오는가"**만 비교한다.
> 수치는 모두 밸런싱 설정값이며 본문은 기본값이다. 코드가 바뀌면 이 문서도 함께 갱신한다.

방문 NPC는 크게 **아침에 오는 NPC**(무기상점·대장장이·이벤트 NPC·투자자 결과)와 **낮에 오는 NPC**(모험가), 그리고 **특정 상황에서 튀어나오는 NPC**(사망 이벤트)로 나뉜다.

---

## 1. 무기 상인 (WeaponShop) — 아침

**언제**: 아침 페이즈 진입 시 하루 한 번 판정.

- **고정 등장일**: **1일차(튜토리얼 상점)·3일차·8일차**는 무조건 등장.
- **9일차부터 누적 확률**로 등장:
  - 마지막으로 온 날 **다음날**에 시작 확률부터 시작해, 오지 않은 하루마다 **+10%p** 누적. 온 날 다시 초기화.
  - 시작 확률 = **10% + (평판 등급 × 7.5%p)**
  - 최종 확률은 100%에서 상한.

| 평판 등급 | 시작 확률(등장 다음날) | 이후 하루당 |
|---|---|---|
| Bronze | 10% | +10%p |
| Silver | 17.5% | +10%p |
| Gold | 25% | +10%p |
| Platinum | 32.5% | +10%p |
| Diamond | 40% | +10%p |

> 예) 평판 Bronze에서 8일차에 온 뒤 계속 안 오면 9일 10% → 10일 20% → … → 18일 100%.

상세: [[무기점_시스템]]

## 2. 대장장이 (Blacksmith) — 아침

**언제**: **매일 아침 무조건 1명 등장**(등장 확률 판정 없음). 어떤 대장장이가 오는지가 확률로 정해진다.

### 타입 결정
- 플레이어가 지난번에 **요청한 타입**이 있으면 **50%**(`requestedTypeBonus`) 확률로 그 타입이 온다.
- 아니면 존재하는 타입 중 **균등 랜덤**.

### 프리미엄 여부
- **20%**(`premiumSpawnChance`) 확률로 프리미엄 대장장이(강화된 혜택)로 등장.

> 즉 대장장이는 "올지 말지"가 아니라 "**어떤 타입·등급으로 오는지**"만 확률이다.

상세: [[무기_시스템]]

## 3. 이벤트 NPC (EventNPC) — 아침

**언제**: 아침 페이즈 진입 시 판정.

- **유산 보장**: 아침 이벤트 보장 유산을 보유하면 **7일차·14일차…(Day % 7 == 0)**에는 확정 등장.
- 그 외에는 **평판 등급별 확률**로 등장:

| 평판 등급 | 이벤트 발생 확률 |
|---|---|
| Bronze | 5% |
| Silver | 10% |
| Gold | 10% |
| Platinum | 15% |
| Diamond | 20% |

- 등장이 확정되면 나타날 이벤트 종류는 별도 추첨(아침 이벤트 목록 참조).

상세: [[아침이벤트_시스템]] · [[평판]]

## 4. 투자자 결과 NPC (InvestorResult) — 아침

**언제**: "수상한 투자자" 이벤트에 투자한 **다음 날 아침**, 투자가 성공(반환 골드 > 0)일 때만 등장. 확률 판정 없음(조건부 확정).

상세: [[아침이벤트_시스템]]

## 5. 모험가 (Adventurer) — 낮

낮 페이즈 동안 **일정 간격마다** 모험가가 방문한다. 등장 간격과 누가 오는지가 확률로 정해진다.

### 등장 간격 (평판 등급별)
평판이 높을수록 손님이 자주 온다. (게임 시간 초 단위, 실제로는 Config 최소/최대로 한 번 더 클램프)

| 평판 등급 | 스폰 간격(초) |
|---|---|
| Bronze | 35~45 |
| Silver | 30~40 |
| Gold | 25~35 |
| Platinum | 20~30 |
| Diamond | 15~25 |

### 낮 진입 시 첫 손님
1. **단골 보장 유산** 보유 + **7일차·14일차…(Day % 7 == 0)**이면 집에 있는 네임드 중 애정도 최고를 **확정 방문**.
2. 아니면 **재방문 판정** → 성공 시 단골(집에 있는 네임드) 재방문, 실패 시 신규 스폰.

### 재방문 판정
- 기본 재방문 확률 **50%**, 호감도 Max 달성 단골 **1명당 +20%p**, 최대 **90%** 상한.
- 후보는 호감도 **50 이상**이고 집에 있는 단골 중, 마지막 방문 후 **3~6일**(랜덤) 지난 자.

### 신규 스폰 시 네임드 vs 일반
- 네임드 가중치 **1**(+ 유산 보너스), 일반 가중치 **5** → 대부분 일반 모험가.
- 재방문 후보 가중치: 호감도 Max 단골 **0.7**, 그 외 **0.3**.

상세: [[모험가_시스템]]

## 6. 사망 이벤트 NPC (DeadEvent) — 상황 발동

**언제**: 낮에 **죽은 네임드 모험가**가 방문 후보로 뽑혔을 때 발동(정해진 주기 없음).

| 결과 | 확률 | 내용 |
|---|---|---|
| 같은 분류 재선택 | 70% | 같은 분류(네임드/일반) 내 살아있는 모험가로 대체. 없으면 청소로 폴백 |
| 청소 이벤트 (NoVisitor) | 15% | 사망을 알리는 청소 NPC |
| 부활 제안 (ReviveOffer) | 10% | 골드/대가로 부활 제안 |
| 기적의 생환 (MiracleRevive) | 5% | 죽었던 모험가가 살아 돌아옴 |

### 집에 아무도 없을 때 (별도 분기)
- 네임드를 부르려는데 살아있는 네임드가 모두 모험/방문 중이면, **70%**로 재선택 재시도, **30%**로 "집에 아무도 없음" → 청소(NoVisitor) NPC.

상세: [[모험가_시스템]]
