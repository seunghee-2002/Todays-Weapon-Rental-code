# 기타 (이펙트·외형·씬·카메라)

> 특정 게임플레이 도메인에 속하지 않고 **게임 전반을 떠받치는 보조 시스템**들을 모았다. 시각 연출(파티클), 모험가 외형 생성, 씬 전환, 카메라 줌이 여기에 들어간다.
> 이 문서는 각 보조 시스템이 무엇을 하고 어떤 규칙으로 도는지를 기획 관점에서 간략히 정리한다(서로 독립적이라 한 문서에 묶되 절로 나눈다). 수치는 모두 밸런싱 설정값이며 본문은 기본값이다.
>
> **사운드(BGM·효과음·BGM 변경 기능)는 분량이 커져 별도 문서로 분리했다** -> [[사운드]]

---

## 1. 시각 이펙트 (연출)

파티클과 효과음을 **함께** 터뜨려 순간의 피드백을 준다.

| 연출 | 쓰임 |
|---|---|
| 네임드 모험가 등장 | 특별한 모험가가 올 때 등장 연출 |
| 강화·진화 성공 / 실패 | 대장장이 작업 결과 연출 |
| 모험 리플레이 노드 | 모험 다시보기에서 사건 지점마다 연출 |

- 파티클은 대상에 붙여 잠깐 재생되고 **수명이 지나면 자동 정리**된다(필요 시 즉시 중단·전체 중단도 가능).
- **이 "이펙트"는 시각 연출(파티클)을 말하며, 무기의 부가효과와는 무관하다.** 무기 효과는 [[무기_시스템]]에서 다룬다.

---

## 2. 모험가 외형 생성

일반 모험가가 등장할 때 **얼굴·복장을 무작위로 조합**해 만든다(직업·성별에 맞춰).

- **항상 들어가는 파츠**: 피부·눈·입·눈썹·머리·상의·하의·장갑(성별·직업별 후보 풀에서 무작위로 고른다).
- **확률로 들어가는 파츠**:

| 파츠 | 장착 규칙 |
|---|---|
| 투구 | 힘(STR) 직업 80%, 그 외 50% |
| 등 장식(망토 등) | 민첩(DEX) 80%, 힘(STR) 10%, 그 외 30% |
| 신발 | 보통 착용하되, 행운(LUK) 직업은 80% 확률로 **맨발** |
| 수염 | 남성만 — 지능(INT) 80%, 그 외 20% (여성은 없음) |
| 안경 | 성별·직업 무관 10% |

- **색상**: 피부·머리색을 팔레트에서 무작위로 고르고, 눈썹은 머리색보다 조금 어둡게, 수염은 머리색과 같게 맞춘다.
- **네임드(고정 캐릭터)**는 무작위 생성 대신 **미리 정해 둔 외형**을 그대로 쓴다.

> 외형 파츠 풀과 색상 팔레트는 외형 생성 데이터(SO)에 들어 있다. 직업·성별·네임드 등 모험가 자체 규칙은 [[모험가_시스템]]에서 다룬다.

## 3. 씬 전환

게임은 **메인 메뉴 씬**과 **인게임 씬** 두 개로 나뉜다.

- 메인 메뉴 ↔ 인게임을 오가고, 필요 시 **현재 씬을 다시 불러온다**(예: 데이터 복원·튜토리얼 미완료 초기화).
- 에디터에서 인게임 씬을 직접 실행하면 **자동으로 메인 메뉴로** 보내, 항상 정상 흐름으로 시작하게 한다.

---

## 4. 카메라 줌

모험가와 상호작용할 때처럼 **특정 위치로 확대**했다가 되돌린다.

- 지정한 대상 쪽으로 부드럽게 **줌인**하고, 끝나면 원래 자리·배율로 **줌아웃**한다.
- **줌인 동안에는 상단 상시 UI를 숨겨** 장면에 집중하게 한다.
- 줌 연출이 진행 중인지 알 수 있어, 겹쳐 실행되지 않게 막는다.
