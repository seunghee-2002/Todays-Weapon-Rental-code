# 모험가·방문자 시스템

> 길드에 찾아오는 방문자(모험가·무기상·대장장이·이벤트 NPC)를 스폰하고 관리하는 시스템. 그중 **모험가**는 스탯·특성·호감도를 가지며 모험의 주체가 되는 핵심 손님이다.
> 이 문서는 방문자가 어떤 규칙으로 등장·관리되는지를 기획 관점에서 정리한다. 화면/표시는 [[모험가_UI]] 참조.
>
> 수치는 모두 밸런싱 설정값이며 본문은 기본값이다. 모험가의 특성이 모험에 미치는 영향은 [[모험_시스템#10-특성trait-효과|모험_시스템 §10]]에서 다룬다.

---

## 1. 방문자 종류와 공통 규칙

길드에는 네 종류의 방문자가 찾아온다.

| 방문자 | 역할 | 체류 시간 |
|---|---|---|
| 모험가 | 무기를 빌려 모험을 떠남 | 45초 |
| 무기상 | 무기 구매([무기점] 도메인) | 60초 |
| 대장장이 | 무기 작업([무기] 도메인) | 60초 |
| 이벤트 NPC | 아침 이벤트([아침 이벤트] 도메인) | 90초 |

> 체류 시간은 **게임 시간 초** 단위.

**공통 규칙:**
- 방문자는 스폰 지점에서 등장해 **인터랙션 포인트**(제한된 자리)에 자리잡고, 자리가 없으면 대기열에서 기다린다.
- 체류 시간이 다 되면 떠난다. 떠나기 **10초 전** 경고 표시.
- 클릭하면 종류별 화면이 열린다(모험가→모험 준비, 무기상→무기점, 대장장이→대장간, 이벤트→아침 이벤트).

**하루의 흐름과 방문자:**
- **아침**: 이벤트 NPC·무기상·대장장이 등 NPC가 등장. 그날 방문할 **일반 모험가 풀(기본 8명)**을 미리 생성.
- **낮**: 모험가 스폰 시작. 평판에 따른 간격으로 계속 등장.
- 아침에 할 일이 끝나면 "아침 건너뛰기"를 안내해 낮으로 넘어갈 수 있다.

---

## 2. 모험가 스폰

낮 동안 일정 간격으로 모험가가 찾아온다.

**스폰 간격**: 평판 등급별 간격(→ [평판] 도메인)에서 랜덤. 간격이 찰 때마다 한 명씩 등장.

**누가 오는가 — 매 스폰마다:**
1. **재방문 판정 먼저** — 조건을 만족하면 단골(네임드)이 다시 찾아온다.
2. 아니면 **신규 스폰** — 네임드 : 일반 = **1 : 5** 가중치로 결정.
   - **네임드**: 집에 있는(모험/방문 중이 아닌) 살아있는 네임드 중에서 선택. 없으면 일반으로 대체하거나 "집에 아무도 없음" 이벤트.
   - **일반**: 아침에 만들어 둔 일반 모험가 풀에서 순서대로 소비(소진 시 즉석 생성).

**재방문(단골) 조건:**
- 호감도 50 이상이고 집에 있는 네임드가 대상.
- 마지막 방문 후 **3~6일** 경과.
- 확률: 기본 50% + 호감도 Max 단골 1명당 +20% (최대 90%). 호감도 Max 단골은 더 자주 온다.

**단골 보장(유산 업그레이드)**: 해당 유산을 가지면 **7일마다** 호감도 높은 네임드가 확정 방문.

## 3. 모험가의 구성

### 네임드 vs 일반

| | 네임드 | 일반 |
|---|---|---|
| 정체성 | 고정된 고유 캐릭터 | 매일 생성되는 익명 손님 |
| 특성 | 데이터에 고정 | 랜덤 |
| 스탯 | 데이터 범위에서 랜덤 | 데이터 범위에서 랜덤 |
| 정보 자동 공개 | 없음(직접 공개해야 함) | 통찰 임계값에 따라 자동 공개 |
| 재방문/단골 | 가능 | 없음(그날 한정) |

### 스탯

**STR / DEX / INT / LUK** 4종. 넷 모두 무기 타입별 가중치로 합산돼 모험 성공률에 반영된다([[모험_시스템#6-성공률은-무엇으로-결정되는가|모험_시스템 §6]]).

그 위에 스탯별 고유 역할이 있다. 각 보정은 공통 지수 곡선(`StatCurve`)을 써서 저스탯 구간은 거의 0이고 고스탯에서만 급격히 커진다.

| 스탯 | 고유 역할 |
|---|---|
| STR | 사망이 확정된 뒤 1회 재굴림으로 생환한다(전투 실패 자체는 뒤집지 않음) |
| DEX | 함정 회피 확률에 가산된다(무기 효과·탈출 로프와 독립 합성). 회피 실패는 이후 이벤트 성공률을 누적으로 깎으므로 체감이 크다 |
| INT | **이미 공개된 경우에만** 나머지 정보 테스트(스탯/특성/종합)의 성공률을 올린다. INT 테스트 자신에는 적용되지 않는다 |
| LUK | 점술가 행운 판정 ([[통찰_시스템#6-점술가-모험-예감--행운|통찰_시스템 §6]]) |

일반 모험가는 **성별로 스탯 범위가 반전**돼 있다 - 남성은 STR/LUK 30~100 · DEX/INT 0~70, 여성은 그 반대. 4스탯 전체로는 대칭이다.

### 특성

모험가마다 성격(특성) 1개. 모험의 성공률·보상·소요 시간 등에 다양하게 작용한다(전체 16종과 효과는 [[모험_시스템#10-특성trait-효과|모험_시스템 §10]]). 네임드는 고정, 일반은 생성 시 랜덤.

### 기본 무기

무기를 빌려주지 않아도 모험가는 **자기 기본 무기**로 떠날 수 있다. 모험가 스탯에 맞춰 생성된다: **70% 최적 타입 / 20% 차선 타입 / 10% 무작위**.

### 외형

최고 스탯에 따른 직업 유형 + 성별로 외형을 생성한다(네임드는 지정 외형이 있으면 그것을 사용).

## 4. 호감도

- **범위 0~100**, 레벨 4단계: Low(~25) / Medium(~50) / High(~75) / Max(76~).
- 모험 결과로 오르내린다(성공 +, 실패/사망 −). [[모험_시스템#12-보상|모험_시스템 §12]]
- **호감도 100 달성 시**:
  - **1회용 사망 보호** 부여 — 다음 사망을 한 번 막아 준다([[모험_시스템#7-사망|모험_시스템 §7]]).
  - 재방문(단골) 확률·가중치 우대, 체류 시간 증가.
- 호감도 레벨은 모험 성공률 보너스에도 작용(Max +5% 등).

---

## 5. 사망과 부활

- 모험 중 사망하면 모험가는 죽은 상태가 되고(네임드는 더는 자동 방문 안 함), 빌린 무기를 잃는다.
- **부활 이벤트**: 특정 조건에서 죽은 모험가를 되살리는 제안/기적 부활 이벤트가 발생할 수 있다.
- **방문자 없음 이벤트**: 집에 부를 모험가가 없을 때 안내 이벤트가 뜬다.

---

## 6. 데이터 (저장되는 것)

- **모험가 정적 데이터**: 이름·네임드 여부·스탯 범위·특성·성별·외형.
- **모험가 인스턴스**: 확정 스탯, 특성, 호감도, 생존/방문/모험 상태, 공개 상태(스탯/특성/무기 힌트), 기본 무기, 통계(방문/성공/마지막 방문일 등).
- **방문자 상태**: 현재 길드에 있는 방문자들의 종류·남은 체류 시간 등(저장/복원).

| 방문자 설정 | 모험가 스폰 간격, 종류별 체류 시간, 경고 임계, 일반 모험가 일일 풀 크기·스탯 범위, 네임드:일반 스폰 가중치, 재방문 확률·대기 일수·호감도 조건, 호감도 Max 우대 |
| (평판 설정) | 평판 등급별 스폰 간격(→ [평판] 도메인) |
