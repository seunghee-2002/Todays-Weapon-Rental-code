# 모험가·방문자 UI

> 방문자가 화면에 어떻게 나타나고 상호작용하는지를 기획 관점에서 정리한다. 로직·규칙은 [[모험가_시스템]] 참조.
>
> 모험가를 클릭한 뒤 열리는 **모험 준비 화면**의 상세는 [[모험_UI]]에서 다룬다.

---

## 1. 화면 속 방문자

방문자는 길드 화면에 **캐릭터 NPC로 직접 등장**한다.

- **등장/퇴장**: 스폰 지점에서 걸어 들어와 자리(인터랙션 포인트)에 서고, 체류 시간이 끝나면 퇴장 연출과 함께 사라진다.
- **체류 타이머**: 각 방문자에게 남은 체류 시간이 표시된다.
- **퇴장 경고**: 떠나기 10초 전 경고 표시(놓치지 않도록 강조).
- **외형**: 모험가는 스탯/성별에 맞는 외형으로 그려진다(네임드는 지정 외형).
- 한 방문자와 상호작용 중에는 다른 방문자가 흐려질 수 있다.

---

## 2. 클릭 → 종류별 화면

방문자를 클릭하면 종류에 따라 다른 화면이 열린다.

| 방문자 | 열리는 화면 |
|---|---|
| 모험가 | 모험 준비 화면([[모험_UI]]) |
| 무기상 | 무기점([무기점] 도메인) |
| 대장장이 | 대장간([[무기_UI]]) |
| 이벤트 NPC | 아침 이벤트([아침 이벤트] 도메인) |

---

## 3. 방문자 목록 / 사이드 버튼

- 화면 측면에 현재 방문 중인 손님을 빠르게 고를 수 있는 방문자 버튼이 제공된다.
- 모험가 버튼에는 통찰로 공개된 정보(이름/일부 스탯 등)가 반영될 수 있다.

---

## 4. 모험가 정보 표시 (가림 규칙)

- 모험가의 스탯·특성·무기 타입은 기본적으로 가려져 있고, **통찰로 공개된 만큼만** 보인다(자동 공개 / 2차 대화). 자세한 규칙은 [[통찰_UI]]·[[모험_UI#2-모험-준비-화면-3탭|모험_UI §2]].
- 일반 모험가는 통찰 임계값에 따라 자동으로 일부 정보가 열리고, 네임드는 직접 공개해야 한다.

---

## 5. 이벤트 팝업

- **방문자 없음**: 부를 모험가가 집에 없을 때 안내 팝업.
- **부활 제안 / 기적 부활**: 죽은 모험가를 되살리는 이벤트 팝업.
- **아침 건너뛰기**: 아침 할 일이 끝났을 때 낮으로 넘어가도록 안내하는 팝업.

---
