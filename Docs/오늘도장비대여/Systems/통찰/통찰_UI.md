# 통찰·정보공개 UI

> 통찰 도메인의 화면들과 **무엇을 어떻게 보여주는지**를 기획 관점에서 정리한다. 로직·규칙은 [[통찰_시스템]], 도메인 지도와 코드 위치는 [[통찰]] 참조.
>
> 통찰은 **전용 화면 하나로 모이지 않고** 여러 화면에 "정보 공개"로 녹아든다. 모험 준비 화면의 공개 표시는 [[모험_UI]]에서도 다룬다.

---

## 1. 정보 공개가 나타나는 곳

| 화면 | 통찰이 하는 일 |
|---|---|
| 모험 준비 — 탐색 탭 | 가려진 스탯/특성을 2차 대화로 공개 (스탯 테스트) |
| 모험 준비 — 던전 상세 | 방어 타입(수색 전 가림), 성공률 분해(임계값), 예상 소요 시간(임계값) |
| 모험 준비 — 실행 탭 | 점술(SeerView)로 예감/행운 확인 |
| 수색 현황 / 결과 | 던전 방어 타입 알아내기 |
| 암시장(무기 상세) | 통찰에 따라 무기 효과 일부만 공개 |
| 모험 결과창 | 대성공 시 통찰 획득 표시 |

---

## 2. 정보 공개 표시 (모험 준비 화면)

자세한 화면 구성은 [[모험_UI#2-모험-준비-화면-3탭|모험_UI §2]]. 통찰 관점 요점:

- **가려진 정보**: 공개되지 않은 스탯/특성/방어 타입은 가림 처리되고, 그에 의존하는 무기 효과는 "모름"으로 표시된다.
- **2차 대화(스탯 테스트)**: 통찰을 활용한 대화 행동. 소요 시간과 성공 확률이 안내되고, 게이지 연출 후 성공/실패를 보여준다(통찰_시스템 §4).
- **성공률 분해**: 통찰 80+ 또는 (공개 스탯 3개 이상 + 방어 타입 공개) 조건을 만족해야 보인다.

---

## 3. 점술 화면 (SeerView)

- 모험 준비 화면에서 호출되는 점술 화면. 수정구 연출 + 점술 결과 텍스트(타이프라이터).
- 결과는 **추상 예감(암담~대길조) + 행운(흉~대길)**을 합친 문구로 표시된다.
- 수정구를 직접 건드리면 이스터에그 점술(LUK 무시)이 나온다.
- 자세한 화면 흐름은 [[모험_UI#3-대화--점술|모험_UI §3]].

---

## 4. 수색 현황 / 결과

| 화면 | 내용 |
|---|---|
| **수색 현황** | 진행 중인 수색 임무를 **실시간 타이머**로 표시, 미확인 결과는 배지로 알림. 게임 시간을 멈추지 않아 다른 일을 하며 기다릴 수 있다. |
| **수색 결과** | 완료된(미확인) 결과를 순차로 보여주고, 공개된 방어 타입 아이콘을 강조한다. 확인을 누르면 방어 타입이 던전 정보에 반영된다. |

- 사이드바의 수색 버튼은 진행 중 임무나 미확인 결과가 있을 때 표시된다.

---

## 5. 그 밖의 표시

- **암시장 무기 상세**: 통찰 수준에 따라 무기 부가효과를 일부만 보여주고 나머지는 잠금 이미지로 가린다(통찰 20당 1개씩 공개).
- **모험 결과창**: 대성공 시 획득한 통찰을 결과 항목으로 표시.
- **유산 화면**: "시작 통찰" 같은 통찰 관련 영구 업그레이드 항목.
