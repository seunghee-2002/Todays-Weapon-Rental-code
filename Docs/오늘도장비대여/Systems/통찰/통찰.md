## 1. 통찰 도메인이 하는 일

> 모험가·던전 정보는 기본적으로 가려져 있고, 플레이어는 통찰을 쌓아 정보를 열어 본 뒤 더 나은 선택으로 모험을 보낸다. 정보의 비대칭과 그 해소가 이 도메인의 핵심이다.

- **통찰 점수(0~100)**: 대성공·평판 돌파로 획득. 높을수록 정보가 더 잘 열린다.
- **자동 공개**: 일반 모험가 스탯/평균/특성이 통찰 임계값에 따라 저절로 열림(네임드 제외).
- **2차 대화**: 시간 + 성공 확률로 스탯·특성·무기 힌트를 능동 공개.
- **수색꾼**: 골드 + 대기 시간으로 던전 방어 타입을 알아냄.
- **점술가**: 골드로 모험 예감(추상 5단계) + 행운(성공률 보정)을 봄.
- **기타**: 예상 소요 시간, 성공률 분해, 암시장 효과를 임계값/단계로 공개.

## 4. 타 도메인 연결

| 도메인 | 연결 지점 |
|---|---|
| **모험** | 점술 행운이 성공률 보정으로; 공개 정보가 준비 화면 표시·성공률 분해 노출을 좌우 |
| **모험가·방문자** | 스탯·특성·무기 힌트 공개 상태 관리 |
| **퀘스트 보드** | 던전 방어 타입(그날 값)을 수색으로 공개 |
| **평판** | 평판 단계 돌파 시 통찰 획득 |
| **경제** | 수색·점술 비용 |
| **유산** | 시작 통찰 등 영구 업그레이드 |
| **무기점/인벤토리** | 암시장 무기 효과 통찰 공개 |

---

## 5. 메모

- 점술의 두 축(추상 예감 / 행운)은 분리되어 있고, **성공률에 실제로 작용하는 것은 행운뿐**이다. 추상 예감은 불확실한 "느낌"(60% 적중).
- 전체 도메인 로드맵: [[Systems]].
