# 통찰·정보공개 시스템

> 모험가와 던전의 정보는 기본적으로 **가려져 있고**, 플레이어는 **통찰**을 쌓아 정보를 열어 본 뒤 더 나은 판단으로 모험을 보낸다. 정보를 여는 수단은 **자동 공개 · 2차 대화 · 수색꾼 · 점술가** 네 가지다.
> 이 문서는 정보가 어떤 규칙으로 공개되는지를 기획 관점에서 정리한다. 화면/표시는 [[통찰_UI]], 도메인 지도와 코드 위치는 [[통찰]] 참조.
>
> 수치는 모두 밸런싱 설정값이며 본문은 기본값이다. (구 기획서 `Completed/통찰_정보공개_체계.md`·`점술가_개편.md`를 현재 코드 기준으로 통합)

---

## 1. 통찰 점수

- **범위**: 0 ~ 100. 회차 저장 데이터에 보관.
- **획득**:
  - 모험 **대성공** 시 +1
  - **평판 단계 돌파** 시 단계별 보너스
- **역할**: 통찰이 높을수록 정보가 **자동으로** 더 많이 열리고, 능동적 공개의 **성공률이 오르고 비용·시간이 줄어든다**. 통찰 자체는 공개에 소모되지 않는 누적 지표다(단, 일부 표시는 임계값을 넘어야 보인다).

---

## 2. 정보 공개 경로 한눈에

| 경로 | 여는 정보 | 비용 | 통찰의 영향 |
|---|---|---|---|
| 자동 공개 | 일반 모험가 스탯/평균/특성 | 무료 | 임계값 넘으면 자동으로 열림 |
| 2차 대화 | 스탯·전체 스탯·특성·무기 타입 힌트 | **게임 내 시간** + 성공 확률 | 시간 ↓, 성공률 ↑ |
| 수색꾼 | 던전 방어 타입 | 골드 + 대기 시간 | 대기 시간 ↓ |
| 점술가 | 모험 성패 예감(추상) + 행운(성공률 보정) | 골드 | 없음(LUK 스탯 기반) |
| 기타 | 예상 소요 시간, 성공률 분해, 암시장 효과 | 무료(임계값) | 임계값 넘으면 열림 |

> **네임드 모험가는 자동 공개 대상이 아니다.** 정보를 2차 대화로 직접 열어야 한다.

## 3. 자동 공개 (일반 모험가)

통찰 점수가 임계값을 넘으면 일반 모험가의 정보가 저절로 보인다.

| 통찰 | 자동으로 열리는 것 |
|---|---|
| 15+ | 스탯 1개 |
| 30+ | 스탯 평균 표시 |
| 50+ | 스탯 2개 |
| 70+ | 최고 스탯(종류+수치) |
| 80+ | 성공률 분해 + 특성 |

---

## 4. 2차 대화 (능동적 공개)

모험 준비 중 모험가와 대화해 정보를 연다. 통찰을 소모하는 게 아니라 **게임 내 시간**을 쓰고 **성공 확률**을 굴린다.

- **시작 조건**: 소요 시간이 그날 21시까지 남은 시간 이내이고, 최대 180분 이내일 것.
- **개별 스탯 공개**
  - 소요 시간(통찰 구간별): 기본 60분 → 30+ 42분 → 50+ 24분 → 70+ 12분.
  - 성공 확률: `70% + 통찰×0.4% − 이미 공개한 스탯 수 × (30% − 통찰×0.2%)`. (많이 열수록 어려워지지만 통찰이 높으면 패널티가 줄어든다)
- **전체 스탯 한 번에**: 시간 2배. 성공 확률은 개별 스탯과 **다른 공식**을 쓴다: `35% + 통찰×0.65% − 이미 공개한 스탯 수 × (30% − 통찰×0.2%)`.
  - 통찰 0에서 개별 70% vs 전체 35%로 시작해, 통찰이 오를수록 격차가 좁혀지다 100에서 둘 다 100%가 된다. **초반엔 시간 2배를 걸고 절반 확률에 거는 도박, 후반엔 효율적인 정답**이 되도록 의도한 곡선이다.
- **특성 공개**: 성공 확률 `50% + 통찰×0.8%`.
- **무기 타입 힌트**: 항상 100% 성공(통찰 0부터 가능).
- **INT 보정**: 모험가의 **INT가 이미 공개돼 있으면** 위 세 확률(개별/전체/특성)에 `+30%p × (INT/100)^2.32`가 가산된다. INT 50이면 +6%p, INT 100이면 +30%p. 말이 통하는 상대일수록 테스트가 수월하다는 의미.
  - **INT 테스트 자신에는 붙지 않는다.** 모르는 값이 그 값을 알아낼 확률을 정하면, 확인 패널에 표시되는 확률이 거짓이 되거나 그 숫자로 INT가 역추론된다.
  - 자동 공개(통찰 임계값)로 INT가 열린 경우도 포함된다.
- **프리미엄(보장형)**: 성공 확률을 무시하고 무조건 공개하는 경로도 있다.

공개에 성공하면 그 정보는 **영구히** 보인다.

## 5. 수색꾼 (던전 방어 타입)

던전의 방어구 타입을 알아내려고 수색꾼을 파견한다. 방어 타입은 무기-방어구 상성([[모험_시스템#6-성공률은-무엇으로-결정되는가|모험_시스템 §6]])에 직결되므로 중요하다.

- **파견 조건**: 같은 던전에 진행 중인 수색이 없고, 아직 방어 타입을 모르고, 미확인 결과도 없을 것.
- **비용**: `250 × 던전 등급 배수(0.8/1/1.2/1.5/2) + 5 × min(일차, 140)` — 140일차부터 고정.
- **소요 시간(게임 내 분)**: 통찰 구간별 기본값 × 등급 배수 × 랜덤(0.5~1.5).
  - 기본값: 통찰 0~24 → 120분 / 25~49 → 80분 / 50~74 → 40분 / 75+ → 20분.
- **완료 → 확인**: 시간이 차면 완료되고, 결과 팝업에서 **확인을 눌러야** 방어 타입이 표시된다.
- **날짜 변경 시**: 진행 중이던(미완료) 수색은 **비용 환불**되고, 모든 수색 기록이 초기화된다(던전 구성이 매일 바뀌므로).
- 수색 비용·시간은 의뢰판 확정 시 미리 계산되어 그날 고정된다.

## 6. 점술가 (모험 예감 + 행운)

점술가에게 특정 모험가-던전 조합의 점을 본다.

- **비용**: `300 + 10 × min(일차, 140)` — 140일차부터 고정. 같은 조합은 하루 1회만, 날짜가 바뀌면 초기화.
- **결과 = 추상 지표 + 행운, 두 축**:
  - **추상 지표(예감)** 5단계: 암담 / 험난 / 보통 / 길조 / 대길조.
    - 모험가 최고 스탯 점수를 던전 요구 수치로 나눈 비율에 그날 방어구 상성을 반영해 5단계로 판정.
    - 단, **60%만 정확**하고 40%는 한 단계 어긋난다(점술의 불확실성).
  - **행운(LuckLevel)** 4단계: 흉 / 소길 / 중길 / 대길.
    - 모험가의 **LUK 스탯** 구간(0~25 / 26~50 / 51~75 / 76+)별 가중치로 뽑는다. LUK이 높을수록 좋은 운이 잘 나온다.
    - 행운은 모험 성공률에 **실제 보정**으로 작용: 흉 −10% / 소길 +5% / 중길 +10% / 대길 +20% (모험의 누적 보정 초기값).
- **두 축은 따로 논다**: "큰 빛(대길조)인데 불운(흉)" 같은 조합이 나오며, 결과 문구가 두 축을 합쳐 묘사한다.
- **이스터에그**: 수정구를 직접 건드리면 LUK을 무시하고 행운을 균등 랜덤으로 뽑는다.

> 추상 지표는 "느낌"일 뿐 성공률에 직접 작용하지 않는다. 실제 성공률에 들어가는 것은 **행운(LuckLevel)** 보정뿐이다.

## 8. 데이터 (저장되는 것)

- **통찰 점수**: 회차 데이터의 단일 값.
- **모험가별 공개 상태**: 자동 공개된 스탯, 대화로 공개한 스탯/특성/무기 힌트, 전체 공개 여부.
- **수색 임무**: 던전별 시작 시각·소요 시간·비용·결과 방어 타입·완료/확인 여부(날짜마다 초기화).
- **점술 결과**: 모험가-던전 조합별 추상 지표·행운(날짜마다 초기화).
