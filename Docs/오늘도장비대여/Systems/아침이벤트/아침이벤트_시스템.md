# 아침 이벤트 시스템

> 매일 아침, 길드에 특별한 손님(이벤트 NPC)이 찾아와 일회성 거래·도박·기회를 제안한다. 무기를 강화하거나, 도박을 하거나, 평판을 사고팔 수 있다.
> 이 문서는 어떤 이벤트가 어떤 확률·규칙으로 작동하는지를 기획 관점에서 정리한다. 화면/표시는 [[아침이벤트_UI]] 참조.
>
> 수치는 모두 밸런싱 설정값이며 본문은 기본값이다. "진행일수"는 현재 게임 일차를 뜻한다(후반일수록 금액이 커진다).

---

## 1. 공통 규칙

- **시점**: 아침 페이즈. 이벤트 NPC가 방문자로 등장한다([[모험가_시스템]]).
- **하루 1회**: 그날의 이벤트 상호작용은 한 번만 가능하며, 완료하면 잠긴다. 매일 아침 초기화.
- **이벤트 선택**: 9종 중 **가중치 랜덤**으로 그날 등장할 이벤트가 정해진다(기본 가중치 균등). 단, 투자 결과를 기다리는 중이면 "수상한 투자자"는 후보에서 빠진다.
- **흐름**: NPC 클릭 → 인트로 대화 → 해당 이벤트 패널에서 선택/실행 → 결과.

---

## 2. 9가지 이벤트

### ① 신비한 마법사 — 무기 강화

무기 1개를 맡기면 등급이 무작위로 변동한다.

| 결과 | 확률 |
|---|---|
| 등급 −1 | 15% |
| 변화 없음 | 15% |
| 등급 +1 | 55% |
| 등급 +2 | 14% |
| 등급 +3 | 1% |

등급은 Common~Legendary(0~4) 범위로 제한된다. 하락 시 부가효과가 줄고, 상승 시 등급이 오른다.

### ② 교환 상인 — 무기 교환

무기 **2개를 바치면** 새 무기 1개를 받는다. 두 무기의 **등급 합(0~8)**이 높을수록 좋은 등급이 나온다.

- 예) 등급 합 0 → 결과 70% Common / 30% Uncommon. 등급 합 8 → 85% Legendary / 15% Epic.
- 결과 등급의 무기 중 무작위 1개를 지급하고, 바친 두 무기는 사라진다.

### ③ 수상한 투자자 — 도박

골드를 투자하면 **다음 날** 결과 NPC가 찾아와 돌려준다.

- **투자 금액**: 최소 1,000골드 ~ 최대 `진행일수 × 500`골드.
- **결과(즉시 확정, 지급은 다음 날)**:

| 결과 | 확률 | 회수 |
|---|---|---|
| 먹튀 | 40% | ×0 |
| 성공 | 50% | ×1.5 |
| 대성공 | 9% | ×2 |
| 대박 | 1% | ×5 |

- 투자 결과를 받기 전까지는 투자자가 다시 등장하지 않는다. 미확인 결과는 2일 후 만료.

### ④ 떠돌이 대장장이 — 무료 작업

무기를 맡기면 **강화 또는 재부여 중 하나를 자동(50%)**으로 무료 적용한다(재료 소모 없음).

- 강화 선택 시: +1(80%) / +2(19%) / +3(1%) 만큼 무료 강화.
- 재부여 선택 시: 부가효과를 다시 뽑아 준다. **무기의 재부여 횟수(3회)를 소모하지 않으며**, 유산으로 사 둔 추가 재부여 권리도 그대로 남는다.

### ⑤ 길드 사절단 — 선물 또는 강제 납부

평판 등급이 높을수록 **선물** 받을 확률이 오른다(인트로 후 즉시 결정).

- **선물 확률**: Bronze 60% / Silver 70% / Gold 80% / Platinum 90% / Diamond 95%.
- **선물**: 골드(`진행일수 ×` 50/100/150 중 확률 결정) + 재료 2개.
- **강제 납부**: 골드(`진행일수 ×` 100 또는 200). 보유 골드 한도 내에서만 차감.

### ⑥ 수수께끼 상자 — 등급별 뽑기

그날 등장하는 상자 등급이 정해지고(일반 60% / 희귀 30% / 신비 10%), 골드로 구매해 즉시 개봉한다.

- **가격**: `진행일수 ×` 150(일반) / 300(희귀) / 500(신비).
- **개봉 결과**: 재료 / 골드 / 무기 / 꽝. 상자 등급이 높을수록 무기 등급과 골드가 커지고 꽝 비중이 낮다.
  - 예) 일반: 재료 40% / 골드 30% / 무기(Uncommon) 20% / 꽝 10%.
  - 예) 신비: 재료 25% / 골드 20% / 무기(Epic~Legendary) 40% / 꽝 15%.

### ⑦ 난민 돕기 — 평판 거래

골드를 기부해 평판을 얻거나, 거절한다.

- **비용**: `진행일수 × 100`골드.
- **기부 시**: 평판 +5(70%) 또는 +10(30%).
- **거절 시**: 평판 −5(60%) 또는 변화 없음(40%).
- 골드가 부족하면 자동 거절 처리된다.

### ⑧ 수집가 — 고가 매입

보유한 **Rare 이상** 무기 1개를 시세보다 비싸게 사 간다.

- 판매가 = 무기 기본 가격 × 3(40%) / ×4(40%) / ×5(20%).

### ⑨ 암시장 상인 — 할인 + 평판 손실

**Rare 이상** 무기 1개를 **50% 할인가**에 제안한다.

- 구매 시 평판 −10.
- 무기의 부가효과는 통찰 수준에 따라 일부만 공개된다([[통찰_시스템]]).

## 3. 데이터 (저장되는 것)

- **그날 이벤트 완료 여부**, 수수께끼 상자 등급, 암시장 제안 무기(패널 도중 저장/복원).
- **투자 대기 상태**: 투자 여부·투자한 날·다음 날 받을 금액·결과 종류(다음 날 NPC가 지급).
