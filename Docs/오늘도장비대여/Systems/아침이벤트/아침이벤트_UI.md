# 아침 이벤트 UI

> 아침 이벤트 화면이 어떻게 구성되고 흘러가는지를 기획 관점에서 정리한다. 로직·확률은 [[아침이벤트_시스템]] 참조.

---

## 1. 화면 구조

아침 이벤트는 **하나의 통합 화면**으로 처리된다. 공통 헤더(이벤트 NPC 정보)를 두고, 그날 이벤트 종류에 맞는 **서브 패널 하나만** 켜진다.

```
이벤트 NPC 클릭
   │
   ▼
인트로 대화
   │
   ▼
아침 이벤트 화면 (공통 헤더 + 해당 서브 패널)
   │  선택/실행
   ▼
결과 표시 → 닫기 (오늘 이벤트 완료)
```

---

## 2. 이벤트별 패널

| 이벤트 | 패널에서 하는 일 |
|---|---|
| 신비한 마법사(무기 강화) | 무기 1개 선택 → 강화 실행 → 등급 변동 결과 |
| 교환 상인 | 무기 2개 선택 → 결과 등급 확률 확인 → 교환 → 새 무기 결과 |
| 수상한 투자자 | 투자 금액 입력 → 확정 → 결과 유형·내일 받을 금액 표시(실지급은 다음 날) |
| 떠돌이 대장장이 | 무기 1개 맡기기 → 강화/재부여 자동 적용 결과 |
| 길드 사절단 | 오프닝 후 **즉시 실행** → 선물/강제납부 결과(별도 선택 없음) |
| 수수께끼 상자 | 그날 상자 등급·가격 확인 → 구매 → 개봉 결과(재료/골드/무기/꽝) |
| 난민 돕기 | 기부/거절 버튼 → 평판 변화 결과 |
| 수집가 | 판매 가능 무기 목록에서 선택 → 판매 → 획득 골드 결과 |
| 암시장 상인 | 할인 무기 정보(통찰에 따라 효과 일부 공개) → 구매 → 평판 손실 결과 |

- 길드 사절단처럼 **선택지가 없는 이벤트**는 인트로 후 바로 결과를 보여준다.

---

## 3. 표시 규칙

- **확률·결과 미리보기**: 교환(결과 등급 확률표), 상자(등급·가격), 투자(금액 범위) 등은 실행 전에 정보를 보여준다.
- **즉시 vs 지연 지급**: 대부분 즉시 반영되지만, **투자는 다음 날** 결과 NPC가 와야 골드가 지급된다.
- **암시장 효과 가림**: 제안 무기의 부가효과는 통찰 수준만큼만 보이고 나머지는 잠금([[통찰_UI]]).

## 관련 코드

> 화면이 구현된 위치. **파일 단위**로만 정리한다.

| 영역 | 위치 |
|---|---|
| 통합 View + 9개 서브 패널 | `Assets/_Projects/Scripts/UI/Views/MorningEvent/` |
| 이벤트 시작·분기 중개 | 아침 이벤트 Controller (`UI/Controllers/`), 진입은 `MorningEventManager` |
