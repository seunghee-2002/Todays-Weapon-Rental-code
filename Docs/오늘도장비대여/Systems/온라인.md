# 온라인 (랭킹·닉네임·제재)

> 다른 플레이어와 **생존 일수 순위를 겨루는 랭킹**, 순위에 표시되는 **닉네임**, 그리고 운영자가 부정 사용자를 막는 **계정 제재(밴)**를 다루는 인프라다.
> 이 문서는 이 세 가지가 어떻게 동작하고 화면에 어떻게 보이는지를 기획 관점에서 한곳에 정리한다(인프라 도메인이라 시스템·UI를 함께 다룬다).
>
> 온라인 기능은 모두 **익명 계정·클라우드 기반** 위에서 돈다(별도 가입·로그인 없음). 계정·클라우드의 토대는 [[저장]]에서 다룬다. 수치는 모두 밸런싱 설정값이며 본문은 기본값이다.

---

## 1. 랭킹 (리더보드)

생존 일수로 전 세계 플레이어와 겨루는 단일 순위표다.

- **점수 = 생존 일수**(한 회차에서 버틴 날 수). 게임오버 때 그 회차의 일수가 제출된다.
- 같은 계정은 순위표에 **한 자리**만 차지하며, 더 높은 기록이 갱신된다.

### 부정 제출 방지
점수 조작을 막기 위해 서버 검증을 거친다.

- **새 게임을 시작할 때** 서버에서 **세션 토큰**(이번 판의 출입증)을 받는다.
- **게임오버 때** 점수와 세션 토큰을 함께 서버에 보내 검증받은 뒤 등록된다.
- 서버는 점수 범위, 세션의 유효성·재사용 여부, 최소 플레이 시간 등을 확인해 **위조·치트로 보이면 거부**한다.
- 거부 사유에 따라 보류 점수·세션을 정리한다.

### 오프라인 대응
- 인터넷이 없으면 점수와 세션을 **보류**해 두고, **네트워크가 돌아오면 자동으로 제출**한다.

### 순위 조회
- 상위 **100명**과 **내 순위**를 본다. 각 항목은 **순위 · 이름 · 일수**.
- 표시 이름은 본인이면 현재 닉네임, 다른 사람은 서버에서 닉네임을 **일괄 조회**해 보여 준다(약 1시간 캐시). 닉네임이 없으면 식별값 기반 기본 이름으로 대체한다.

## 2. 닉네임

순위표 등에 표시되는 이름이다.

- 닉네임은 **회차 데이터에 로컬 저장**되며, **클라우드(계정)에도 보관**돼 기기를 바꿔도 따라온다.
- **첫 접속 시** 식별값 기반 **기본 닉네임**("Player" + 식별값 앞 일부)이 자동으로 붙는다.

### 변경 규칙

| 항목 | 규칙 |
|---|---|
| 길이 | **2~12자** |
| 허용 문자 | 한글·영문·숫자·밑줄(`_`) |
| 금지어 | 욕설 단어 목록에 걸리면 거부(기기에서 1차, 서버에서 2차 검사) |
| 비용 | **첫 1회 무료**(설정값), 이후 변경마다 **유산 50** 차감 |

- 변경 흐름: 입력 검증 → (유료면) 유산 보유 확인 → 서버 검증·변경 횟수 증가 → 유산 차감 → 로컬·클라우드 반영.
- 변경 누적 횟수는 클라우드에 기록돼, 무료 횟수 소진 여부를 기기가 바뀌어도 유지한다.

> 변경 비용으로 쓰이는 유산은 [[유산_시스템]]에서 다룬다.

---

## 3. 계정 제재 (밴)

운영자가 부정 사용자의 계정 이용을 막는 장치다.

- 제재 여부의 **진실은 서버에 있고**, 게임은 그 상태를 받아 안내·차단에만 쓴다.
- **검사 시점**: 앱 실행(로그인 직후), 네트워크 재연결 시, 랭킹 제출 시(서버가 거부하며 제재를 알림).
- 제재가 감지되면 메인 메뉴에서 **안내 팝업**이 뜬다.
  - **영구 제재** 또는 **기한부 제재**(해제 날짜 표시), 운영자가 적은 **사유**를 함께 보여 준다.
- 운영자가 제재를 풀면 다음 검사에서 **정상으로 돌아온다**.

## 4. 화면

| 화면 | 진입 | 내용 |
|---|---|---|
| 랭킹 팝업 | 메인 메뉴 | 로딩/오류 표시, 1~100위 목록(순위·이름·일수), 하단에 **내 순위** 고정 |
| 닉네임 변경 팝업 | 설정 | 입력칸, **무료/유료 비용 표시**, 입력 오류 안내, 확인·취소 |
| 제재 안내 팝업 | 메인 메뉴(자동) | 제재 기한·사유 안내 |

---

## 5. 저장·Config

- **닉네임 설정**: 길이 제한(2~12), 허용 문자 패턴, 변경 비용(유산 50)·무료 횟수(1), 욕설 단어 목록.
- **보류 점수·세션 토큰·닉네임 변경 횟수** 등 온라인 상태값은 기기(앱 설정 저장)와 클라우드에 나눠 보관된다(회차 저장과 별개).
