# 시간

> **시간**은 게임의 박자를 만드는 토대다. 하루가 아침→낮→저녁→밤으로 흐르고, 각 시간대마다 일어나는 일이 다르다. 손님 등장·모험 진행·퀘스트 마감·아침 이벤트가 모두 이 시간 흐름에 맞물린다.
> 이 문서는 시간이 어떻게 흐르고, 하루가 어떻게 나뉘며, 플레이어가 속도를 어떻게 조절하는지를 기획 관점에서 한곳에 정리한다(소형 도메인이라 시스템·UI를 함께 다룬다).
>
> 각 시간대에 실제로 무엇이 벌어지는지는 해당 도메인 문서에서 다룬다. 수치는 모두 밸런싱 설정값이며 본문은 기본값이다.

---

## 1. 시간은 어떻게 흐르는가

- **현실 1초 = 게임 3분**으로 흐른다(배속을 곱한 만큼 빨라진다).
- 하루는 **06:00에 시작해 21:00에 끝난다**. 21:00을 넘기지 않도록 시간이 고정된다.
- 게임은 **하루(15시간) 단위**로 진행되며, 일·시·분을 하나로 이은 **통합 시간 좌표**도 함께 관리한다(모험 이벤트 예약 등 내부 계산에 쓰인다).

---

## 2. 하루의 시간대 (4단계)

| 시간대 | 시각 | 주로 일어나는 일 |
|---|---|---|
| 아침 | 06:00 ~ 09:00 | 손님 NPC 상호작용 — 무기 상인·대장장이·이벤트 NPC, 아침 이벤트 |
| 낮 | 09:00 ~ 18:00 | 모험가 손님 등장, 모험 진행 |
| 저녁 | 18:00 ~ 21:00 | 하루 마무리 |
| 밤 | 21:00 ~ | 시간 자동 정지 → "다음날로 진행" 안내 |

- 시간대가 바뀌면 알림이 뜨고, 다른 시스템들이 그 전환을 신호로 동작한다(손님 스폰·의뢰판 갱신 등).
- **21:00에 도달하면 시간이 자동으로 멈추고**, 다음 날로 넘어갈지 묻는다. 확인하면 **다음 날 06:00 아침으로** 새로 시작하고 게임이 저장된다.

---

## 3. 시간 조절

플레이어는 상단바의 시간 버튼으로 속도를 조절한다. 버튼은 **상황에 따라 역할이 바뀐다**.

| 상황 | 버튼 역할 |
|---|---|
| 낮·저녁 | **배속 순환**: x1 → x2 → x4 → 정지 → (다시 x1) |
| 아침(스킵 가능 시) | **아침 건너뛰기**: 곧장 09:00으로 |
| 밤(21:00 이후) | **다음 날**: 다음 날로 진행 |

- **배속**은 1배·2배·4배와 정지를 돌아가며 고른다.
- **아침 건너뛰기**: 무기 상인과의 상호작용을 마치면 아침을 건너뛸 수 있다. 아침 손님 모두와 상호작용을 끝내면 **건너뛰기를 자동으로 권유**한다.
- **시스템 강제 정지**: 튜토리얼 등에서는 시스템이 플레이어의 시간 조작을 잠그고 강제로 멈출 수 있다.
- 일부 화면은 **열려 있는 동안 시간을 멈춘다**(예: 무기점). 화면을 닫으면 다시 흐른다.

---

## 4. 화면 — 상단바

| 요소 | 내용 |
|---|---|
| 날짜 | 현재 며칠째인지 |
| 시각 | 현재 시각(시:분) |
| 시간 버튼 | 배속(x1/x2/x4)·정지·아침 스킵·다음 날 아이콘이 상황에 맞게 바뀜 |

- 시각·날짜·정지 상태가 바뀌면 표시가 즉시 갱신된다.
- 시간대가 바뀌면 전환 알림이 함께 뜬다.

---

## 5. 저장

현재 날짜·시각, 플레이어 정지 여부, 선택한 배속이 **한 회차 게임 데이터**에 저장된다(게임오버 시 초기화).

- 불러올 때 21:00을 넘긴 잘못된 시각은 21:00으로 보정한다.
- 정지 상태는 저장된 "플레이어 정지 여부"와 "21시 이후인지"로부터 복원된다.
