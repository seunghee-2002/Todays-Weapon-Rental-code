> 상자 R이 6.1R -> 4.4R로 평평해졌다. 상세: [balance/2026-07-27_아침이벤트_일수비례_제거.md](balance/2026-07-27_아침이벤트_일수비례_제거.md)

3-4에서 **"일수 비례 배율(`*PerDay`)을 전부 제거"** 했다고 선언했지만,
`MorningEventManager`는 통째로 누락됐다. 지금도 전부 `currentDay` 곱으로 굴러간다.

### 일수 비례가 남아 있는 지점

| 항목 | 공식 | 코드 |
|---|---|---|
| 수수께끼 상자 (일반/희귀/신비) | `currentDay x 150 / 300 / 500` | `GetMysteryBoxCost` |
| 상자 골드 보상 | `day x Random(25~50 / 80~150 / 200~400)` | `OpenBoxNormal/Rare/Mythic` |
| 난민 기부 | `currentDay x 100` | `refugeeCostPerDay` |

| 길드 사절단 강요(지출) | `currentDay x 100 / 200` | `guildForceLow/HighMult` |
| 수상한 투자자 상한 | `1000 + currentDay x 500` | `investMinGold`, `investMaxGoldPerDay` |

### R 기준으로 본 인플레

반복 구간 진입은 **61주 = 421일**. 5주(35일)와 비교하면 일수는 12배 오르는데
R은 694 -> 1138G(1.64배)밖에 안 오른다. 그래서 **전 항목이 일률적으로 7.4배 비싸진다.**

| 항목 | 5주 (R=694) | 61주 (R=1138) | 인플레 |
|---|---:|---:|---:|
| 상자 (일반) | 5,250G = **7.6R** | 63,150G = **55R** | 7.3배 |
| 상자 (희귀) | 10,500G = **15R** | 126,300G = **111R** | 7.4배 |
| 상자 (신비) | 17,500G = **25R** | 210,500G = **185R** | 7.4배 |
| 난민 기부 | 3,500G = **5R** | 42,100G = **37R** | 7.4배 |
| 길드 강요 (low) | 3,500G = **5R** | 42,100G = **37R** | 7.4배 |

비교 기준: 확정 계수는 무기 1.8~30R, 강화 0.6~12R, 수색 0.3R다.
**신비 상자 185R은 전설 무기 30R의 6배**로, 체계 안의 어떤 값보다도 크다.

### 그리고 상자는 기대값 자체가 무너져 있다

**비용은 일수 비례인데 무기 보상은 고정가**(basePrice)라, 후반으로 갈수록 급격히 나빠진다.
재료 보상도 `rewardMaterialPool`이 `MAT_ENF_001` 하나뿐이라 개당 50G에 불과하다.

| 상자 | 비용 | 기대값 | EV/비용 (5주 -> 61주) |
|---|---|---|---:|
| 일반 | 150d | `500 + 11.25d` (재료 50G 40% / 골드 30% / 고급무기 2400G 20% / 꽝 10%) | **17% -> 8%** |
| 희귀 | 300d | `1,830 + 28.75d` (재료 100G 30% / 골드 25% / 희귀·에픽 6000G 30% / 꽝 15%) | **27% -> 11%** |
| 신비 | 500d | `4,537 + 60d` (재료 150G 25% / 골드 20% / 에픽·전설 11250G 40% / 꽝 15%) | **38% -> 14%** |

> 무기 가치는 basePrice로 환산했다(인벤토리 상한 50칸이라 실제 효용은 이보다 낮을 수 있다).
> 어떤 티어도, 어떤 시점에도 **기대값이 비용의 절반을 넘지 않는다.**

### 예외 — 투자만 잘 설계돼 있다

`0.4 x 0 + 0.5 x 1.5 + 0.09 x 2 + 0.01 x 5 = 0.98` — **기대값 98%의 거의 공정한 도박**이다.
상한만 일수 비례라 후반에 변동폭이 커지는 구조이며, 이건 의도로 읽힌다.

### 조정 방향 (제안)

1. **일수 곱을 제거하고 고정가로.** 3-4가 5개 항목에 한 것과 같은 처리.
   상자 비용을 예컨대 3R / 8R / 20R(1,500 / 4,000 / 10,000G) 고정으로 두면 R 성장이 인플레를 담당한다.
2. **상자 EV를 비용의 90~110%로.** 도박이므로 투자(98%)와 같은 급이 자연스럽다.
   현재 8~38%는 "사면 무조건 손해"라 콘텐츠가 죽는다.
3. **`rewardMaterialPool`을 확장.** 강화 재료 1종(50G)만 들어 있어 재료 보상이 사실상 꽝이다.

## 1-5. 점술 / 호감도 / 네임드 — 전부 측정 완료 (2026-07-28)

> **네임드 + 호감도 실측 (단계 5-2, 3단 A/B: 193755 미반영 -> 200252 named-blind -> 200331 우대 정책):**

## 1-5-A. 점술 상세 (2026-07-28)

## 1-7. 무기 제작 / 재부여 — 측정 완료 (2026-07-28)

> **실측 (단계 5-3, sim_summary_20260728_202111 vs 미반영 200331, 100시드 x 70주):**
>
> - **무기 제작은 사실상 죽은 콘텐츠다.** 100시드 x 70주 전체에서 상급 **8회** / 중급 **1회** / 초급 **0회**.

>   골드 비용(1,050~2,950G = 1~3R)은 무기 구매(2.1~3.0R)와 비슷해 문제가 아니다.

>   순수입 하락은 그보다 크다 — 나빠진 효과의 무기를 계속 쓰기 때문이다.
>   **단 이건 봇이 결과를 무조건 수용하는 최악 케이스다.** 런타임은 before/after를 고를 수 있으므로
>   실제로는 손해를 보지 않는다. 즉 이 측정의 결론은 "재부여가 나쁘다"가 아니라
>   **"재부여의 가치는 전적으로 선택권에 있고, 비용은 그 선택권 값으로 3.3~5.5R"** 이다.

> - 조정은 미실시. **새 기준선은 202111.**

| 3 | **한 번에 한 축만 바꿔라** | 원인 분해가 불가능해진다. 실사례: 무기 진열 등급과 점술 가격을 같이 올렸더니 **전자가 기본 성공률을 올려 후자의 한계 효용을 깎았다**(점술 회수율 134% -> 31%). 각각 보면 멀쩡한 조정이 겹쳐서 함정이 됐다 (4부) |
| 4 | **상류부터 확인하라** | 배정(`OnVisitor`)보다 의뢰판 확정(`SelectBoard`)이 먼저다. 한쪽만 고치면 효과가 없다 |
| 5 | **"이득일 때만 한다"는 정책은 지출 0을 만든다** | 그 0이 봇 결함인지(원칙 2) 콘텐츠가 죽은 것인지 구분하려면 **강제 참여 정책으로 한 번 더 돌려봐야** 한다 |

> **`.bat`은 ASCII만 쓴다.** 한글 주석을 넣으면 종료 코드 0인데 아무것도 실행되지 않는다.
> Unity 에디터는 닫고 돌린다(프로젝트 폴더 잠금).

# 4부. 로드맵 이후 — 주차 계단 가격 체계 (2026-07-28)

로드맵 1~6단계가 끝난 뒤, **"계속 늘어나는 구조는 밸런스를 맞출 수 없다"**는 문제 제기에서 시작한 후속 작업.
1부의 개별 영역이 아니라 **가격 체계 전체를 다시 설계**한 것이라 별도 부로 둔다.

- 설계 근거: [balance/reference/골드_경제_구조.md](balance/reference/골드_경제_구조.md) (지출처 전수 19곳 + 고정/변동 판정)
- 조정 기록: [balance/2026-07-28_주차계단_가격체계.md](balance/2026-07-28_주차계단_가격체계.md)

## 4-1. 진단 — 무한히 늘어난 건 가격이 아니라 수입이었다

애초 가설("일수 비례가 남아 폭주한다")은 **틀렸다.** 전수 조사 결과 일수 비례 곱은 계수가 전부 0인
죽은 항뿐이었고, 퀘스트 벌금도 60주에서 79,200G에 캡이 걸려 있었다. 진짜 문제는 반대쪽이었다:

| | 1~10주 | 61~70주 | 배수 |
|---|---:|---:|---:|
| 주간 수입 | 25,323G | 156,023G | **6.2배** |
| 주간 지출 | 17,496G | 96,728G | 5.5배 |
| 보유 골드 | 35,141G | **2,243,037G** | 64배 |

- **R(모험 1회 순수입)은 70주에 1.7배뿐인데 주간 수입은 6.2배다.** 차이는 처리량(주간 시도 79 -> 186회).
  **R 기준 체계는 단가 인플레는 막지만 처리량 증가를 못 잡는다.**
- 보유 골드가 최대 벌금의 **28배**라 벌금을 아무리 세게 해도 죽지 않는다.
  목표(후반 게임오버 필연)는 벌금이 아니라 **지출/수입 비율**로 달성해야 했다.

## 4-2. 설계 — 왜 주차 계단인가

| 후보 | 기각 사유 |
|---|---|
| 일수 비례 | 무한 선형 증가. 예고가 불가능하다 (2026-07-27에 걷어낸 것) |
| 로그 수렴 곡선 | 일수 기준이라 플레이 속도(처리량)를 반영 못 한다. 튜닝 파라미터도 2개로 는다 |
| R 연동 | 1.7배라 6.2배 수입을 못 따라간다 |
| 평판 티어 연동 | 승급 직후 값이 뛰어 **"승급 페널티"**가 된다. 언제 오를지 몰라 예고도 불가능 |
| **주차 계단** | 4단계(10/20/30/40주)에서 **자동 수렴**. 날짜가 확정적이라 **길드 전령이 미리 예고할 수 있다** |

선례가 이미 있었다 — 의뢰판 던전 등급 가중치가 `QuestBoardConfig.questWeightTiers`로 같은 구조다.

## 4-3. 결과

| 구간 | 구조 지출비율 전 -> 후 | 순수입 전 -> 후 |
|---|---|---|
| 41~50주 | 53% -> **90%** | 48,299 -> 8,324 |
| 51~60주 | 59% -> **98%** | 30,153 -> **-13,251** |
| 61~70주 | 55% -> **91%** | 59,294 -> 6,510 |

- 보유 골드 224만 -> **86만(-61%)**, 41주 이후 등락하며 횡보.
- **41주 이후 평균 드리프트 +528G/주 = 사실상 0** -> 저축이 랜덤 워크가 되어 확률 1로 파산한다.
- 상급자 폐업률 **4% -> 21%**. 중급자는 22 -> 23%(거의 무변화)인데 전설 보유율은 17 -> 31%로 개선.

## 4-4. 이 작업에서 배운 것

> **"값어치가 커지는가"를 더 정확히 말하면 "플레이어가 강해진 뒤에도 그 값어치가 유지되는가"다.**
>
> - **물건**(무기·강화·진화·재부여) = 강해질수록 값어치도 커진다 -> **변동 가능**
> - **정보**(점술·수색·새로고침) = 강해질수록 값어치가 **줄어든다** -> **고정. 올리면 함정이 된다**

실측이 판정을 두 번 뒤집었다.

1. **점술을 "변동"으로 판정했다가 철회.** 3배(900G)에서 A/B를 돌리니 회수율 31%로 무너졌다
   (300G일 때는 134%였다). **원인이 같은 작업의 다른 축**이다 — 무기 진열 등급을 올려 기본 성공률이
   오르자 운세 보정의 한계 효용이 줄었다. 황금 아뮬렛과 동일한 구조.
2. **"여지 추정"이 대부분 빗나갔다.** 점술·재부여에서 큰 싱크가 나올 거라 봤지만 각각 함정/기형이 됐고,
   **실제 주력은 대장간(45,285 -> 94,619G/주)**이었다. 이미 등급 연동이라 "건강하니 손대지 말자"고
   적어둔 항목이 정답이었다.

## 4-5. 남은 것

- **중간 구간(11~30주)이 55~56%로 목표(75~80%) 미달.** 더 조이면 중급자(폐업률 23%)가 무너져 의도적으로 남겼다.
- **61~70주 드리프트가 +6,510G로 양수.** 51~60주의 -13,251과 상쇄돼 평균은 0이지만,
  통과율이 회복되는 구간에서는 저축이 다시 는다. 더 조이려면 대장간 배율 2.0 -> 2.2.
- **`VisitorManager.CleaningReward = 50 x currentDay`** — 수입 쪽에 남은 일수 비례.
  이번 정리는 지출(SpendGold)만 훑어서 목록에 없었다. 별도 판단 필요.

# 5부. 엔드리스 구간 (61주~) — 난이도 등급과 종말 시계 (2026-07-29)

기록: [balance/2026-07-29_엔드리스_난이도등급과_벌금곡선.md](balance/2026-07-29_엔드리스_난이도등급과_벌금곡선.md)
설계: [balance/reference/주간퀘스트_레벨디자인.md](balance/reference/주간퀘스트_레벨디자인.md) §8

## 5-1. 4부의 사각지대

4부의 측정은 **70주까지**였고 그 안도 대부분 캠페인이다. 엔드리스를 160주까지 늘려 재보니
**축적이 되살아나 있었다** — 지출은 45,000G에서 멈추는데 수입은 143,000G까지 오른다.
`PriceTierConfig`의 계단이 41주에서 끝나는데 처리량(주간 성공)은 123 -> 138로 계속 늘기 때문이다.

즉 **4부의 계단 설계는 캠페인 안에서만 성립한다.** "드리프트 0 달성"은 캠페인 구간의 결론이었다.

## 5-2. 난이도 분류가 이름뿐이었다

엔드리스 템플릿 16종은 아키타입(휴식/표준/시험)으로 분류돼 있었지만 실측 통과율은 **역전**돼 있었다.
"휴식형"(쉬움)이 "시험형"(최고난도)보다 2.6배 어려웠다.

난이도를 만드는 것은 **병목 3종뿐**이다 — 저가용 던전(의뢰판 가중치 최대 30배 차) / 희소 무기(석궁 5종) /
둘의 조합. 등급 요구는 병목이 아니다(전설 2회 단독 90.7%).

재설계 후 (중급자 통과율): Easy 95% / Normal 69% / **Hard 42.0~42.1%** / Extreme 30%.

## 5-3. 결과

| | 전 (벌금 고정 79,200) | 후 (`+8,000 x 주차`) |
|---|---|---|
| 상급자 수명 / 폐업률 | 160주(완주) / 31% | **139주 / 70%** |
| 중급자 수명 / 폐업률 | 160주(완주) / 21% | **129주 / 83%** |
| 초급자 | 30주 / 100% | 30주 / 100% (무변화) |
| 페르소나 순서 | **역전**(중급이 더 오래 삶) | **정상** |

## 5-4. 배운 것

| # | 교훈 |
|---|---|
| 1 | **측정 구간을 넘어선 결론을 내지 말 것.** 4부의 "드리프트 0"은 70주까지의 이야기였는데 전 구간으로 읽힐 뻔했다. |
| 2 | **분류 라벨은 검증 전까지 주장일 뿐이다.** 아키타입은 문서·코드·에셋에 다 박혀 있었지만 실측과 무관했다. |
| 3 | **개체 수가 아니라 실측이 병목을 정한다.** 석궁 5종/마도서 6종으로 거의 같은데 통과율은 46% vs 86%였다. |
| 4 | **압박을 올리면 페르소나 순서가 바로잡힐 수 있다.** 약한 압박에서는 현금을 쌓아둔 중급자가 재투자하는 상급자보다 오래 살았다. |

## 5-5. 남은 것

- **가격 계단 41주 정체** — 벌금 기울기 8,000이 큰 값인 근본 원인. 계단을 61주+로 연장하면 낮출 수 있으나,
  정보 서비스 함정(3부 원칙)을 다시 밟을 위험이 있어 측정 없이 손대지 않았다.
- **상급자에게는 등급이 단조가 아니다** — 던전 병목이 의뢰판 새로고침으로 뚫린다(78~85%).
  석궁 병목은 못 뚫는다(46%). 실력 반영으로 보고 남겼다.
- **Extreme 내부 편차 20.9~37.5%** — 최고 난이도의 결로 남겼다.
