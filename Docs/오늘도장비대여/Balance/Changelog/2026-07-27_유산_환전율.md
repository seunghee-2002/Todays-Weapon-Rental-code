# 유산 환전율을 200 -> 50G/포인트로 인하 (1/4)

> 기록: 2026-07-27 · 작성: /balance (소급) · 커밋: d89beca2

## 근거 (왜)
유산(영구 재화) 1포인트를 골드로 환전할 때 200G는 과대평가였다. StartingGold 업그레이드(80유산 투자 -> 회차당 +1000G)의 손익분기를 4회차로 맞추려면 유산 1 = 50G가 적정. 환전율이 높으면 유산을 골드로 바로 녹이는 게 영구 업그레이드보다 이득이 되어 유산 시스템의 존재 의미가 약해진다.

## 대상 시스템 (무엇을)
유산(LegacyManager / LegacyConfig). 유산 -> 골드 환전 경로.

## 수정 전후 (어떻게)
| 항목 | 전 | 후 | 위치(파일:필드) |
|---|---|---|---|
| 유산 1당 환전 골드 | 200 | 50 | LegacyConfig.goldPerLegacy |

- 코드 기본값(`LegacyConfig.cs`)과 에셋(`LegacyConfig.asset`) 모두 반영. 툴팁에 "StartingGold 업그레이드 손익분기 4회차" 근거를 명시.

## 시뮬 / 검증 근거
- 조정 당시: 시뮬 없음 - 판단 근거: StartingGold 영구 업그레이드(80유산 -> +1000G/회차) 대비 손익분기 계산. 유산 80점을 환전하면 200G 기준 16000G(즉시), 50G 기준 4000G. 업그레이드는 4회차부터 4000G 누적을 넘겨 이득이 되도록 설계.
- **사후 실측 (2026-07-27, 시뮬 단계 2 유산 회차 반복 반영 후 A/B)**: `Documents/Simulation/sim_summary_20260727_201902.md`(50) vs `sim_summary_20260727_201958.md`(200 오버라이드), 100시드 x 70주 x 5회차.
  - 200이면 초급자 수명이 13 -> 20주로 늘지만 성장원이 업그레이드가 아니라 **벌금 연명 환전(발동률 100%)**이다.
  - 50에서는 연명 환전 의존이 낮고(초급 81~94%, 중급 ~20%) 회차 성장이 업그레이드 축으로 유도된다 — **인하 방향이 "환전보다 업그레이드" 설계에 부합함을 실측이 지지**.
  - 남은 문제: 50에서 초급자 회차 성장 체감(수명 13 -> 15주)이 약함 — 환전율이 아니라 유산 비용/효과 21종(로드맵 1-4) 조정에서 다룰 것.

## 기대 효과 / 리스크
- 기대: 유산을 즉시 골드로 녹이는 선택의 이득을 낮춰 영구 업그레이드로 유도.
- 리스크: 초반 골드가 급한 플레이어에게 환전 매력이 크게 떨어짐. 유산 획득량 대비 체감 확인 필요.
