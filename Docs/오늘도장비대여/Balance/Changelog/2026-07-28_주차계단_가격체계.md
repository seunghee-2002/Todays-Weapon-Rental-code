# 주차 계단 가격 체계 도입 (후반 골드 무한 축적 해소)

> 기록: 2026-07-28 · 작성: /balance

## 근거 (왜)

**후반에 골드가 무한 축적돼 게임오버가 구조적으로 불가능했다.**

조정 전 실측(상급자 1회차, 100시드 x 70주):

- 70주차 보유 골드 **2,243,037G** = 주간 순수입의 38배, **최대 벌금(79,200G)의 28배**.
- 주간 수입은 25,323 -> 156,023G(**6.2배**)로 느는데 지출은 17,496 -> 96,728G(5.5배)에 그쳐
  순수입이 7,827 -> 59,294G(**7.6배**)로 벌어진다.
- **벌금을 아무리 세게 해도 안 죽는다.** 목표(후반 게임오버 필연)에 도달하려면
  벌금이 아니라 **지출/수입 비율**을 올려야 한다는 뜻이다.

원인은 가격 구조다. 상세 분석은 [[골드_경제_구조|reference/골드_경제_구조.md]].

- 수입의 99%가 모험 수수료이고 그 크기는 **던전 등급**이 정한다.
- 그런데 가격 대부분이 고정가라 R(모험 1회 순수입, 70주에 1.7배) 대비로도, **주간 수입(6.2배) 대비로는
  더욱** 실질 하락한다. 유일하게 비율을 유지한 건 **등급 연동인 대장간**(3.5% -> 3.1%)뿐이었다.

## 대상 시스템 (무엇을)

가격 체계 전반 — 신설 `PriceTierConfig`가 주차 구간별 배율을 한 곳에서 관리한다.
대장간(BlacksmithManager) / 점술(SeerManager) / 무기 상점(WeaponShopManager) /
의뢰판(QuestBoardManager) / 부활(VisitorManager) + 밸런스 시뮬레이터 미러.

## 수정 전후 (어떻게)

### 구조 변경

| 항목 | 전 | 후 |
|---|---|---|
| 가격 결정 | 고정가 (일부 일수 비례, 계수는 전부 0) | **주차 구간 배율** (`PriceTierConfig`) |
| 계단 경계 | 없음 | **10 / 20 / 30 / 40주** (5구간, 40주 이후 수렴) |
| 무기 상점 진열 등급 | `WeaponShopConfig.gradeWeights` 고정 1벌 | `PriceTierConfig.weaponShopGradeWeights` 구간별 5벌 |

계단 주차는 평판 도달 실측(상급 7/17/28/39주, 중급 10/18/26/35주) **직후**에 놓아
수입이 먼저 오르고 값이 따라오는 순서가 되게 했다. 평판이 아니라 주차를 기준으로 삼은 이유는
① 승급 페널티 회피 ② **예고 가능성**(길드 전령이 미리 알릴 수 있다) — `골드_경제_구조.md` 4장.

## 시뮬 / 검증 근거

`sim_raw_20260728_232853.csv` vs 기준선 `sim_raw_20260728_221500.csv`, 100시드 x 70주 x 5회차.

**무결성:** 도입 직후 배율을 전부 1.0으로 두고 돌린 런(`230753`)이 기준선과 **바이트 단위로 동일**했다.
구조 도입이 기존 동작을 건드리지 않았음을 확인한 뒤 튜닝에 들어갔다.

### 상급자 1회차 — 구조 지출 비율(벌금 제외)과 보유 골드

| 구간 | 구조비율 전 -> 후 | 순수입 전 -> 후 | 보유 골드 전 -> 후 |
|---|---|---|---|
| 1~10주 | 64% -> 64% | 7,827 -> 7,827 | 35,141 -> 35,141 |
| 11~20주 | 47% -> 55% | 25,196 -> 21,466 | 216,233 -> 198,726 |
| 21~30주 | 44% -> 56% | 41,539 -> 32,470 | 546,089 -> 458,185 |
| 31~40주 | 51% -> **78%** | 42,414 -> 17,739 | 959,732 -> 686,585 |
| 41~50주 | 53% -> **90%** | 48,299 -> 8,324 | 1,472,331 -> 892,708 |
| 51~60주 | 59% -> **98%** | 30,153 -> **-13,251** | 1,777,242 -> 804,301 |
| 61~70주 | 55% -> **91%** | 59,294 -> 6,510 | 2,243,037 -> **864,310** |

- **보유 골드 -61%**, 41주 이후 89만 -> 80만 -> 86만으로 **등락하며 횡보**한다.
- **41주 이후 평균 드리프트 +528G/주 = 사실상 0.** 저축이 랜덤 워크가 되어
  장기적으로 반드시 0에 닿는다(도박사의 파산). "후반 게임오버 필연"의 수학적 근거.
- 51~60주(통과율이 가장 낮은 구간)에 순수입이 **마이너스로 전환**한다 —
  "평소엔 얇은 흑자, 어려운 구간에 뒤집힘"이라는 설계 목표 그대로다.

### 페르소나 안전성

| 지표 | 상급자 | 중급자 | 초급자 |
|---|---|---|---|
| 폐업률 | 4% -> **21%** | 22% -> 23% | 100% -> 100% |
| 통과율 | 87% -> 90% | 60% -> 65% | 29% -> 29% |
| 수명 | 70주 유지 | 70주 유지 | 20주 유지 |

- 중급자는 폐업률이 거의 그대로인데(22 -> 23%) **전설 보유율이 17 -> 31%로 올랐다** —
  진열 등급 상향의 부수 효과.

## 기대 효과 / 리스크

- 기대: 후반 정상 상태가 "얇은 흑자"가 되고, 어려운 시험주가 실제 고비가 된다.
  40주 이후 계단이 없으므로 **가격은 자동으로 수렴**한다.
- **리스크 1 — 중간 구간(11~30주)이 55~56%로 목표(75~80%)에 미달.** 그 구간 지출은
  대장간·수색이 대부분인데 더 조이면 중급자(폐업률 23%)가 무너진다. 의도적으로 남겼다.
- **리스크 2 — 61~70주 드리프트가 +6,510G로 양수.** 51~60주의 -13,251과 상쇄되어 평균은 0이지만,
  통과율이 회복되는 구간에서는 다시 저축이 는다. 더 조이려면 대장간 배율 2.0 -> 2.2 정도.
- 리스크 3 — 상급자 폐업률 21%가 과한지는 플레이 감각으로 재확인이 필요하다.

## 측정 중 뒤집힌 판정 — 점술은 "고정"이다

설계 문서에 **점술을 "변동으로 가야 할 것"**으로 적었으나 **실측이 반박했다.**

배율 3배(회당 900G)로 올린 런에서 A/B(`-simSeer 0`)를 돌린 결과:

| | 점술 ON | 점술 OFF |
|---|---:|---:|
| 41주+ 주간 수입 | 142,732 | 137,545 |
| 41주+ 주간 지출 | 128,242 | 107,206 |
| **순수입** | **14,490** | **30,339** |

16,583G를 쓰고 5,187G를 회수 = **회수율 31%**. 5-1에서 300G일 때 134%였던 것이 무너졌다.

**원인은 같은 작업의 다른 축이다.** 무기 진열 등급을 올려 기본 성공률이 오르자
점술 운세 보정(+0.2)의 한계 효용이 줄었다 — 황금 아뮬렛과 동일한 구조다.
**점술처럼 "정보"를 파는 항목은 값어치가 성장과 함께 커지지 않으므로,
가격으로 싱크를 만들려 하면 함정이 된다.** 배율 1.0으로 되돌렸다.

같은 이유로 재부여도 4배(회당 15,000G = 전설 무기 한 자루 값)에서 2.0배로 내렸다.
