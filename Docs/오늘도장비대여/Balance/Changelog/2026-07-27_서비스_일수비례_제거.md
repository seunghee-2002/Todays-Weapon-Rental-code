# 수색·점술·의뢰판·상점의 일수 비례 배율 제거 (5beffd17)

> 기록: 2026-07-27 · 작성: /balance (소급) · 커밋: 5beffd17

## 근거 (왜)
수색(스카우트)·점술(점술가)·의뢰판 재확인·상점 가격에 "현재 일차 x 배율"의 일수 비례 가산이 붙어 있었다. 재부여 비용 개편(`6942e781`)과 같은 논리로, 모험 수입(R)이 자연 성장하는데 서비스 비용까지 날짜로 인플레하면 이중 인플레가 된다. 일수 비례 항을 전부 0으로 눌러 기본가 + 고정 배율 구조만 남김.

## 대상 시스템 (무엇을)
통찰/서비스 4종: 스카우트(ScoutManager/InsightConfig), 점술가(SeerManager/SeerConfig), 의뢰판 재확인(QuestBoardManager/QuestBoardConfig), 무기 상점 가격(WeaponShopManager/WeaponShopConfig).

## 수정 전후 (어떻게)
| 항목 | 전 | 후 | 위치 |
|---|---|---|---|
| 스카우트 일차당 비용 | scoutCostPerDay = 2 | 0 | InsightConfig.asset |
| 점술 일차당 비용 | costPerDay = 3 | 0 | SeerConfig.asset |
| 의뢰판 재확인 일차당 비용 | reconfirmCostPerDay = 5 | 0 | QuestBoardConfig.asset |
| 상점 가격 일차당 배율 | priceMultiplierPerDay = 0.012 | 0 | WeaponShopConfig.asset |

- 기본가(scoutBaseCost 250, seerBaseCost 300, refreshBaseCost 500 등)는 유지. 관련 `*CostDayCap`(421) 필드는 후속 커밋 `f30a7c32`에서 무효 필드로 정리·제거됨.

## 시뮬 / 검증 근거
판단 근거: R 기준 밸런싱 체계의 "이중 인플레 제거" 원칙 (`Documents/balance/reference/밸런스_시뮬레이터_정리.md`). 재부여 고정가화(`6942e781`)와 동일 논리.

## 기대 효과 / 리스크
- 기대: 서비스 비용이 후반부에 비이성적으로 치솟지 않고 기본가 기준으로 일정하게 유지.
- 리스크: 후반 골드가 풍부한 구간에서 서비스 비용 체감이 지나치게 낮아질 수 있음(기본가 자체의 적정성 재검토 여지).

## 관련 파일
- `Assets/_Projects/Data/Config/InsightConfig.asset`, `SeerConfig.asset`, `QuestBoardConfig.asset`, `WeaponShopConfig.asset`
