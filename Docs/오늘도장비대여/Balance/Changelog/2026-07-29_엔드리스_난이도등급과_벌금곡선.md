# 엔드리스 구간에 난이도 등급 4단계를 만들고 벌금을 주차 곡선으로 전환

> 기록: 2026-07-29 · 작성: /balance

## 근거 (왜)

캠페인(1~60주) 이후 반복 구간에 "쉬운 주 / 평범한 주 / 어려운 주"를 의도적으로 두고, 플레이어가
**어려운 주가 안 걸리길 바라며 최대한 오래 버티는** 플레이를 하게 만드는 것이 목표였다.

착수 전 실측(`sim_endless_sweep_20260729_010224.md`)에서 두 가지가 드러났다.

### 1. 기존 난이도 분류는 이름뿐이었다

엔드리스 템플릿 16종은 아키타입(휴식/표준/소피크/시험)으로 분류돼 있었지만, 실측 통과율은
그 분류와 **무관했고 심지어 역전**돼 있었다 (중급자 기준):

| 템플릿 | 문서상 분류 | 실측 통과율 |
|---|---|---:|
| W70 | 시험형(최고난도) | **96.7%** |
| W61 | 휴식형(쉬움) | **36.8%** |

"쉬움"으로 구운 W61(낮은 산 3회)이 "최고난도" W70보다 2.6배 어려웠다.

난이도를 실제로 만드는 것은 아키타입도 등급 요구도 아니라 **병목 3종**이었다:

| 병목 | 정체 | 실측 |
|---|---|---:|
| 저가용 던전 요구 | 엔드리스 의뢰판 등급 배율이 일반 0.05 / 고급 0.25 vs 희귀+ 2~150 (최대 30배 차) | 37~42% |
| 희소 무기(석궁) 요구 | 개체 5종뿐 (다른 6타입은 13종) | 42% |
| 위 둘의 조합 | | 31% |

등급 요구는 병목이 아니었다 — 전설 이상 2회 단독 요구가 90.7%였다.

### 2. 엔드리스는 위협이 아니었다

벌금이 60주차 값(79,200G)으로 고정돼 있어, 최고난도 퀘스트를 65% 실패해도 주당 +40,473G가
쌓였다. 중급자 폐업률 **0%**. 실패가 아프지 않으니 "버티기"라는 긴장이 성립할 자리가 없었다.

측정에서 확인된 원인: 지출은 45,000G에서 멈추는데 수입은 143,000G까지 오른다.
`PriceTierConfig.tierMaxWeeks = {10,20,30,40}`이라 41주 이후 가격이 고정인데,
처리량(주간 성공)은 123 -> 138로 계속 늘기 때문이다.

## 대상 시스템 (무엇을)

- 주간 퀘스트 엔드리스 구간 (`QuestManager`, 신설 `EndlessQuestConfig`)
- 퀘스트 생성기 (`WeeklyQuestGenerator` — 에디터)
- 퀘스트 정적 데이터 (`WeeklyQuestData` + CSV importer)

## 수정 전후 (어떻게)

### A. 난이도 등급 도입

| 항목 | 전 | 후 | 위치(파일:필드) |
|---|---|---|---|
| 난이도 분류 | 없음 (아키타입만) | `QuestDifficulty` 4단계 Easy/Normal/Hard/Extreme | `WeeklyQuestData.difficulty` |
| 엔드리스 풀 구성 | 아키타입 기반 3+6+4+3 | 병목 개수 기반 **4벌씩 16종** | `WeeklyQuestGenerator.BuildEndlessRequirements` |
| 던전 선택 | 등급으로만 지정 | **유효 가중치 밴드**(Abundant/Thin/Scarce) | `WeeklyQuestGenerator.InBand` |
| 희소 무기 | 석궁·마도서 랜덤 | 석궁=강한 병목 / 마도서=약한 병목 **명시 배정** | `HardScarceWeapon` / `MildScarceWeapon` |
| 요구 슬롯 수 | 2~3개 혼재 | **전 템플릿 2개 고정** | 위 동일 |
| 전설 던전 | 시험형 3종이 사용 | **미사용** | 위 동일 |
| 엔드리스 보상 배율 | 아키타입 기반 0.9~1.5 | 난이도 기반 **0.8 / 1.0 / 1.3 / 1.7** | `EndlessRewardMult` |
| 제목 풀 | 아키타입별 | **난이도별** (난이도를 예고) | `EndlessTitle` |

결과 보상: Easy 45,798G / Normal 57,248G / Hard 74,422G / Extreme 97,322G

### B. 벌금 주차 곡선

| 항목 | 전 | 후 | 위치(파일:필드) |
|---|---|---|---|
| 61주+ 벌금 | SO 고정 **79,200G** | `79,200 + 8,000 x (주차-61)` | `EndlessQuestConfig.fineBase` / `finePerWeek` |
| 계산 위치 | `questData.weeklyFine` | `QuestManager.CalculateWeeklyFine()` 런타임 분기 | 동일 |

캠페인(1~60주) 벌금은 손대지 않았다 — SO 고정값 그대로다.

### C. 추첨 규칙 (신설 Config)

| 필드 | 값 | 의미 |
|---|---|---|
| `campaignLastWeek` | 60 | 61주차부터 추첨 |
| `difficultyWeights` | 30 / 35 / 25 / 10 | Easy/Normal/Hard/Extreme |
| `noRepeatWindow` | 3 | 직전 3주 템플릿 제외 |
| `blockConsecutiveExtreme` | true | Extreme 2연속 차단 |

추첨은 시드 재현이 아니라 **결과 ID 저장**으로 복원한다 (`GameData.currentEndlessQuestID`).
회차마다 순서가 달라야 하는데(리더보드 게임에서 암기가 되면 안 된다) 시드 고정은 그 반대이기 때문이다.

## 시뮬 / 검증 근거

- 난이도 사다리: `Documents/Simulation/sim_endless_sweep_20260729_020116.md` (60시드 x 3페르소나 x 17구성)
- 생존 곡선: `Documents/Simulation/sim_summary_20260729_020501.md` (기울기 4,000) / `sim_summary_20260729_020955.md` (8,000)

### 난이도 사다리 (중급자, 61주 이후 통과율)

| 등급 | 실측 |
|---|---|
| Easy | 90.5 / 95.6 / 97.2 / 97.6 % |
| Normal | 69.2 / 69.2 / 69.6 % |
| Hard | **42.0 / 42.1 / 42.1 / 42.1 %** |
| Extreme | 20.9 / 28.3 / 33.0 / 37.5 % |

### 벌금 기울기 A/B (160주, 100시드)

| | 기울기 4,000 | 기울기 8,000 |
|---|---|---|
| 상급자 수명 중앙값 | 160주(완주) | **139주** |
| 상급자 폐업률 | 31% | **70%** (폐업 128주) |
| 중급자 수명 중앙값 | 160주(완주) | **129주** |
| 중급자 폐업률 | 21% | **83%** (폐업 123주) |
| 초급자 | 30주 / 100% | 30주 / 100% (무변화) |
| 페르소나 순서 | **역전** (중급이 더 오래 삶) | **정상** (상급이 더 오래 삶) |

기울기 4,000에서는 상급자가 더 많이 죽는 역전이 있었다 — 재투자로 현금이 얇기 때문이다.
8,000에서는 통과율 우위(88% vs 70%)가 생존으로 이어져 순서가 바로잡혔다.

초급자는 캠페인 30주에서 폐업하므로 엔드리스 변경의 영향을 전혀 받지 않는다.

### 무결성 게이트

캠페인 1~60주 에셋은 `difficulty` 한 줄 추가 외에 **변경 0건** (`git diff` 확인).
시뮬 추첨도 전용 `questRng`를 써서 캠페인 구간 rng 스트림을 건드리지 않는다.

## 기대 효과 / 리스크

**기대 효과**
- 엔드리스에 실제 난이도 분산이 생긴다. Easy(95%)와 Extreme(30%)의 격차가 3배다.
- 제목이 난이도를 예고하므로 플레이어가 이번 주가 고비인지 보고 안다.
- 성장은 정점에서 멈추는데 실패 비용만 오르므로 회차가 반드시 끝난다 (생존 일수 중앙값 903~973일).

**리스크 / 한계**
1. **상급자에게는 등급이 단조가 아니다.** 던전 병목은 의뢰판 새로고침으로 뚫리지만(78~85%)
   석궁 병목은 못 뚫는다(46%). 실력 차이 반영이라 그대로 두되, 상급자 체감은 등급 라벨과 다르다.
2. **벌금 혼자 격차를 메우고 있다.** 가격 계단이 41주에서 끝나 지출이 정체하는 게 근본 원인이라,
   기울기 8,000이라는 큰 값이 필요했다. 가격 계단을 61주+로 연장하면 기울기를 낮출 수 있다 (미실시).
3. Extreme 내부 편차가 20.9~37.5%로 넓다. 최고 난이도의 결이라 보고 남겼다.
