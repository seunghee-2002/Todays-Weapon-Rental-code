# 무기 basePrice를 R 기준으로 3배 상향 (8791c697 + CSV 동기화 ccbe65fc)

> 기록: 2026-07-27 · 작성: /balance (소급) · 커밋: 8791c697, ccbe65fc

## 근거 (왜)
R 기준 밸런싱 체계에서 모험 수입(R) 스케일에 맞춰 무기 판매가(상점 구매가 기준값)를 전 등급 일괄 3배 상향. 무기 구매가 모험 수입 대비 너무 저렴해 자산 축적 압박이 약했던 문제 조정.

## 대상 시스템 (무엇을)
무기 상점(WeaponShopManager) / 무기 SO(`Weapons/*.asset`)의 basePrice. 상점 판매가·분해/환급 계산의 기준값.

## 수정 전후 (어떻게)
전 등급 basePrice x3 (대표값):
| 등급 예시 | 전 | 후 |
|---|---|---|
| Common (예: WEA_AXE_COM_001) | 300 | 900 |
| Epic (예: WEA_AXE_EPI_001) | 2500 | 7500 |

- 모든 무기 `.asset`에 x3 적용. 이후 커밋 `ccbe65fc`에서 `WeaponData.csv`의 basePrice 컬럼을 `.asset` 기준으로 동기화(별도 밸런스 결정 아님, 데이터 정합성 후속).

## 시뮬 / 검증 근거
판단 근거: R 기준 밸런싱 체계 (`Documents/balance/reference/밸런스_시뮬레이터_정리.md`). 대장장이 강화 기본비용 x3(`6942e781`)와 동일 스케일 정렬.

## 기대 효과 / 리스크
- 기대: 무기 구매가 모험 수입 대비 유의미한 지출이 되도록 정렬, 자산 관리 압박 부여.
- 리스크: 초반 무기 확보 장벽 상승. 초반 골드 흐름(수수료·퀘스트 보상)과의 균형 재확인 필요.

## 관련 파일
- `Assets/_Projects/Data/Weapons/WEA_*.asset` — basePrice
- `Assets/_Projects/Data/CSV/WeaponData.csv` — basePrice 동기화 (ccbe65fc)
