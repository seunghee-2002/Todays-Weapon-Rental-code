# 맨발(Boots 미착용) 확률을 LUK 독점 -> 전 직업 분산 (LUK 80%/0% -> 45%/12%)

> 기록: 2026-07-29 · 작성: /balance

## 근거 (왜)

외형 파츠 직업 분류 작업(`Documents/외형_파츠_분류_기준.md`)의 설계 요구가
**"외형은 스탯 힌트여야 하며 최고 스탯을 확정시키면 안 된다"** 로 확정됐다.
이 기준으로 `AppearanceGenerator` 의 착용 확률을 점검한 결과 **맨발만 요구를 위반**하고 있었다.

`BootsSkipChanceLuk = 0.80f` 이고 나머지 직업은 `0f` 하드코딩이라
**맨발인 모험가는 예외 없이 LUK**였다. 전체 모험가의 약 20%가 이 상태로 등장한다.

이는 [[2026-07-29_일반모험가_페르소나_20종|일반 모험가 페르소나 20종 개편]]이 해소한 문제와 같은 종류다.
그 작업은 "성별만 보면 스탯 성향이 확정되어 통찰(InsightManager)이 파는 정보의 가치가 깎인다"는
이유로 성별-스탯 상관을 제거했는데, **맨발이 같은 누출 경로를 그대로 남겨두고 있었다.**

### 다른 착용 확률과의 비교 (4직업 균등 가정, 베이즈)

| 관측 | P(해당 직업) | 사전확률 25% 대비 | 판정 |
|---|---|---|---|
| **맨발 (수정 전)** | **LUK 100%** | +75%p | **완전 확정 - 위반** |
| 수염 (남성) | INT 57% | +32%p | 강한 힌트 - 허용 |
| 망토(Back) 착용 | DEX 53% | +28%p | 강한 힌트 - 허용 |
| 헬멧 착용 | STR 35% | +10%p | 약한 힌트 - 허용 |

맨발 외 3종은 전부 힌트 수준이라 **이번에 건드리지 않았다.**

> **4직업 균등 가정의 근거:** 페르소나 20종에서 1스탯 집중 8종이 4직업에 2종씩,
> 2스탯 집중 12종(6축 x 남/여)이 각 직업에 3종씩 기여한다. `GetHighestStat()` 기준 분포가 균등하다.

## 대상 시스템 (무엇을)

- **외형 생성**(`AppearanceGenerator.Generate`) — 일반 모험가 랜덤 외형의 Boots 슬롯
- **통찰**(`InsightManager`, 간접) — 외형으로 최고 스탯을 무료 역산하는 경로를 차단
- 골드·성공률·평판에는 영향 없음. **순수 표현 계층 변경이다.**

## 수정 전후 (어떻게)

| 항목 | 전 | 후 | 위치(파일:필드) |
|---|---|---|---|
| LUK 맨발 확률 | `0.80f` | `0.45f` | `AppearanceGenerator.cs:BootsSkipChanceLuk` |
| STR/DEX/INT 맨발 확률 | `0f` (호출부 하드코딩) | `0.12f` | `AppearanceGenerator.cs:BootsSkipChanceOther` (신설) |

호출부도 삼항 하드코딩 `: 0f` 에서 상수 참조로 바꿨다 (`AppearanceGenerator.cs:59-62`).

### 수치 도출

두 조건을 연립해 풀었다.

1. `P(LUK|맨발)` 을 다른 허용 신호(수염 57% / 망토 53%)와 같은 **약 55%** 로 맞춘다
   -> `p_luk / (p_luk + 3 x p_other) = 0.55` -> `p_luk = 3.67 x p_other`
2. **맨발 등장 빈도를 기존 20%로 유지**한다 (부츠 아트 30종의 노출량을 지키기 위해)
   -> `0.25 x p_luk + 0.75 x p_other = 0.20`

해: `p_other = 0.12`, `p_luk = 0.44` -> 반올림해 **0.45 / 0.12** 채택.

### 검산

| 지표 | 전 | 후 |
|---|---|---|
| P(LUK \| 맨발) | **100%** | **55.6%** |
| P(LUK \| 신발) | 6.3% | 17.2% |
| 맨발 등장 빈도(전체 모험가) | 20.0% | 20.3% |

신발을 신은 경우에도 LUK 확률이 25% -> 17.2%로 내려가 **역방향으로도 약한 힌트**가 남는다.

## 시뮬 / 검증 근거

**시뮬 없음.** 골드·평판·R 지표에 영향이 없는 표현 계층 변경이라 BalanceSim 대상이 아니다.
판단 근거는 위 베이즈 계산과 기존 착용 확률 3종(수염·망토·헬멧)과의 정합성이다.

실제 확인은 `Tools > Today's Weapon Rental > Adventurer Preview Window` (플레이모드 전용)로 한다.

## 기대 효과 / 리스크

**기대 효과**
- 맨발이 LUK를 확정하던 유일한 100% 누출 경로가 사라졌다. 외형 신호 4종이 전부 35~57% 힌트 대역에 들어온다.
- 맨발 빈도가 사실상 그대로라 부츠 파츠 30종의 노출량 손실이 없다.
- LUK의 "맨발 도적" 인상은 유지된다 (LUK가 다른 직업보다 3.75배 자주 맨발).

**리스크 / 주의**
- **판금 갑옷 전사가 맨발로 나올 수 있다** (STR도 12%). 직업별로 차등하면 해소되지만
  (예: STR 5% / DEX·INT 15%) 수치가 복잡해져 우선 균일값으로 뒀다. 렌더 확인 후 거슬리면 재조정.
- 맨발 캐릭터의 직업 분포가 넓어져 "맨발 = 도적" 이라는 기존 플레이어 인식과 어긋날 수 있다. 의도된 변경이다.
- 이 변경만으로는 확정 회피가 완성되지 않는다. **파츠 인덱스 분류(진행 중)에서
  전용(1직업) 배정을 금지**해야 전체 설계가 성립한다.
