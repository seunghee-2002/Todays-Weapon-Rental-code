# 주간 퀘스트 벌금·시험주 요구 튜닝 (4커밋 이력)

> 기록: 2026-07-27 · 작성: /balance (소급) · 커밋: a087e4cd -> 5e46418f -> 61a6a946 -> bf7878b6 (시간순)

## 근거 (왜)
주간 퀘스트는 매주 목표 미달 시 벌금(weeklyFine)을 물고, "시험주"는 특정 등급 무기/던전으로 N회 성공 같은 조건(targetCount·minGrade)을 요구한다. 60주 캠페인에 맞춰 벌금 곡선과 시험주 난이도를 여러 차례 재조정했다. 핵심은 (1) 벌금을 플레이어 수입 규모에 비례시키고, (2) 초반 시험주 요구를 낮춰 부하를 줄이는 것.

## 대상 시스템 (무엇을)
주간 퀘스트(QuestManager / WeeklyQuestData 에셋 ~19종). 각 에셋은 주차별 `weeklyFine` 배열 + 시험주 조건(targetCount, minGrade, requirementText, goldReward 등)을 가짐.

## 수정 전후 (어떻게) - 시간순 이력
각 커밋이 `weeklyFine` 배열 전체를 다시 쓰므로 대표값(초반/후반)과 구조 변경만 정리. 정확한 주차별 값은 각 커밋 참조.

| 순서 | 커밋 | 핵심 변경 |
|---|---|---|
| 1 | a087e4cd (07-26) | 벌금·시험주 요구 재조정(이 패스의 기준선). 일부 시험주 targetCount/minGrade/requirementText 조정 |
| 2 | 5e46418f (07-26) | 벌금 하향 + 시험주 대폭 완화(targetCount·minGrade·specificDungeonID·specificWeaponType 완화, 일부 goldReward 조정) |
| 3 | 61a6a946 (07-26) | 벌금 기울기(주차 증가폭) 상향: 예) 초반 4450->4600, 후반 41500->47500 (스텝 확대) |
| 4 | bf7878b6 (07-27) | 벌금을 "수입 비율 기준"으로 재설정: 초반 하향(4600->2500)·후반 상향(69500->79200). 시험주 부하 하향(targetCount 예: 6->5, 5->4, 4->3) |

최종 상태(=bf7878b6): 초반 주차 벌금 약 2500대에서 시작해 후반 79000대까지 증가하는, 수입 비율에 맞춘 곡선. 시험주 성공 요구 횟수는 한 단계씩 낮춤.

## 시뮬 / 검증 근거
판단 근거: 주간 퀘스트 레벨 디자인·난이도 계수 (`Documents/balance/reference/주간퀘스트_레벨디자인.md`, `Documents/balance/reference/주간퀘스트_난이도_계수.md`), R 기준 시뮬 재측정(`Documents/balance/reference/밸런스_시뮬레이터_정리.md`, `Documents/Simulation/`). 벌금을 주차별 예상 수입(R)의 일정 비율로 맞추는 것이 목표.

## 기대 효과 / 리스크
- 기대: 초반 벌금·시험주 부하를 낮춰 이탈 방지, 후반 벌금을 수입에 비례시켜 긴장 유지.
- 리스크: 4회 반복 튜닝으로 곡선이 여러 번 뒤집혔으므로, 최종 곡선의 주차별 실측 검증 필요. 시험주 완화가 과해 후반 도전 부족 우려.
