# 이벤트 난이도 계수를 최종 성공률 곱 -> 요구 스탯 임계값 적용으로 이동 (+ 2차 클램프 제거)

> 기록: 2026-07-29 · 작성: /balance · 미커밋

## 근거 (왜)

`difficultyMultiplier`(보스 0.7 / 미니보스 0.85)가 **최종 성공률에 곱해지는** 구조라, 플레이어가 확정적으로 통제 가능한 보스 성공률 상한이 **어떤 투자를 해도 70%**로 고정돼 있었다. Legendary 무기 + 모험가 스탯 전부 100 + Common 던전이라도 70%다. 그 위를 넘기는 수단은 운세(대길 +0.20, 유료 도박)와 기분 배율(보스는 반감 적용, 최대 x1.15)뿐 — 둘 다 랜덤이라 투자로 통제되지 않는다.

더 큰 문제는 **포화 지점이 매우 이르다**는 것이었다. 상성 최고치가 `0.60`(`TypeAdvantage.weaponArmorBonus`)이라 2차 클램프(`clamp(effectBase x (1+상성+부적), 0, 1)`)에서 `effectBase`가 0.625만 넘으면 1.0으로 잘린다. Common 던전(임계값 110) 기준 스탯 점수 **69**만 넘으면 포화하고, 그 위의 무기 등급/스탯/도감 보너스/호감도/조건부 효과가 전부 사장됐다. 즉 "만렙 투자가 70%"가 아니라 **어중간한 투자로 이미 70%에 도달하고 그 위는 전부 무의미**했다.

이 상한은 [[밸런스_시뮬레이터_정리|reference/밸런스_시뮬레이터_정리.md]] 4-1(라인 436)에 이미 관측돼 있었다:

> 완주 확률 상한이 전 등급 약 70%로 같은 것은 보스 `difficultyMultiplier` 0.7이 병목이기 때문이다. 등급 간 차이가 아니므로 문제 아님.

당시엔 "등급 간 상대 밸런스"만 보고 문제 없음으로 판정했으나, **투자 보상 곡선(성장의 종착점)** 관점에서는 병목이 맞다고 재판단했다.

## 대상 시스템 (무엇을)

모험 성공 판정 — `AdventureManager.Calculations` (`CalculateSuccessRate` / `CalculateEventSuccessRate`), 밸런스 시뮬레이터 미러(`SimCore`).

### 검증 포인트

- **변하는 구간은 "기존에 클램프에 걸리던 구간"뿐이다.** 구식 `r x (1+상성) x 0.7`과 신식 `r x 0.7 x (1+상성)`은 곱셈 순서만 다른 같은 식이라, **클램프가 물리기 전까지는 완전히 동일**하다. 차이는 오직 클램프가 늦게 걸린다는 것뿐이다.
- 따라서 **"저투자 = 불변"이 아니다.** 상성이 좋으면 낮은 스탯에서도 클램프에 걸리므로(상성 +0.6이면 스탯/임계값 0.625에서 포화), 초급자도 영향을 받는다. 실측에서 초급자 완주율이 +10%p 오른 것이 이 때문이다.
- 상성 -0.45 무기의 보스 상한은 38.5% -> 55%로 올랐다. `effectBase`가 1로 클램프된 뒤 `x0.55`가 걸리는 구조라, 상성이 나쁘면 여전히 55%가 천장이다.
- 2차 클램프 제거는 `bonusSum`이 **음수일 때만** 결과가 달라진다. 유일한 음수 요인은 `traitEasyExpertHighTierPenalty = -0.15`(양학 특성, 고티어 던전). 예: 양학 + 스탯 1.0배 + 상성 0.6 보스 = 85% -> 97%. 그 외 경우는 3차 클램프와 중복이라 무효과.

## 기대 효과 / 리스크

**기대**
- 성장의 종착점이 생긴다. 스탯/무기 등급/상성/도감/호감도 투자가 보스 판정까지 실제로 이어진다.
- 난이도 계수에 "요구 스탯 몇 배" 라는 읽을 수 있는 의미가 생겼다. SO 값 조정 시 직관이 선다.
- 상성 선택의 가치가 커진다 (상성 0.6과 0의 보스 상한 차이가 실질화).

**실측으로 확인된 리스크 (후속 조정 필요)**

1. **중급자 완주율 89~95%는 과하다.** 수색·점술을 거의 안 쓰는 페르소나가 15주차부터 사실상 전승한다. 상급자(64~69%)보다 높은 역전도 발생했다 — 상급자가 더 높은 등급 던전에 도전하는 정책이고 중급자는 보유 무기가 많아(42자루 vs 8자루) 상성을 맞추기 쉬운 탓으로 보이나, 어느 쪽이든 난이도가 사라졌다.
2. **골드 인플레가 재발했다.** 상급 70주 보유 골드 190만 -> **500만(2.6배)**. [[2026-07-28_주차계단_가격체계]]가 224만 -> 86만으로 잡고 "드리프트 0"을 달성했던 성과를 되돌린다.
3. **평판이 복리로 증폭된다.** 완주율 상승 -> 평판 상승 -> 스폰 간격 단축 -> 주간 시도 증가(상급 5주차 69 -> 105) -> 골드 증가. 성공률 손잡이 하나가 세 지표를 동시에 민다.
4. **벌금 압박이 약해졌다.** 상급 91~100주 주간벌금/수입 31% -> 22%. [[2026-07-29_엔드리스_난이도등급과_벌금곡선]]가 세운 기울기가 무뎌졌다.

**유지된 것**
- **R(모험 1회 순수입)은 거의 불변**(684 -> 665G, 1203 -> 1183G). 골드 총량이 는 것은 **1회당 수입이 아니라 모험 횟수와 완주 비율**이 늘어서다. 즉 **R 배수로 정의된 가격표는 다시 짤 필요가 없고**, 성공률/스폰 쪽 손잡이만 조이면 된다. 3-6의 "가격은 더 건드리지 않는다" 규칙이 여전히 성립한다.
- 사망 판정(`CalculateDeathRate`)은 무수정. 사망률 1.4% -> 0.6%는 판정식이 아니라 **판정 횟수**가 준 결과다(실패해야 사망을 굴린다).

**후속 조정 후보 (미적용)**
- `AdventureConfig.successRateMax` 1.0 -> 0.90~0.95 — 상한 재도입. 가장 국소적이다.
- 보스 `difficultyMultiplier` 0.7 -> 0.6 (요구 임계값 1.43배 -> 1.67배) — 계수 자체를 조임.
- 던전 `baseStatThreshold` 상향 — 2026-07-26에 한 번 내렸다가 원복한 이력이 있으니 [[2026-07-26_고등급던전_완주율]]를 먼저 볼 것.
- `maxEventCountByGrade`(3/4/5/6/7) — 완주 확률 = `회당성공률^이벤트수`라, 상한이 풀린 지금은 이벤트 수를 되돌릴 여지가 생겼다.

> 어느 것을 택하든 **1번(중급 완주율)이 기준 지표**다. 골드·평판·벌금은 전부 완주율의 종속 변수라 완주율만 잡으면 함께 따라온다.
