# 아침 이벤트 일수 비례 제거 + 상자 EV 98% 정상화

> 기록: 2026-07-27 · 작성: /balance

## 근거 (왜)

로드맵 1부(`밸런스_미적용_영역과_시뮬_로드맵.md` 1-1)에서 유일하게 "위반 확정"이었던 영역.
3-4에서 일수 비례 배율을 전부 제거했다고 선언했지만 `MorningEventManager`가 통째로 누락되어,
상자/난민/사절단이 전부 `currentDay x 배율`로 굴러가고 있었다.

**조정 전 실측 (시뮬 단계 1 반영 후, 100시드 x 70주):**
- 강제 참여 런에서 상자 1개 비용이 18.2R(1~10주) -> 108.7R(61~70주)로 폭주 (확정 계수 항목은 무기 ~2R, 수색 0.3R로 평평).
- 상자 기대값이 비용의 8~38%라 EV 계산 봇(상급자)은 참여 2,665회 중 상자 구매 0회 — 콘텐츠 사망.
- 강제로 사게 하면 상급자 주간 순수입 29,889 -> 9,078G(-70%), 중급자 수명 중앙값 38 -> 12주로 붕괴. "참여할수록 손해"가 정량 확인됨.
- 사절단 선물도 61주에 day x 92.5 = 약 39,000G = 34R로, 전설 무기(30R)보다 큰 공돈 — 수입 쪽도 같은 위반.

처리 원칙은 3-4(`2026-07-27_서비스_일수비례_제거.md`)와 동일: 일수 곱을 제거하고 고정가만 남겨 **R 성장이 인플레를 담당**하게 한다. 상자 EV는 투자(98%)와 같은 급의 "거의 공정한 도박"인 비용의 98%로 맞췄다. 투자자는 EV 98% + 상한만 일수 비례인 의도된 설계로 판정(로드맵 1-1), 변경하지 않았다.

## 대상 시스템 (무엇을)

아침 이벤트(MorningEventManager / MorningEventConfig): 수수께끼 상자(6), 난민 돕기(7), 길드 사절단(5).
+ 밸런스 시뮬레이터 미러(SimCore) 동기화.

상자 확률표(재료/골드/무기/꽝)는 유지. EV 계산(재료 = 구매가 평균 210G, 무기 = 등급 basePrice):
- 일반 1,500G: 0.4x210 + 0.3x3,000 + 0.2x2,400 = 1,464 (98%)
- 희귀 4,000G: 0.3x420 + 0.25x8,000 + 0.3x6,000 = 3,926 (98%)
- 신비 10,000G: 0.25x630 + 0.2x18,250 + 0.4x15,000 = 9,807 (98%) — 무기 1.5배 / 골드 1.8배 잭팟 구조(전설 확정안 채택)

## 기대 효과 / 리스크

- 기대: "사면 무조건 손해"였던 상자 콘텐츠 부활. 아침 이벤트 참여가 손해 -> 소폭 이득으로 전환. 후반 인플레는 R 성장이 담당.
- 리스크 1: EV 98% < 100%라 순수 EV 최적화 봇(상급자)은 여전히 상자를 안 산다 — 의도된 설계(투자와 같은 급의 도박)이며, 실제 플레이어는 분산 선호로 구매할 것.
