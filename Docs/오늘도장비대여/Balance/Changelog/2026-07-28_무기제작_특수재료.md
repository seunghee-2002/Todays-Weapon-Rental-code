# 무기 제작을 되살리기 위해 특수 재료 요구·드롭률 조정

> 기록: 2026-07-28 · 작성: /balance

## 근거 (왜)

무기 제작/재부여를 시뮬에 반영(로드맵 단계 5-3)한 첫 측정에서 **무기 제작이 사실상 죽은 콘텐츠**로 나왔다.
100시드 x 70주 전체에서 상급자 **8회** / 중급자 **1회** / 초급자 **0회**.

실패 사유를 분류해보니 원인이 단일했다:

| 실패 사유 | 상급자 | 중급자 |
|---|---:|---:|
| 해금일 미도달 | 0% | 0% |
| 골드 부족 | **0%** | **0%** |
| 인벤토리 만석 | 0% | 0% |
| 일반 재료(MAT_CRF) 부족 | 3.2% | 39.8% |
| **특수 재료(MAT_SPC) 부족** | **100%** | **100%** |

골드도 슬롯도 해금일도 일반 재료도 병목이 아니었다. 오직 특수 재료였다.

특수 재료는 **던전당 1종**이 `specialDropMaterial`로 고정되고, 보스 클리어 시에만 3~10%로 1개 떨어진다.
그런데 레시피는 서로 다른 던전 2~3곳의 특수 재료를 동시에 요구했다:

- 에픽 8종: `MAT_SPC_RAR_* x1~2` + `MAT_SPC_EPI_* x2` (2던전)
- 전설 8종: `MAT_SPC_RAR_* x1~2` + `MAT_SPC_EPI_* x1` + `MAT_SPC_LEG_* x2` (3던전)

`MAT_SPC_EPI_* x2`만 해도 **그 특정 에픽 던전 보스 클리어 기대 40회**(2 / 0.05)이고,
그 던전이 의뢰판에 뜨고 -> 선택되고 -> 성공해야 굴림 1회다.

> **중요: 조정 전에 봇 정책부터 의심했다** (로드맵 3부 원칙 2).
> 상급자 봇의 제작 목표가 `OrderByDescending(requiredGold)`, 즉 "가장 비싼 레시피"였다.
> 50일 이후 전설(3던전 관문)만 노리느라 에픽조차 못 만들고 있었다.
> 목표 선정을 "특수 재료 관문이 가장 적은 것 중 최고가"로 고치자 **8회 -> 120회(15배)** 로 뛰었다.
> 드롭률을 먼저 올렸다면 봇 결함을 드롭 인플레로 덮을 뻔했다.
> 이 정책 수정은 시뮬 봇 코드 변경이라 아래 수치 조정과는 별개다.

봇 교정 후에도 시드당 1.20자루로, 목표(70주 캠페인에서 에픽 5자루 이상)에 4배 부족했다.

## 대상 시스템 (무엇을)

무기 제작(`BlacksmithManager.ExecuteCraft(WeaponRecipeData)`)의 재료 요구량과,
보스 보상의 특수 재료 드롭률(`AdventureManager.Calculations.CalculateMaterialDropsWithBonus`).

## 수정 전후 (어떻게)

**1) 레시피 특수 재료 — 종류 수 감축 + 개수 절반** (`WeaponRecipes/*.asset` 16종)

| 등급 | 전 | 후 |
|---|---|---|
| 에픽 8종 | `RAR x1~2` + `EPI x2` (2던전) | **`EPI x1`** (1던전) |
| 전설 8종 | `RAR x1~2` + `EPI x1` + `LEG x2` (3던전) | **`EPI x1` + `LEG x1`** (2던전) |

- `MAT_SPC_RAR_*` 요구를 전 레시피에서 제거(16행), 남은 특수 재료 count를 전부 2 -> 1로 통일.
- **일반 재료(`MAT_CRF`)와 `requiredGold`는 변경 없음** — 진단상 병목이 아니었다(상급 실패 사유 3.2%).

**2) 특수 재료 드롭률 일괄 2배** (`Config/AdventureConfig.asset`)

| 항목 | 전 | 후 |
|---|---:|---:|
| specialDropCommon | 0.01 | 0.02 |
| specialDropUncommon | 0.02 | 0.04 |
| specialDropRare | 0.03 | 0.06 |
| specialDropEpic | 0.05 | 0.10 |
| specialDropLegendary | 0.1 | 0.20 |

`specialMaterialDrop`(회당 개수 1)은 변경하지 않았다.

## 시뮬 / 검증 근거

100시드 x 70주 x 5회차. 축을 하나씩 넣어 각 단계의 기여를 분리 측정했다.

| 단계 | 결과물 | 상급자 시드당 제작 |
|---|---|---:|
| 최초 측정 | sim_summary_20260728_202111 | 0.08자루 |
| 봇 목표 선정 교정(코드) | 20260728_204302 | 1.20 |
| + 레시피 RAR 요구 제거 | 20260728_204738 | 1.26 (**+5%**) |
| + count 2->1 & 드롭률 2배 | **20260728_205454** | **6.11 (목표 달성)** |

- **RAR 제거 단독 효과는 +5%에 그쳤다.** `RAR x1 @3%`(기대 33클리어)보다 `EPI x2 @5%`(기대 40클리어)가
  이미 더 빡빡한 관문이라, 종류를 줄여도 총 소요가 거의 안 줄었다. 병목은 "종류 수"가 아니라
  **"특정 던전 1곳을 반복 방문해야 한다"는 구조**였다. 그래서 개수·확률 축을 함께 썼다.
- 실패 사유의 특수 재료 비중은 100% -> 98.7%로 여전히 지배적이다(제작이 늘어도 매일 시도하므로 자연스럽다).

**부작용 점검 (202111 -> 205454):**

| 지표 | 전 | 후 |
|---|---:|---:|
| 상급 주간 순수입 | 38,707G | 37,084G (-4.2%) |
| 상급 폐업률 | 5% | 4% |
| 중급 주간 순수입 | 12,774G | 12,811G (+0.3%) |
| 중급 폐업률 | 18% | 21% |
| **무기 구매 지출** | 2,757G/주 | **2,720G/주 (거의 동일)** |
| 제작 재료 지출 | 199G/주 | 397G/주 |
| R 기준 제작 1자루 | 측정 불가(0회) | **1.1~1.6R** (구매는 2.0~3.1R) |

- **무기 상점 구매가 잠식되지 않았다.** 제작이 대체재가 아니라 추가 공급원으로 작동했다.
- 제작 1자루가 구매의 약 절반 값(1.1~1.6R vs 2.0~3.1R)이라 "재료를 모으는 수고 대신 싸게 얻는 경로"라는
  설계 의도에 맞는 위치다.

## 기대 효과 / 리스크

- 기대: 무기 제작이 죽은 콘텐츠에서 벗어나 70주 캠페인의 실질 획득 경로가 된다.
  특수 재료를 노리고 특정 던전을 반복 방문할 동기가 생긴다.
- **리스크 1 — 목표치가 공격적이다.** "에픽 5자루 이상"은 제작을 *주요* 획득 경로로 올리는 수준이다.
  이번 측정에서는 구매 잠식이 없었지만, 봇이 인벤 상한에 여유가 있어서일 수 있다.
  실플레이에서 제작 무기가 남아돌면 분해 회수 루프가 과열될 수 있으니 무기 보유 수를 관찰할 것.
- **리스크 2 — 중급자 폐업률 18% -> 21%.** 중급자는 제작을 거의 안 하므로(0.17자루) 인과가 약하고
  시드 경로 발산 노이즈로 본다. 다만 다음 조정 때 재확인할 것.
- **리스크 3 — 드롭률 2배는 제작 외 경로에도 영향을 준다.** 특수 재료는 결과 화면에서 골드로 사야 하므로
  (`buyPrice` 750~2,500G) 후반 골드 싱크가 커진다. 상급 제작 재료 지출이 199 -> 397G/주로 2배 됐다.
- 미조정: `specialMaterialDrop`(회당 1개), 일반 재료 요구량, `requiredGold`, 재부여 비용.
