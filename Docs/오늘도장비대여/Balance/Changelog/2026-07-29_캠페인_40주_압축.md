# 캠페인을 60주에서 40주로 압축하고 벌금을 2차 곡선으로 전환

> 기록: 2026-07-29 · 작성: /balance · `54444356` + 미커밋(엔드리스 인덱스 수정)

## 근거 (왜)

### 1. 목표 플레이타임과 캠페인 길이가 어긋나 있었다

하루 = 06:00~21:00 = 900게임분, 1초 = 3게임분이라 **1일 = 실시간 5분**(4배속 1.25분)이다.

| | 주차 | 일수 | 4배속 시간 |
|---|---:|---:|---:|
| **목표 회차 플레이타임** | — | 240~288 | **5~6시간** |
| 캠페인 전체 | 60주 | 420 | **8.8시간** |
| 수명 목표 (상급 / 중급 / 초급) | 60 / 35 / 15 | | 8.8 / 5.1 / 2.2시간 |

**캠페인(8.8시간)이 목표 회차(5~6시간)보다 길었다.** 그래서 설계된 커리큘럼의 58%만 소비되고
T4(46~60주, 전설 등급·전설 던전 도입)와 60주차 최종 시험 `전설의 완성`은 **아무도 못 봤다.**

### 2. 수명이 목표의 2~4배였고, 애초에 측정조차 안 됐다

| | 목표 | 2026-07-26 | 압축 직전 |
|---|---:|---:|---:|
| 상급 | 60주 | 70주 / 폐업 16% | **70주 완주 / 폐업 0%** |
| 중급 | 35주 | 55주 / 폐업 68% | **70주 완주 / 폐업 0%** |
| 초급 | 15주 | 10주 | 43주 |

상급·중급이 측정 구간(70주)을 완주해 **수명 중앙값이 잘려(censored) 값 자체가 안 나왔다.**
160주로 늘려도 상급 폐업률 1%라 마찬가지였다.

### 3. 수명 손잡이 탐색 — 6개 중 4개가 무효였다

압축 전에 다른 축을 전부 시도했고, 각각이 "여기는 아니다"를 확정했다.

| 축 | 결과 | 판정 |
|---|---|---|
| `successRateMax` 1.0 -> 0.95/0.90/0.85 | 완주율 -13%p (0.95) | **기각** — 전설 무기·스탯 100·일반 던전인데 "상한이 90%라" 실패하면 플레이어가 납득할 수 없다 |
| 보스 `difficultyMultiplier` 0.7 -> 0.6 | 완주율 **-0.8%p** | 저·중급 던전이 이미 포화 구간(상성 0.6 때문에 `effectBase >= 0.625`면 잘림)이라 지렛대가 없다 |
| 평판 임계값·획득 개편 | 45주 골드 **-1%** | 임계값을 올렸지만 획득 공식도 같이 커져 상쇄. 초반 시도 수만 -20% |
| `maxEventCountByGrade` 원복 | 순수입 **+4%** | 역효과. 이벤트마다 골드를 주므로 이벤트가 늘면 완주율이 떨어져도 중간 보상이 늘어난다 |
| 퀘스트 티어 앵커 +50% | 통과율 **74 -> 74%** | 등급 요구는 병목이 아니다(엔드리스 실측과 일치). 원복함 |
| 던전 요구 빈도 29 -> 38주 | 통과율 74 -> 70% | **유효** — 던전만이 작동하는 난이도 손잡이다 |

**수명을 직접 정하는 것은 골드 수지뿐이고, 수입 축은 완주율에 둔감했다.**
지출도 손잡이가 아니었다 — 가격을 2~4.5배 올려도 총액이 45,000G에서 정체한다
(인벤토리 50칸 상한에 이미 40자루, 강화·재료도 유한해서 **쓸 곳이 없다**).
남은 것은 회피 불가능한 **벌금**과 **캠페인 길이**뿐이었다.

## 대상 시스템 (무엇을)

주간 퀘스트 생성기(`WeeklyQuestGenerator`, 에디터) + 연동 Config 3종 + 밸런스 시뮬레이터 미러.

40주 지도 (파동 규칙 유지 — 시험 직전은 휴식, 소피크·시험 비인접, 시험 직후는 도입):

```

T1(5~10)  도 도 표 소 휴 시
T2(11~20) 도 도 표 소 휴 표 변 소 휴 시
T3(21~30) 도 도 표 소 휴 표 변 소 휴 시
T4(31~40) 도 도 표 소 휴 표 소 표 휴 시
```

### C. 벌금을 선형 -> 2차 곡선

| 항목 | 전 | 후 | 위치 |
|---|---|---|---|
| 벌금 공식 | `1200 + 4500 x w` | **`1200 + 200 x w^2`** | `FINE_BASE`, 신설 `FINE_QUAD` |

| 주차 | 선형 4500 | 2차 200 |
|---:|---:|---:|
| 5 | 23,700 | **6,200** |
| 9 | 41,700 | **17,400** |
| 20 | 91,200 | **81,200** |
| 40 | 181,200 | **321,200** |

**전환 이유:** 리스케일(3000 -> 4500)로 초급자가 **9주**에 죽었다(목표 15주).
초반 벌금 41,700G 한 방이 원인인데, 선형에서는 초반을 낮추면 후반도 같이 낮아진다.
[[밸런스_시뮬레이터_정리|reference/밸런스_시뮬레이터_정리.md]]가
*"초급 15주 / 중급 35주를 선형 `BASE + w x SLOPE`로 맞추려면 **BASE가 음수여야 한다**"* 고
지적하고 55주로 타협했던 조합이다. **2차 곡선은 절편을 건드리지 않고 이 제약을 우회한다.**

### D. 후반 던전을 희소 개체로 (T3~)

| 항목 | 전 | 후 | 위치 |
|---|---|---|---|
| 던전 개체 선택 | 등급 안에서 균등 | **21주 이후 `questWeight` 최저 개체만** | `MakeDungeon(scarceOnly:)` |
| 던전 자료구조 | `(id, name)` 튜플 | **`DungeonInfo`** (grade + questWeight) | `CollectDungeonsByGrade` |

캠페인 31~40주 의뢰판 배율이 `{0.05, 0.25, 2, 15, 150}`으로 엔드리스와 동일해,
엔드리스 실측(상급자 Thin 94% / Scarce 76% / **VeryScarce 47%**)이 그대로 적용된다.
캠페인이 `questWeight`를 못 보던 것이 **던전 난이도를 통제할 수 없던 이유**였다.

## 이번에 드러난 버그 4건 — 전부 "주차 절대값 하드코딩"

**캠페인 길이라는 상수 하나를 바꿨더니 그 값을 암묵적으로 가정한 코드가 네 군데서 조용히 깨졌다.
넷 다 에러 없이 잘못된 값을 내놓는 종류라, 측정값을 그대로 믿었으면 오판으로 이어졌다.**

| # | 위치 | 증상 | 수정 |
|---|---|---|---|
| 1 | `WeeklyQuestGenerator.Generate` | `RenameAsset`이 재임포트를 일으켜 메모리 수정본을 되돌린 뒤 저장 -> **제목만 새로 붙고 요구조건은 옛것** | 이동 -> 채우기 -> `SetDirty` 순으로 교체 |
| 2 | `SimBundle.CampaignWeeks = 60` (상수) | 엔드리스 스윕이 41~56주 템플릿을 못 찾아 **빈 결과로 `exit 0`** | `EndlessQuestConfig.campaignLastWeek`을 읽는 프로퍼티로 |
| 3 | `SimReport.CheckpointWeeks/ExamWeeks` | 60주 기준(5/15/29/45/60)이라 **존재하지 않는 주차를 리포트** | 40주 기준(4/10/20/30/40) |
| 4 | `EndlessDifficulty` / `BuildEndlessRequirements` switch | 주차 61~76 절대값이라 41~56주가 전부 `<= 64` -> **16종 전부 Easy 라벨 + `default`(최고난도) 조합** | **엔드리스 인덱스(0~15)** 기준으로 전환 |

4번이 가장 컸다 — "Easy 라벨이 붙은 최고난도 퀘스트"가 16주 내내 반복돼
중급 통과율 13% / 생존 3주로 측정됐다.

> **남은 위험**: 도입 스케줄·주차 지도·시험주 명세는 여전히 주차 절대값이다.
> 캠페인 길이를 또 바꾸면 같은 방식으로 깨진다.

## 기대 효과 / 리스크

**기대 효과**
- 중급자(대다수 플레이어) 회차가 5.3시간으로 목표에 맞고, 설계된 커리큘럼 T0~T4를 전부 소비한다.
- 전 페르소나가 폐업한다(97 / 100 / 100%) — 오늘 아침까지 상급·중급 폐업률 0%로 회차가 끝나지 않았다.
- 벌금 2차 곡선은 인게임 근거도 자연스럽다: 길드가 신참에게는 관대하고 명성이 쌓일수록 위약금이 가파르게 오른다.

**리스크 / 남은 것**
1. **상급 52주(7.6시간)는 목표 40주를 30% 초과한다.** 통과율 81%라 벌금을 거의 안 내고, 던전 빈도를
   더 올리려면 도입주(새 요소 1개 원칙)를 깨야 한다. 대장간 소모처 개편 후 재검토 권장.
2. **엔드리스가 매우 가혹해졌다.** `fineBase`를 4배(79,200 -> 321,200) 올린 결과로
   중급 기준선 폐업률 4.8 -> **71.4%**, 생존 40 -> **25주**, 순수입 +10,404 -> **-5,124G**.
   캠페인 40주 + 엔드리스 25주 = 65주라 **중급자는 대부분 캠페인 안에서 죽어 엔드리스를 못 본다.**
3. **`EndlessQuestConfig.finePerWeek`(8,000)가 캠페인 곡선과 안 맞는다.** 40주차에서 2차 곡선의
   기울기는 주당 약 16,000G인데 엔드리스는 8,000G로 꺾인다. 미조정.
4. 상급 통과율 81%는 목표 95%에 못 미친다. 문서의 "생존 주차 우선, 통과율 양보" 결정을 따랐다.
