# 액티브 아이템 제작 총비용을 약 1/3로 인하 (2be2f5d7)

> 기록: 2026-07-27 · 작성: /balance (소급) · 커밋: 2be2f5d7

## 근거 (왜)
액티브 아이템 제작 총비용(골드 + 재료)이 실사용 대비 과했다. 소비형 아이템을 실제로 만들어 쓰기엔 진입 장벽이 높아, 골드 비용을 대폭 낮추고 일부 레시피의 재료 개수도 줄여 합산 총비용을 약 1/3 수준으로 조정.

## 대상 시스템 (무엇을)
액티브 아이템 제작(ActiveItemManager / BlacksmithManager 제작 경로). 레시피 SO(`ActiveItemRecipes/`) + CSV.

## 수정 전후 (어떻게)
골드 비용(goldCost) 대표값:
| 레시피 등급대 | 전 | 후 |
|---|---|---|
| 저가(DEATH_WARD, DOLL, ESCAPE_ROPE 등) | 300 | 100 |
| 중가(CHARM_01, DISASSEMBLY_KNIFE, FAME_SCROLL, GOLD_AMULET, TREASURE_MAP 등) | 800 | 150 |
| 고가(CHARM_02, POTION, SWIFT_SHOES) | 1500 | 250 |

재료 개수(count)도 일부 인하 (예: `RECIPE_GOLD_AMULET_01` 재료 count 4 -> 1). FORGE_STONE 계열은 재료 라인 일부 제거.

- 골드 인하만으론 약 1/5~1/6이지만, 재료 개수 인하까지 합산해 "총비용 약 1/3"로 맞춤. 레시피별 정확한 값은 커밋 2be2f5d7 참조.

## 시뮬 / 검증 근거
- 조정 당시: 시뮬 없음 - 판단 근거: 소비형 아이템의 회당 효용 대비 제작비 체감 조정. 정량 시뮬 미실시 (MC 계산은 `밸런스_시뮬레이터_정리.md` 4-6).
- **사후 실측 (2026-07-27, 시뮬 단계 3 액티브 아이템 반영 후)**: `Documents/Simulation/sim_summary_20260727_205343.md` vs 미사용 기준선 `sim_summary_20260727_201902.md`, 100시드 x 70주.
  - 아이템 1개 총비용(제작 골드 + 재료 구매): 상급자 1.5~1.9R / 중급자 0.9~1.9R — 4-6 계산(0.5~2.3R)과 정합.
  - 사용/미사용 비교: 상급자(에픽+ 던전에만 사용) 주간 순수입 32,800 -> 33,978G(+3.6%), 중급자(아무데나 사용) 5,625 -> 4,711G(-16%) — **"상위 던전에 쓰면 이득, 하위 던전에 쓰면 손해" 방향 재현**. 단 아이템 지출 규모가 작아 격차가 노이즈 대비 크지는 않음.

## 기대 효과 / 리스크
- 기대: 액티브 아이템 제작·소비 회전율 상승, 실사용 유도.
- 리스크: 재료 수요가 줄어 재료 획득 루프(분해/드랍)의 가치가 함께 하락할 수 있음.
