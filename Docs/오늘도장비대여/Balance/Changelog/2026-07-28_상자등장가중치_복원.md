# 수수께끼 상자 등장 가중치 복원 (디버그 잔재 원복)

> 기록: 2026-07-28 · 작성: /balance

## 근거 (왜)

`MorningEventConfig.asset`의 `boxTierWeights`가 코드 기본값과 달랐다.

- 코드 기본값(`MorningEventConfig.cs`): `{ 0.60f, 0.30f, 0.10f }`
- 에셋 실제값: `0.33 / 0.33 / 0.33`

런타임은 에셋을 읽으므로 **신비 상자(10,000G)가 일반 상자(1,500G)와 같은 1/3 확률로 등장**하고 있었다.

git 이력에서 원인이 확정됐다:

```
a9f0bcef  "morningevent debug"  (2026-06-11)
-  boxTierWeights: 0.6 / 0.3 / 0.1
+  boxTierWeights: 0.33 / 0.33 / 0.33
```

**커밋 메시지가 "debug"이고 코드 기본값은 그대로다.** 모든 티어를 골고루 확인하려고 균등하게 바꿔놓고
되돌리지 않은 테스트 잔재이지, 밸런스 의도가 아니다.

이 항목은 [[2026-07-27_아침이벤트_일수비례_제거]]에
"boxTierWeights 미확인"으로 리스크 기록해 둔 것이며, 이번에 원인이 확정돼 정리한다.

## 대상 시스템 (무엇을)

아침 이벤트 - 수수께끼 상자(`MorningEventManager.RollBoxTier` 경로)의 티어 추첨 가중치.

## 수정 전후 (어떻게)

| 항목 | 전 | 후 | 위치(파일:필드) |
|---|---:|---:|---|
| 일반 상자(1,500G) 가중치 | 0.33 | **0.6** | MorningEventConfig.asset:boxTierWeights[0] |
| 희귀 상자(4,000G) 가중치 | 0.33 | **0.3** | 같은 배열[1] |
| 신비 상자(10,000G) 가중치 | 0.33 | **0.1** | 같은 배열[2] |

등장 확률로 환산하면 33/33/33% -> **60/30/10%**.
상자 가격·기대값(EV 98%)은 변경하지 않았다. 코드 기본값과 일치시킨 것이므로 실질은 원복이다.

## 시뮬 / 검증 근거

`Documents/Simulation/sim_summary_20260728_211911.md` vs `sim_summary_20260728_205454.md`, 100시드 x 70주 x 5회차.

중급자(상자를 사는 유일한 페르소나 — 상급자는 EV 기반이라 미구매, 초급자는 아침 이벤트 무시):

| 항목 | 전 | 후 |
|---|---:|---:|
| 상자 회당 평균 가격 | 5,159G | **3,436G (-33%)** |
| 구매 횟수(100시드 누적) | 148회 | 157회 (+6%) |
| 상자 총 지출 | 763,500G | 539,500G (-29%) |

- 의도대로 싼 상자가 자주 떠 평균 구매가가 내려갔고, 골드 여유 조건(가격의 5배)에 막혀 못 사던 경우가
  줄어 구매 횟수는 오히려 늘었다.
- 중급 주간 순수입이 12,811 -> 11,489G로 움직였으나 **상자 지출 규모(주 약 77G, 순수입의 0.7%)로는
  설명되지 않는 변화폭이라 시드 경로 발산 노이즈로 본다.** 중급자는 폐업률 21~22% 구간이라
  중앙값이 노이즈에 민감하다(단계 2에서 확인된 성질).

## 기대 효과 / 리스크

- 기대: 초반 플레이어가 살 수 없는 고가 상자(10,000G)를 계속 마주치는 상황이 줄어든다.
  상자 티어가 "일반이 흔하고 신비는 귀하다"는 원래 설계대로 돌아온다.
- 리스크: 신비 상자 등장이 1/3 -> 1/10로 줄어 **고가 상자의 전설 무기 획득 경로가 그만큼 희소해진다.**
  다만 신비 상자는 EV 98%의 도박이므로 기대 손익은 중립이고, 등장 빈도만 원설계로 복귀한 것이다.
- 상자 EV(98%)·가격(1,500/4,000/10,000)은 2026-07-27 조정 그대로다.
