## 작업 전 읽을 것

> [!important] 밸런싱 전에 대상 시스템의 참고 문서를 먼저 읽는다
> `/balance` 스킬이 자동 안내하지만, 수동으로 볼 때도 아래 순서를 지킨다.

- [[밸런스_시뮬레이터_정리]] — 시뮬 규칙 / 커밋별 조정 이력 / **R 기준 밸런싱 체계(3부, 핵심)** / R 미적용 검산
- [[골드_경제_구조]] — **골드 지출처 전수(19곳) + 고정/변동 가격 판정 원칙.** 가격 체계 재설계의 근거 문서
- [[주간퀘스트_난이도_계수]] — 퀘스트 목표 부하 계수·캡·예산 공식
- [[주간퀘스트_레벨디자인]] — 40주 커리큘럼·티어 앵커·시험주 명세
- [[시뮬레이터_설계]] — 시뮬레이터 하루 루프·페르소나 정책
- [[밸런스_미적용_영역과_시뮬_로드맵]] — 아직 밸런싱 안 된 영역·다음 할 일

> [!note] 시뮬레이터 원시 출력
> 실행 결과(`sim_summary_*.md`, `sim_raw_*.csv`)는 Vault 밖 `Documents/Simulation/`에 있다. 이유는 [[시뮬레이션_결과]] 참조.
